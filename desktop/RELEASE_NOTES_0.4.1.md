# 开智 0.4.1

## 猜你想问

- 在「设置 → AI」新增独立的「猜你想问」区域，可打开或关闭问题推荐，保存后生效。
- 关闭后清除输入框中的建议、取消进行中的推荐请求，并停止后续推荐请求；迟到的回复不会重新显示。
- 开关偏好保存在本机，重启后保留；沿用已有设置，默认开启，重新打开可恢复推荐。
- 开启时，根据当前阅读位置、选区和最近对话推荐下一个问题；按 Tab 或回车采用，Esc 收起，也可直接点击发送。推荐会消耗模型额度。

## 阅读与界面

本版包含 [0.4.0](https://github.com/graohene10-spec/pdf-copilot/releases/tag/desktop-v0.4.0) 的改进：

- 更紧凑的玻璃模型卡片与思考强度滑杆，清晰区分开启和关闭的文档上下文开关。
- PDF 放大超宽时显示底部横向滚动条；深色滤镜改善正文、公式和细线的对比度，保留彩色图片的层次。
- 修复深浅主题切换后组件颜色不同步，以及设置和 PDF 样式影响窗口底色的问题。
- 空白对话支持英文问候、中文古诗和自定义问候；思考进度显示转动星标、动词与用时。

同步更新首页、桌面使用说明、升级指南、隐私说明与内置示例。

Windows x64 发布包含安装版、免安装 ZIP、完整源码 ZIP、发布清单和 SHA-256 校验文件。0.3.1 及以后版本可在应用内一键升级；文档库、阅读进度、设置、对话记录和已保存凭据继续沿用。
