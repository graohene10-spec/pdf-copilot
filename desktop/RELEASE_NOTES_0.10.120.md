# 开智 0.10.120

## 总结

把一份文档写成一份总结文档，存进文档库。

- **入口**：文档库里右键文档选「总结…」；阅读区右键选「总结这份文档…」；阅读助手里输入 `/summary`。
- **设置**：进来先是一张表，一行一项（范围、长度、结构、语风、语言、侧重），点哪行哪行展开，可以选现成的，也可以自己写一句。都可以不填，没填的由助手决定。别的要求写在下面的输入框里，按发送就是开始。
- **范围可以说个大概**：「第三章」「讲同态的那部分」「当前这一章」，助手自己用目录和搜索去找，并说明它认定的是哪一段。
- **草稿面板**：开始后阅读区换成一张纸，助手写到哪显示到哪。对话栏里只留一枚小牌子，不显示正文。助手栏标题上的文档图标可以收起、再打开草稿。
- **随时改**：可以打断助手，接着说「短一半」「第三节展开」，改的是同一份草稿。
- **存入文档库**：点了才存。存成 Markdown，放在原文档所在的文件夹里，名字是「原名 · 总结.md」；同一段对话再存是覆盖上次那份。
- **图解与可交互**：打开后文档里可以有 Intelligent UI 的图解和可拖动的演示；Markdown 阅读器现在会把文档里的 `ui` 代码块画出来，不显示代码。
- **分多次写**：文档很长时打开，助手一段一段地读和写，自己接着写到完（最多 40 轮），用量更多。不开就是一次写完。
- 总结对话不读也不写记忆。

目前修改是整篇重写：每改一次，助手会把整份文档重新输出一遍。

## 文档库

- 右键文档、右键标签多了「打开所在文件夹」，在资源管理器里选中这份文件。
