# 开智 0.10.118

## PDF 在高分屏上发虚

- 每页位图的像素上限从 400 万提到 1200 万。原来 A4 页面只要在屏幕上宽过约 1680 个物理像素（2K、4K 屏配 125%～200% 缩放，铺满阅读区时很容易超过）就画不到屏幕的分辨率，再被拉伸显示，字是糊的。
- 页面框对齐到整数个设备像素，位图一个像素对屏幕一个像素。原来在 125%、150%、175% 缩放下页面框常常停在半个像素上，位图被拉伸零点几个像素。
- 屏幕缩放比例变了（窗口拖到另一块屏幕、在系统里改了缩放）会自动按新的倍率重画。

## 记忆分成「本书」和「全局」

- 新对话开头可以三选一，下面一行写明读什么、记到哪：
  - 本书：只读这本书里记下的，新记的也只留在这本书；
  - 全局：读所有书共用的记忆，新记的所有书都能用；
  - 不用：不读记忆，这段对话也不记。
- 选的那种是下一段新对话的默认；第一次默认是「本书」。
- 原来的「不记入记忆」只是不记，仍然会读。现在「不用」是读和记都关。
- 以前的对话和记录都算「全局」，不受影响。管理对话页里右键一段对话可以改。

## 界面

- 顶栏右侧去掉「文档详情」和「并排阅读」两个按钮。阅读助手居中，左边是收藏、翻译，右边是收起顶栏、全屏，设置单独在最右。
- 文档详情改成一张居中的卡片：在文档库里右键文档，或右键标签，选「详情与标签…」。
- 并排阅读的其他入口不变：快捷键、右键菜单、标签的右键菜单、拖动标签。
- 阅读区右侧书签轨道的细线从顶到底一整条，两头不再留空和淡出。
