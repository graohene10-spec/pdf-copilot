# 功能清单与测试记录

日期：2026-10-06。修复版本：0.2.3。

## 本次确认并修复的问题

1. 含链接的 PDF 页调用了 PDF.js 6.4.299 已移除的 `convertToViewportRectangle`，导致页面不能完成初始化，内链与框选均受影响。改为转换两个端点，已用包含真实 PDF 注释链接的合成文件复现并验证。
2. 页面尚未渲染完成时，框选结束会被直接丢弃。现在等待该页完成后打开预览；退出框选、切换文档、缩放、导航或再次框选会取消旧等待，避免使用旧坐标。
3. 取消文字选择或改选阅读区外的内容后，“发送选中文字”仍可能保留上一次文字。现在立即清空选择状态。
4. 框选模式中翻页后提示恢复为普通阅读模式。现在保留框选模式及拖动操作提示。
5. 取消加密 PDF 的密码输入后，取消提示被通用“无法打开 PDF”错误覆盖。现在保留取消提示，并能继续打开其他文档。

前两项都能导致“鼠标拖动后没有预览”。用户个人 Edge 中当时发生的是哪条路径仍未直接确认。

## 自动检查

- 单元测试：57 项通过，1 项真实 Codex 元数据测试默认跳过；真实连接另用 Edge Native Messaging 检查通过。
- 最终阅读验收：26 组检查全部通过，含高 DPI、加密 PDF 和用户指定 PDF 的本地预览；原生截图和增强框选包含多次正反向拖动及取消重试。
- `npm run test:acceptance`：独立临时 Edge、合成 PDF、本机服务，覆盖上述阅读和框选矩阵。可用 `PDF_COPILOT_TEST_DPR=2` 测高 DPI；指定 `PDF_COPILOT_LOCAL_PDF_PATH` 时只本地预览该文件。
- `node scripts/browser-smoke.mjs`：选文和图片附件、模拟 API 流式、临时窗口、侧栏用户操作、引用回跳及文档隔离。
- `npm run test:upgrade`：公式、等待状态、取消/错误恢复、快捷键注册、滚动和内存预算；极简版设置 `PDF_COPILOT_MATH_PROFILE=plain`。
- 两个发行版均完成资源路径、语法和 Manifest V3 检查。
- `node scripts/native-inference-smoke.mjs` 是按需运行的真实 Codex 收发检查，会使用少量额度；验证合成文字与内存中生成的小图。不会上传用户文档、导出图片或读取登录令牌。

原生命令集成测试只在测试副本捕获监听器。无头浏览器不能触发浏览器级按键，因此不将这些结果标记为真实快捷键已通过。测试副本的额外权限、延迟渲染入口不进入发行包。添加附件不会自动发送给模型；本次个人 PDF 的截图只用于内存预览。

## 真实浏览器环境的待验项目

隔离无头 Edge 的结果不能代替真实浏览器快捷键和原生 PDF 右键菜单验收。当前仍未完成这些操作在个人配置及不同浏览器版本中的完整检查。升级时需重新加载扩展并重开旧阅读页，设置页应显示 v0.2.3。

本版按上述已测范围和限制发布，安装与使用步骤见仓库 README。测试截图使用合成 PDF 和模拟回复，不包含个人文档。
