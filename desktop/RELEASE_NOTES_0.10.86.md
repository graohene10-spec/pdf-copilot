# 开智 0.10.86

Codex 速度档：

- 支持 Codex 各模型自己的速度档：标准、快速、超快（Ultra Fast）。每个模型有哪几档由 Codex 报出来，有的模型没有超快、有的一档都没有，界面只列出当前模型有的。
- 阅读助手输入栏的模型抽屉里多一行「速度」；设置 → AI 里每个功能也能单独选。
- 选「标准」会明确告诉 Codex 用标准速度（有的模型默认就是快速档，会多耗额度）。
- 换到没有所选档位的模型时按标准走。旧版 Codex 不报档位，仍是原来的 Fast 开关。

书签：

- 侧栏的「标签」换成「书签」：所有书的书签按书归在一起，一行一枚（小画 + 名字或页码），点一下打开那本书跳过去。
- 自定义书签：右键书签 →「换画风…」→「用自己的图片…」，图片裁成书签的比例存下来，各本书通用，最多 12 张；正在用的自定义图可以删掉。

文档的标签本身没有删：文档详情里仍能加，搜索仍能搜到，只是侧栏不再按标签筛选。
