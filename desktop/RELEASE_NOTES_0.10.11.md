# 开智 0.10.11

## 滚动条
- **随界面风格变化，而且更淡**：液态玻璃是淡灰圆条；暖色极简是一道细的暖灰线；铅笔草稿是一小段淡铅笔线。指上去才加深。
- **修复灰色带箭头的系统滚动条**：代码块、表格、设置、翻译栏等处原来会冒出系统样式的滚动条，现在都用应用自己的样式。
- **阅读区的滚动条平时隐藏**：PDF 和 Markdown 的滚动条（包括 PDF 底部的横向滚动条）只在滚动时出现，停下约一秒后隐去；鼠标指到滚动条上也会显出来。

## 代码语法高亮
- 阅读助手回答里的代码块、Markdown 文档里的代码块都有语法高亮（常用的三十多种语言）。没标语言的代码会自动识别，拿不准就不上色。
- 配色随界面风格和深浅主题变化：铅笔草稿像彩色铅笔，暖色极简是低饱和的陶土 / 橄榄色。

## 「猜你想问」修复
- 换到另一场对话或另一份文档时，上一处的猜测不再留在输入框里（原来会把别的文档的问题带过来，按回车还会发出去）。
- 空白的新对话、没选中文字时不显示猜测；新的猜测没算出来时，旧的也撤掉。
