# 开智 0.10.94

使用教程（十二段全部做完）：

- 章节顺序：接入 AI、快速解释、用图解释、阅读助手、翻译、标记、书签、文库、多文档、阅读视图、计时、外观。
- 接入 AI 放在最前：连接服务（填 API Key，或用本机 Codex 的登录），再给每个功能选模型。翻译和快速解释选响应快的（示例用 DeepSeek Flash），阅读助手选能力强的旗舰模型。
- 阅读助手一段包含：提问、选中回答里的词到附属对话追问、从任意一条回答开分支、输入 / 调出指令、/btw 顺便问一句。
- 节奏加快：每段开头一张片头（编号、细线、标题），顶部一排节拍点标出进行到第几步，鼠标和镜头都更利落。
- 每段循环播放。点「看完了」：圆描一圈、勾划出来，章节列表里打上勾，然后进下一段；全部看完后可以从头再看。
- 每次启动自动弹出，直到勾上左下角的「不再自动弹出」。侧栏底部的播放按钮随时可以再打开。
- 字幕改成平铺直叙的写法。
