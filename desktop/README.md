# 开智 0.7.1

开智是一款 Windows PDF / Markdown 阅读与管理工具，支持并排阅读、同书多开、本机手写标记和 AI 文档问答。界面采用可调节的液态玻璃材质，文档库、阅读进度、设置和对话记录保存在本机。

[下载 0.7.1](https://github.com/graohene10-spec/pdf-copilot/releases/tag/desktop-v0.7.1) · [本版更新](RELEASE_NOTES_0.7.1.md) · [0.7.0 更新](RELEASE_NOTES_0.7.0.md) · [升级指南](docs/UPDATING.md) · [隐私与数据](docs/PRIVACY.md) · [构建与发布](docs/RELEASING.md)

## 0.7.1 更新

- 侧栏与阅读助手收放时，PDF 连续跟随阅读区缩放；适应宽度时拖动助手边缘可实时调整页面，松手后更新清晰位图。
- 书签采用白色磨砂玻璃、深色芯和明暗轮廓，适合白纸、深色页面与图片底板；名称与标记显示在同一块玻璃中。
- 提问导航使用黑白刻度，悬停可查看问题并钉住，钉住后刻度旁出现圆点。
- 新增「设置 → 外观 → 边缘高光」，范围 0–100%，默认 50%，拖动时可实时预览。

## 下载与首次使用

需要 Windows x64 和系统 WebView2。普通用户下载发行包即可使用，无需安装 Node.js 或 Rust。

| GitHub 附件 | 用途 |
| --- | --- |
| [kaizhi_0.7.1_x64-setup.exe](https://github.com/graohene10-spec/pdf-copilot/releases/download/desktop-v0.7.1/kaizhi_0.7.1_x64-setup.exe) | Windows x64 安装版 |
| [kaizhi_0.7.1_x64-portable.zip](https://github.com/graohene10-spec/pdf-copilot/releases/download/desktop-v0.7.1/kaizhi_0.7.1_x64-portable.zip) | 免安装版；解压后运行 `开智-portable/开智.exe` |
| [kaizhi_0.7.1_source.zip](https://github.com/graohene10-spec/pdf-copilot/releases/download/desktop-v0.7.1/kaizhi_0.7.1_source.zip) | 完整源码，供开发者构建 |
| manifest.json / SHA256SUMS.txt | 文件清单、源码提交和附件校验值 |

1. 安装程序，或将免安装 ZIP 全部解压，保留 `开智.exe` 旁的 `native-host/` 文件夹。
2. 点击左栏「加入文档」、按 `Ctrl + O`，或把多个 PDF / MD / Markdown 文件拖入窗口。也可先打开包内 `samples/` 中的示例。
3. 在「设置 → AI」选择服务商并填写配置；API 服务使用自己的密钥，Codex 使用本机登录。可用服务与协议见下方说明。
4. 打开文档，点击「阅读助手」，输入问题并发送。需要结合当前页和原文检索时，开启输入区的文档上下文选项。

安装版与免安装版共用当前 Windows 账号的应用数据目录。「免安装」指无需运行安装程序，文档库并不随程序文件夹一起迁移；备份与更换电脑请看[数据说明](docs/PRIVACY.md)。

0.3.1 起，安装版与免安装版都能一键下载、校验、安装并重启；**0.3.0 安装版**也可从应用内升级。0.6.1 起优先使用 GitHub 接口的附件摘要校验，旧版若因网络取不到校验文件，可手动下载本版。**0.2.2 及更早安装版、0.3.0 及更早免安装版**需要手动升级。具体步骤见[升级指南](docs/UPDATING.md)。

## 文档库与阅读

- 文档库支持标签、收藏、搜索和排序；可按加入时间、阅读时间、名称、大小或类别升降序排列，「默认排列」保留最近阅读或手动排序。加入文档记录原文件位置，原文件保留在原处。
- PDF 支持连续阅读、目录、内部链接、页码跳转、缩放、选文、图表框选和引用定位。`Ctrl + 滚轮` 缩放，`Ctrl + 0` 适应宽度。
- 页面放大到比阅读区宽时，阅读区底部出现一条玻璃横向滚动条，可拖动或点轨道跳转，范围覆盖整页；`Shift + 滚轮` 和触控板横滑同样可用。
- 深色主题下，PDF 的文字与线条映射为深灰底、柔白字；识别到的彩色图片和照片保留原色并适度压暗。图片识别延后到滚动停止、浏览器空闲时进行，并缓存结果。
- Markdown 支持目录、公式、图片、表格、任务列表、源码视图和按原文件行号定位。`Ctrl + 滚轮`、`Ctrl + = / -` 或工具栏 − / ＋ 可缩放整篇文档，文字、图片、公式与表格一起变化；点击百分比恢复 100%。默认字号和内容宽度在「设置 → 阅读」调整。
- `Ctrl + F` 聚焦阅读工具栏的搜索框；`Enter / Shift + Enter` 切换下一个 / 上一个结果。PDF 逐页搜索可取消，纯扫描 PDF 需要文字层才能搜索正文。
- `F11` 进入或退出全屏。普通窗口与全屏均可使用「收起顶栏与侧栏」，左上角保留展开标签；点标签或按 `Ctrl + B` 展开。
- 开关左栏、顶栏或阅读助手时，阅读区连续跟随面板尺寸变化。适应宽度时拖动助手边缘，页面实时缩放，松手后重新渲染。
- 文档打开后自动保存阅读位置；各标签分别保留本次运行中的缩放、目录、搜索状态和 Markdown 视图。
- 右键文档库里的书目：打开、收藏、更换显示封面（首页预览 / 自选图片 / 默认图标）、从文档库移除。封面压缩后保存在本机，同一本书的副本共用。

### 并排阅读与同书多开

点击顶栏「并排阅读」或按 `Ctrl + \`，从已打开标签或文档库选择文档，最多同时显示三栏。PDF 和 Markdown 可混合并排，每栏独立保留工具栏、缩放与阅读位置；也可通过标签右键菜单选择在左侧或右侧并排打开。

右键文件标签，选择「在右侧再开一份」，可同时查看同一本书的不同位置。副本共用原文档、AI 对话和手写标记，但各自保留当前工作区内的位置；副本位置不写回文档库。整个并排布局及副本位置不跨重启恢复。

点击某栏会把键盘阅读操作、框选和标记切到该栏；并排时助手仍保持原来的阅读对象。需要换书时，从助手对话标题的菜单选择「改读」。右键标签还可为该文档开一个固定的助手窗口，最多三个；阅读栏和助手栏可拖动重排，助手宽度可拖动调整。

### 框选与手写标记

PDF 和 Markdown 的工具栏均提供框选与标记。Markdown 框选会同时准备截图与区域内原文，公式保留 LaTeX 源码，表格按行列提取，可通过选区旁的快捷气泡直接提问。

标记工具包括钢笔、荧光笔、下划线和橡皮。`Alt + 1 / 2 / 3` 切换前三种工具，再按当前工具的键退出；`Ctrl + Z` 撤销，`Esc` 退出标记。PDF 可清除本页，Markdown 可清除全部标记并撤销该操作。

笔迹自动保存在本机，同书副本共享；PDF 标记跟随页坐标，Markdown 标记跟随段落布局。重启后恢复笔迹，撤销历史保留在本次运行中。标记是阅读器覆盖层，原文件保持不变；当前不提供带笔迹 PDF 导出。

### 书签

`Alt + B` 在当前位置添加书签，`Ctrl + ↑ / ↓` 跳到前一个或后一个书签；也可在阅读区右键选择「在这里加书签」。点击右侧玻璃标记跳转，右键命名或删除。名称与标记一体显示，连续按快捷键可继续跳转。PDF 和 Markdown 均支持，书签保存在本机，同书副本共享。

## AI 问答与对话记录

支持 DeepSeek、OpenAI、Claude、Kimi、智谱 GLM、通义千问、自定义接口和本机 Codex。默认回车发送、`Ctrl + Enter` 换行；发出的问题下方会列出一起交给 AI 的截图、所选文字和文档页码；参考原文收在回答上方的 Thinking 里，点开才显示。回答流式显示，可停止、复制、跳转原文引用；思考时显示 Claude Code 式的转动星标、带从左到右流光的英文动词（Thinking… / Cogitating… 等）和按整秒走的用时，展开可看完整思路，不显示 token 计数；回答中的公式和 Mermaid 图表可排版显示。点输入区的模型按钮，输入栏下沿会拉长露出模型胶囊和分段式的思考强度选择（再点一次或按 Esc 收回）；服务、密钥与预算在「设置 → AI」；输入区右侧的圆环显示当前对话的上下文占用。

空白对话显示助手形象和问候，可在「设置 → AI → 空白页问候」选择英文、中文古诗、混合或自定义句子。问候使用内置的 Anthropic Serif，中文按字体回退显示；古诗不显示作者与出处。输入框提供轮换提示语，思考时的转动符号每段回答随机选择。

普通选中文字不会自动展开助手，点击浮动的「问 AI」入口才会带入原文。开启文档上下文（输入区的书本胶囊：带主色玻璃为开，书本上有斜线为关）后，助手可读取当前页、搜索和补充有限的相关原文；支持图片的模型可接收页图或框选截图。发送问题时准备上下文并调用服务；下述「猜你想问」会单独发起推荐请求。

**猜你想问**默认开启，可在「设置 → AI → 猜你想问」关闭。输入框为空，且有文字选区或已有有效文字对话时，助手根据选区和最近对话推荐问题；文档上下文开启时还会读取当前页原文。空白新对话与单独截图不触发推荐。按 `Tab` 或回车将建议填入输入框，再发送或修改；`Esc` 收起，采用提示只在前三次出现。

推荐使用当前服务商：DeepSeek Flash、GPT-5.4 Mini、Claude Haiku，或其他服务商的当前模型；Codex 使用当前模型支持的最低思考强度。每次推荐会消耗额度。关闭并保存后清除建议、取消推荐请求，重启后保留选择。发送范围见[隐私说明](docs/PRIVACY.md)。

对话菜单可新建、切换和删除对话；问题可编辑后重答，回答可重新生成或从此处分支。右侧提问导航可跳到历史问题，悬停卡片显示问题与回答摘要，可钉住常用问题。历史菜单使用实色底板，按「这份文档 / 全部文档」查看已保存对话。

已保存的对话文字、思考内容和引用可在重启后恢复；草稿、尚未发送的选区和图片附件不跨重启保存。每文档最多保存最近 40 个非空会话，每会话最多保存 60 条消息。详细保存与删除范围见[隐私说明](docs/PRIVACY.md)。

每段对话同时最多一题，当前窗口共用并发与等待队列；默认同时运行 2 题，其中 Codex 最多 1 题，最多等待 8 题。切换标签、切换对话、回文档库或收起助手不会停止已提交的回答；「停止」针对当前会话，关闭同一文档的最后一个标签会中止该文档任务并保存历史。队列已满时保留问题和附件，以便重试。

### AI 服务配置

| 服务 | 配置方式 |
| --- | --- |
| DeepSeek、OpenAI API、Claude（Anthropic）、Kimi、智谱 GLM、通义千问 | 选择服务商，填写 API Key，选择或输入模型名称 |
| 自定义接口 | 填写基础 API 地址与模型名称，选择 OpenAI 兼容、OpenAI Responses 或 Anthropic Messages 协议 |
| Codex 本机登录 | 安装并登录本机 Codex，在设置中检查连接并读取模型列表 |

基础 API 地址保留服务所需的路径前缀，例如 `/v1`，不追加 `/chat/completions`、`/responses` 或 `/messages`。自定义接口可连接 OpenRouter、硅基流动、公司网关及本机服务；HTTP 的 localhost、127.0.0.1 或 IPv6 回环地址允许不填密钥。列表外的模型可直接输入名称，截图与检索工具按所选模型的能力使用。

### 框选快捷提问

「设置 → AI → 框选快捷提问」可配置 1–6 个截图旁的提问气泡，默认四个：为什么、详细展开、通俗解释、举个例子。气泡介绍最多 12 个 Unicode 字素，实际提示词最多 16000 个字符。0.4.0 起，空对话里的三个快捷提问按钮已移除。

按 `Alt + Shift + S` 框选 PDF 或 Markdown，选区外虚化并压暗，旁边显示提问气泡。按数字键 `1–6` 或点击发送问题与截图，Markdown 同时带上区域原文；「自己提问」保留选区并打开输入框，`Esc` 或点击选区外取消。快捷气泡使用选区和有限文字历史，不额外附上整页或启用文档检索。

框选快捷模式默认开启，旧版配置升级后也会开启；可在「设置 → AI → 框选快捷提问」关闭。关闭后，是否自动展开助手由「设置 → 阅读」的框选选项决定。缺少配置或队列已满时保留截图供重试，成功提交后收起预览。

## 外观、字体与设置

设置有五页：

| 页面 | 主要内容 |
| --- | --- |
| 外观 | 主题、文档视图、透明度、模糊程度、边缘高光、光线折射、玻璃可读性、六套底板、本机图片图库、界面和阅读字体 |
| 阅读 | PDF 初始缩放、缩放步长、侧栏超宽匹配与框选行为；Markdown 字号及内容宽度 |
| 快捷键 | 录入组合键、禁用操作、冲突检查及恢复默认 |
| AI | 服务、模型、接口、凭据、阅读预算、并发队列、助手形象、空白页问候、猜你想问及框选快捷提问 |
| 更新 | 当前版本、检查更新、自动检查、接收测试版 |

底板提供晨雾、暮光、薄荷、薰衣草、石墨、素白六种预设，也可上传 PNG / JPEG / WebP，图库最多保留六张。选择底板后先预览整个界面，点「采用」保留当前选择，点「不采用」还原；采用后再保存设置。

玻璃透明度、模糊程度和边缘高光均可连续调整。边缘高光默认 50%，100% 对应旧版强度；拖动滑杆时设置遮罩和模糊暂时撤去，可直接查看界面变化。光线折射可单独开关。

「玻璃可读性」提供三种方式：加厚玻璃以保持主题字色、按底图明暗切换字色、关闭补偿。选择「切换字色」时，不同位置的组件可使用不同字色；悬停提示跟随对应控件的字色。加厚模式可调整补偿强度，玻璃底色可跟随主题或取自底图。实色、高对比度与系统减少动效设置有对应回退。

内置 Anthropic Serif 可变字体，默认用于 Markdown 正文和助手回答的西文，中文使用系统黑体回退；PDF 保持原文件排版。外观页可分别选择界面字体和阅读字体，并导入 TTF / OTF / WOFF / WOFF2，最多保留 16 个字体文件，成功保存后可在本机离线使用。字体导入受本机存储大小限制，较大字体可改用已安装的系统字体选项。

助手形象可选小螃蟹、Claude、ChatGPT、DeepSeek，或上传自己的 PNG / JPEG / GIF / WebP。动图可用，图片上限为 2 MB。

## 从源码开发

桌面端使用 Tauri 2、Vue 3 / TypeScript、Rust 和 SQLite；浏览器扩展保留在仓库根目录的 `extension/`，两者分别使用版本号和发布标签。

Windows 开发环境需要 Node.js 22（与 CI 一致）、Rust MSVC（项目最低 1.90）、Microsoft C++ Build Tools / Windows SDK 和 WebView2。本机 Codex 助手使用 Windows 的 .NET Framework 4.x 编译器。

从仓库根目录开始：

```powershell
npm ci
npm run build:host
cd desktop
npm ci
node scripts/prepare-assets.mjs
npm run desktop:dev
```

独立前端预览使用 `npm run dev`。浏览器预览的文档库在 IndexedDB 中；Windows 程序使用本机 SQLite，两个环境不共用数据。Codex 和原生更新功能需要 Windows 桌面版。

本机构建与打包：

```powershell
npm test
cargo test --release --locked --manifest-path src-tauri/Cargo.toml
npm run desktop:build
npm run package:desktop
node scripts/release-assets.mjs --tag desktop-v0.7.1
```

本机测试使用 release 配置可复用正式构建缓存；CI 当前使用默认测试配置。工具不在 PATH 时可使用 `scripts/build-windows.ps1`。本机构建产物在 `release/` 中使用中文名称；`release/github/` 中整理为上方表格的英文附件名。程序运行时可加 `package:desktop -- --staging` 先输出至 `artifacts/package-staging/`。

版本、锁文件、自动标签、测试版和手动发布的完整步骤见[构建与发布说明](docs/RELEASING.md)。

## 阅读器缓存与验证

最近阅读器通常最多保留三个，超过 32 MiB 的文件会减少后台驻留数量。96 MiB 是原始文件数据的缓存目标；当前并排可见的阅读器固定保留，可能超过该目标。实际进程内存还包括 PDF 解析、文字层和位图。

PDF 缩放或侧栏适配时，旧画面保留，新位图在后台准备后整体提交；邻页预绘有像素预算，后台阅读器减少绘制。关闭标签或淘汰缓存会释放阅读器资源，已保存的阅读进度、对话和笔迹仍在本机。

`npm test` 包含设置、队列、搜索、缓存、笔迹与更新选择等检查。`scripts/` 中另有分屏、同书多开、对话、PDF 标记、搜索、设置和玻璃界面的隔离浏览器检查，以及正式程序的原生检查。检查报告和截图写入被 Git 忽略的 `artifacts/`。

各版本的构建记录见 [GitHub Actions](https://github.com/graohene10-spec/pdf-copilot/actions/workflows/desktop-release.yml)。

## 当前边界

支持本地 Windows x64 文档管理与阅读，单文件上限为 PDF 256 MiB、Markdown 16 MiB；扫描 PDF 的正文检索依赖已有文字层。PDF 标记与阅读状态独立保存在本机；正文编辑、标准 PDF 批注写回及带笔迹 PDF 导出尚未提供。第三方主题 / 前端插件执行入口尚未提供。
