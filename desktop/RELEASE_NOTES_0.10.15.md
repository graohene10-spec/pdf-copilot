# 开智 0.10.15

## 背景动画：八个新画面

和原有的流形、神经网络一起轮换（设置 → 外观 → 轮换 里可以单独开关）：

- **DNA 双螺旋**：自己拧着转，上端解旋成两条单链，复制叉上下游走。
- **洛伦兹吸引子**：两条起点只差千分之一的轨道，先重合，后分道扬镳。
- **凯莱图 A₅**：画在截角二十面体上，红点沿两个生成元一步步走，旁边写出走过的字。
- **墨西哥帽势**：小球从帽顶滚进谷底，径向振荡（希格斯模），再沿谷绕圈（戈德斯通模）。
- **Dijkstra 最短路径**：从 s 一圈圈向外确定距离，到 t 后描出最短路径，再换一对起点终点。
- **生命游戏**：环面上的随机汤，沉寂后重新撒一把。
- **分形二叉树**：十级自相似，每一级分叉都绕着母枝转，张角缓缓开合。
- **机柜阵列上的波**：几百个机柜排成格点，水滴落下，起伏一圈圈传开。

每个画面都有自己的一组英文定理 / 定义。之前没改过轮换列表的，升级后自动带上新画面。

## 翻译栏

- 栏拖窄时，清空、关闭按钮和「翻译模式」开关不再被挤出去：标题只留图标，语言可横向滑动，底部一行放不下就换行。
- 更紧凑：卡片的操作按钮不再单占一行（指到卡片上才浮现在右下角），边距、行距收紧，输入框默认一行、随内容变高。
