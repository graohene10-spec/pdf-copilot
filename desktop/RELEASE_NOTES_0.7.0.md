# 开智 0.7.0

## 阅读

- **书签**：每个书签是一枚发光的小玻璃标记，不再用蓝色；命名后，名字和标记在同一块玻璃里，不会错位。深色底上文字自动变成浅色。书签细条往左挪，让开滚动条。上一次跳转还在滚动时，可以继续按 `Ctrl + ↑ / ↓` 接着跳。
- 阅读区下沿不再淡出；上沿只留很窄的一道渐隐。
- 打开或收起侧栏、顶栏、阅读助手时，阅读区每一帧都跟着缩放，不会等动画结束再一下子跳开。适应宽度时拖动助手的宽度，页面直接跟着缩放，松手后才重新渲染一次，不再卡顿。
- 阅读区的搜索框平时不带底色，融进工具条。

## 阅读助手

- 「阅读助手」按钮换成 Claude 菊花图标。
- 弹出时和弹出后外观一致；打开顶栏、侧栏后，文字颜色立刻正确，不会先错一会儿。
- 输入框提示语和空白页问候语换成新的一批；古诗每句以句号收尾。
- 右侧提问导航：
  - 刻度只用黑白两色；每条刻度占满一整格，格与格之间没有点不到的空隙。
  - 点最后一个问题也不会把窗格挤乱。
  - 悬停卡片可以移上去，右上角有钉住按钮；钉住的问题在导航上多一个圆点。
- 对话记录菜单改成实底，后面的文字不再透出来叠在一起。
- 思考时的转动符号有 9 种，每段回答随机用一种。

## 界面

- 悬停提示的文字颜色跟着它所指的控件走：深色底图上控件文字变白，提示也变白。
- 设置里拖动「玻璃透明度」和「模糊程度」时，设置窗的遮罩和模糊全部撤掉，能直接看到效果。
- 换底板时先预览整个界面，底部有「采用 / 不采用」，选「不采用」就退回原来的底板。

安装版与免安装版继续使用原文档库、阅读进度、设置、标记和对话记录；0.3.1 起的版本可在应用内一键升级到本版本。
