# 开智 0.10.5

- **/btw 也显示思考过程**：等回答时和主对话一样，有转动的星标、Thinking… 动词和计时。
- **「添加到对话 / 在侧边对话提问」浮条不再被边框截断**：浮条浮在窗口最上层，太靠近窗口左右边缘时自动往里挪，始终一行。
- **选中文字的底色整齐了**：原来的底色是半透明的，行内代码块或行与行叠住的地方会更深，看起来参差不齐。回答、Markdown 正文、译文里改用不透明的同色底；PDF 文字层盖在页面上，仍用半透明。
- **去掉选中文字后浮出的「问 AI」按钮**：右键菜单里仍有「问阅读助手」。
- **翻译默认用 AI**：已经选过翻译服务的不受影响。用 Codex 翻译时，翻译栏会弹一个小气泡提醒 Codex 较慢，建议换成 DeepSeek、Kimi 等国产大模型；可以「去设置」，也可以点 × 不再提醒。
