# 开智 0.10.75

## 页面崩溃后自动恢复

- 页面进程崩溃或卡死时自动重新载入（10 分钟内最多 3 次），并重新打开刚才的文档，提示「页面刚才出错退出了，已自动恢复」。
- 每次故障在应用数据目录的 render-failures.jsonl 记一行技术信息（类型、原因、退出码、WebView2 版本、出错模块、Graphite 是否开着），不记文档内容。
- 设置 → 更新 → 渲染与排障：可以关掉 Graphite（重启后生效），并能看到最近一次故障。
- 主窗口改为启动时按 Graphite 开关创建。

## 图解

- Intelligent UI 新增十种讲概念用的图：韦恩图、嵌套图、映射图、关系图 / 交换图、推理链、概念树、运算表、轮换图、数轴、象限图。图上文字支持公式，可标出重点；铅笔草稿主题下是手绘线条、红铅笔重点。
- AI 有一份「图解目录」，按概念的结构自己挑图；快速解释的「可视化讲解」优先出图，不再做表单和指标卡片。

## 其他

- 背景图案在任何界面操作时都不暂停。
- 设置窗、确认框弹出时玻璃用轻量模糊。
