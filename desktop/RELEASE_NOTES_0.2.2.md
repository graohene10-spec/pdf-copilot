# 开智 0.2.2

- 更新液态玻璃界面：面板采用同心圆角，按钮、工具栏、搜索框与文件标签使用胶囊形；左侧导航保留较方正的圆角。玻璃边缘加入转向光标的镜面高光与分层阴影。
- 文档分类、标签、视图切换及设置分类使用滑动的玻璃选中态；侧栏和弹窗加入弹簧动效，减少动效设置下关闭位移与缩放。
- 文档库的搜索、统计和视图切换布局更紧凑；设置使用分组列表、开关与细槽透明度滑杆。
- 阅读助手整合输入、清空与发送操作，发送键旁可直接选择模型和思考强度，只更新这两项，保留服务商、接口、密钥及预算设置。
- 新增统一悬停提示，可显示用户当前配置的快捷键；键盘聚焦同样可用。超长自定义提示词限制提示框高度。
- 修复 Codex 快捷模型菜单冷启动列表不完整和刷新后不同步的问题；加载失败可重试，关闭菜单或切换文件会取消过期发现请求。
- 修复实色与高对比度模式下滑动选中高亮错位的问题，保留定位并关闭不适用的视觉动效。

沿用 0.2.1 的全屏、PDF / Markdown 搜索、拖入文件、多标签缓存、自定义快捷提问与可选的框选快捷提问模式。安装版与免安装版继续使用原文档库、阅读进度、主题、设置和已保存凭据。

Windows x64 发布包含安装版、免安装 ZIP、完整源码 ZIP、程序清单和 SHA-256 校验文件。免安装版使用系统 WebView2，Codex 需要本机已安装并登录。

验证：64 项单元测试、前端类型检查、127 组界面回归和 7 组针对性检查通过；正式 Windows 程序另通过 5 组原生设置检查。覆盖深浅主题、实色与高对比度、模型发现与取消、设置、框选提问、全屏搜索及慢速 PDF 重绘。PDF 检查未检测到黑屏、白屏或内容丢失，峰值位图缓存低于 2400 万像素；测试未发送外部 AI 请求，原生检查结束后用户原偏好已逐字恢复。
