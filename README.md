# PDF Copilot · PDF 阅读助手

轻量的 Windows Edge / Chrome 扩展，把 AI 对话放在 PDF 阅读旁边。日常可以继续使用浏览器自带阅读器；需要直接框选、连续滚动和页码引用时，再切换到基于 PDF.js 的增强阅读器。

**当前版本：v0.2.3。** 这是可解压安装的初版，尚未上架浏览器扩展商店。使用 DeepSeek / OpenAI API Key 时只需安装扩展；复用本机 Codex CLI 登录时，再安装随包提供的可选 Windows 小助手。

[下载 v0.2.3](https://github.com/graohene10-spec/pdf-copilot/releases/tag/v0.2.3) · [使用教程](docs/USER_GUIDE.md) · [隐私与权限](PRIVACY.md) · [测试记录](docs/QA_REPORT.md)

## 功能介绍

| 功能 | 浏览器自带 PDF 阅读器 | 增强阅读器 |
|---|---|---|
| 阅读 PDF | 保留 Edge / Chrome 原有界面和功能 | PDF.js 本地渲染，支持选文件和拖入文件 |
| 连续阅读 | 由浏览器提供 | 鼠标滚轮、触控板跨页，按需渲染相邻页 |
| 导航 | 由浏览器提供 | 上/下一页、输入页码、PDF 目录、文档内部链接、个人书签 |
| 缩放与夜间模式 | 由浏览器提供 | 放大、缩小、适合宽度、夜间显示 |
| AI 侧栏 | 扩展图标或快捷键打开 | 顶部“AI 侧栏”按钮或快捷键打开 |
| 临时问答 | 独立小窗口，快捷键召出 | 按钮或快捷键召出，也可作为附件目标 |
| 发送文字 | 复制粘贴；选文右键菜单视浏览器支持情况而定 | 鼠标选文后点击“发送选中文字” |
| 框选图表/公式 | 先截取当前可见标签页，再在截图窗口裁剪 | 点击“框选截图”，直接在 PDF 页内拖动 |
| 页码引用 | 保留来源文件信息 | 附件保留页码；点击引用可回跳并高亮原区域 |

AI 对话还支持：

- **三种连接方式**：DeepSeek API、OpenAI API、Codex 本机登录。API 地址可以自定义，但接口须兼容对应服务的协议。
- **模型与思考强度**：可输入模型 ID；已知模型提供对应强度选项，Codex 从本机接口读取模型与能力。可用模型、额度及图片能力由服务和账户决定。
- **流式回复与状态提示**：发送后立即显示“AI 思考中…”，正文开始返回后显示“正在接收回答…”，支持停止、复制回答和清空当前会话。
- **公式排版**：默认发行版内置 KaTeX 与字体，支持行内和独立公式，无需安装 LaTeX 或其他公式环境，也不从 CDN 加载。
- **附件预览**：文字和截图先加入对话，确认问题后再发送给模型；可以在发送前移除附件。
- **文档会话隔离**：不同文档分别保留有限的内存会话；临时问答与侧栏独立。

## 安装扩展

需要 Windows 和较新的 Edge / Chrome；Manifest 要求 Chromium 132 或更新版本。直接使用发行包无需 Node.js、Python、.NET SDK 或 TeX。Windows 小助手需要 .NET Framework 4.x；Codex CLI 是单独的可选前置条件。

1. 下载并解压推荐的 **pdf-copilot-0.2.3.zip**，放在准备长期保留的文件夹中。
2. 在地址栏打开 `edge://extensions`（Edge）或 `chrome://extensions`（Chrome）。
3. 开启“开发人员模式”，点击“加载解压缩的扩展”。
4. 选择解压后的 **extension 文件夹**，其中应直接包含 `manifest.json`。不要选择 ZIP、完整包的外层目录或源码目录。
5. 在浏览器工具栏的扩展菜单中固定 PDF Copilot 图标，便于打开 AI 侧栏。
6. 点击扩展图标打开侧栏，再点击“设置”。设置页顶部应显示 **v0.2.3**。
7. 如果要对已经在浏览器打开的 `file:///` 本地 PDF 截图，进入扩展“详细信息”，启用 **允许访问文件网址**。在增强阅读器中使用“打开 PDF”文件选择器不需要这项权限。

浏览器会从所选文件夹持续加载扩展，安装后请保留该目录。当前为手动侧载版本，更新时需要重新加载。

### 连接 DeepSeek / OpenAI API

1. 在设置页选择“DeepSeek”或“OpenAI API”。
2. 填写自己的 **API Key**。默认只保留到浏览器关闭；只有勾选“记住密钥”才会写入扩展本地存储。
3. 一般保留默认 API 地址：DeepSeek 为 `https://api.deepseek.com`，OpenAI 为 `https://api.openai.com/v1`。程序会分别追加 `/chat/completions` 或 `/responses`，不要重复填写完整接口路径。
4. 选择或输入账户可调用的模型 ID，再选择支持的思考强度。截图需要支持图片输入的模型。
5. 点击“保存设置”，按浏览器提示允许访问所选 API 网站，然后返回对话。
6. 先发送一句简单问题确认连接，再添加 PDF 选文或截图。

聊天顶部也可以切换服务、模型和思考强度。切换服务前，应先在设置中为对应服务保存密钥。自定义 API 地址需要 HTTPS；本机 localhost / 127.0.0.1 / ::1 服务允许 HTTP。第三方代理须兼容该服务的流式接口，插件不自动适配任意聊天接口。

模型预设只是便捷选项，不保证账户有权使用。API Key 模式使用相应 API 服务，不会自动复用浏览器里的 ChatGPT 登录。

### 连接 Codex 本机登录（可选）

仅使用 API Key 的用户可以跳过本节。小助手通过浏览器 Native Messaging 调用本机 Codex，不需要后台服务或本地网络端口。

1. 安装或更新 **Windows 原生 Codex CLI**，按 [官方 CLI 安装说明](https://learn.chatgpt.com/docs/codex/cli) 选择 Windows 方式。本版小助手验证的最低兼容版本为 **0.159.2**。
2. 使用同一 Windows 用户，在终端确认版本并登录。登录由 Codex 自己处理，参见 [官方认证说明](https://learn.chatgpt.com/docs/auth)：

~~~powershell
codex --version
codex login
~~~

3. 完成扩展安装后，双击完整包中的 **windows-helper/install.cmd**。安装只登记当前 Windows 用户，通常不需要管理员权限。
4. 在扩展设置中选择“Codex 本机登录”，点击 **检查连接并读取模型**。
5. 确认“版本兼容”和“登录状态”，选择读取到的模型与思考强度，保存设置。

设置页会显示小助手实际调用的 CLI **路径、版本、兼容性和登录状态**。如果电脑装了多份 Codex，终端找到的程序可能与助手登记的程序不同。更新后可以重新运行安装程序；安装器会检查候选程序并选择满足要求的最新版本。

明确显示“未登录”时，使用设置页显示的那个可执行文件执行 `login`。版本不兼容时，登录状态尚未检查，不表示账号退出登录。桌面应用已有会话，也不保证另一份 CLI 使用相同认证配置；助手不会读取或复制桌面应用内部令牌。

发行包侧载 ID 固定为 `henkklpcghcjfjplgpmfdjihldalhknd`。如果自行更改开发公钥，或未来使用不同商店 ID，请在设置页复制实际 ID，并从完整包目录运行以下命令，替换引号内的 ID：

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\windows-helper\scripts\install-host.ps1 -ExtensionId '实际的32位扩展ID'
~~~

需要指定 CLI 时，在上述命令后追加 `-CodexPath 'C:\实际路径\codex.exe'`；必须是 Windows 原生 EXE，不能是 `.cmd` 启动脚本或 WSL 程序。单独下载助手 ZIP 时，脚本位于解压目录的 `scripts` 下。

更多安装参数和诊断见 [Windows 小助手说明](docs/WINDOWS_HELPER.md) 与 [兼容性说明](docs/COMPATIBILITY.md)。小助手目前没有代码签名。

## 使用教程

### 1. 在浏览器自带阅读器旁提问

1. 正常在 Edge / Chrome 打开 PDF。
2. 点击扩展图标，或按侧栏快捷键，打开 AI 侧栏。
3. 复制 PDF 文字并粘贴到输入框。浏览器支持时，也可以选中文字后右键发送给 PDF Copilot。
4. 需要图片时，点击侧栏的 **截图框选**，或使用截图快捷键。插件会截取当前可见标签页，在单独窗口中让你拖动选择区域。
5. 确认截图预览，将选区加入对话，输入例如“解释这里的公式”或“总结这张图”，点击 **发送**。

截图只覆盖当前可见画面；先滚动和缩放到需要的位置。使用快捷键时，先让 PDF 标签页处于前台。部分浏览器内置 PDF 页不提供扩展选文右键菜单，可以直接复制粘贴。

### 2. 使用增强阅读器

1. 在 PDF 标签页按增强阅读器快捷键，或在侧栏点击 **增强阅读器**。
2. 在线 PDF 首次打开时，点击“允许读取并打开 PDF”，只授权相应网站。本地 PDF 可在阅读页点击 **打开 PDF**，也可拖入文件。
3. 鼠标停在中间的 **PDF 阅读区域**，上下滚动即可跨页。顶部支持上/下一页、输入页码并确认、缩放；点击缩放百分比恢复适合宽度。
4. 左侧列出文档已有的目录。点击顶部 ☆ 收藏当前页；再次点击可移除，保存的页码在“我的书签”中显示。
5. 点击 **夜间** 切换 PDF 显示；侧栏主题可在设置中选择日间、夜间或跟随系统。

PDF 内没有目录时，插件不会自动生成目录。加密 PDF 会询问密码，可以重试或取消。在线文件依赖登录、一次性地址或 POST 下载时，重新读取可能失败，下载后用文件选择器打开即可。

### 3. 发送选中文字或框选区域

**文字：** 在增强阅读器中拖动选择文本，底部“发送选中文字”变为可用；选择“发送到：侧栏 / 临时对话”，点击按钮。文字先成为待发送附件。

**截图：**

1. 点击底部 **框选截图**，进入框选模式。
2. 在同一 PDF 页内按住鼠标左键拖动，松开后出现预览；正向和反向拖动均可。页面仍在渲染时，会等待完成再显示预览。
3. 点击 **发送到对话**，将图片加入所选对话；或者点击“取消”后重新框选。
4. 在对话中检查附件，输入问题，点击 **发送**。加入附件本身不会向模型发送请求。

再次点击“框选截图”或按 Escape 可以退出框选模式。请在单页范围内选择，跨页区域请分别截图。缩放、跳页或切换文档会取消尚未完成的旧选区。夜间模式截图仍保持 PDF 原色。增强模式附件中的页码按钮可以回到来源页，并高亮对应区域。

### 4. 临时问答、等待和公式

- 使用临时问答快捷键，或点击“临时问答 / 临时对话”按钮，打开独立窗口。关闭窗口后释放该临时会话。
- 输入问题后点击“发送”，或按 **Ctrl + Enter**。等待期间显示“AI 思考中…”，收到正文后显示“正在接收回答…”；点击“停止”可中止当前请求，已收到的内容保留。
- “清空”清除当前文档对话和附件。“复制”复制回答原文，包括公式源文本。
- 默认版在回复完成或停止后排版 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 公式。代码块和行内代码不解析为公式；不支持或不完整的公式保留原文。
- 极简版始终显示公式原文。当前尚未提供完整 Markdown 排版、OCR、全文搜索、整本文档索引或知识库。

## 快捷键设置

| 操作 | 建议默认组合 |
|---|---|
| 打开 AI 侧栏 | Ctrl + Shift + 7 |
| 打开临时问答 | Alt + Shift + Q |
| 截图后框选 | Alt + Shift + S |
| 打开增强阅读器 | Ctrl + Shift + 8 |

实际组合以扩展设置页为准，浏览器会保留手动修改的键位。未设置或冲突时：

1. 点击扩展设置里的 **设置浏览器快捷键**，或在地址栏输入 `edge://extensions/shortcuts` / `chrome://extensions/shortcuts`。
2. 找到 **PDF Copilot · 阅读助手**，为“打开 AI 侧栏”等具体操作点击编辑并按所需组合。
3. 回到扩展设置，点击 **重新检查**。

浏览器里的“激活扩展”是扩展图标操作，侧栏快捷键应设置在 **打开 AI 侧栏** 这一行。扩展不能强行覆盖系统、浏览器或其他扩展占用的组合。

## 数据保存与轻量化

PDF 在浏览器本地解析，不会自动整本上传。只有点击对话的“发送”后，问题、已选附件和有限会话历史才会交给你选择的模型服务。

截图在内存中裁剪和交接，插件不创建本地 PNG 文件、不写持久图片数据库；`chrome.storage.session` 中的待取附件会在消费或过期后清理。聊天也不提供持久历史。系统交换文件、崩溃转储、浏览器自身行为及服务商处理政策不属于“绝不落盘”的保证范围。

API Key 默认放在会话存储中；“记住密钥”使用扩展本地存储，**不是加密凭据保险库**。设置中可以忘记当前服务的密钥。个人书签只保存文档指纹和页码。Codex 凭据由 Codex 管理，小助手使用受限临时线程，不导出令牌、不写图片和提示日志。

运行时没有前端框架、模型 SDK、开发者后台、统计 SDK 或常驻服务。PDF.js 与 KaTeX 固定版本并随包提供。为控制资源使用：

- 增强阅读器最多保留 3 个页面画布，合计约 1600 万像素；本地文件上限 256 MiB。
- 最多保留最近 5 个文档会话；待发送附件最多 8 个。
- 单张图片 data URL 不超过 4 MiB，图片总量不超过 8 MiB；Codex 一次最多 4 张图片。过大截图在内存中缩小。
- 历史消息、公式数量和公式长度均设有上限，超限公式显示原文。

权限在实际操作时使用或申请：`activeTab` 用于当前页截图，`sidePanel` 用于侧栏，`storage` 用于设置和附件，`contextMenus` 用于菜单，`nativeMessaging` 用于可选 Codex 连接。API / 在线 PDF 按网站申请访问；没有在所有网页运行的内容脚本。详情见 [隐私与权限](PRIVACY.md)。

## 更新、卸载与常见问题

**更新：** 下载新完整包，把新 `extension` 的内容覆盖到原来加载的目录，在扩展管理页点击“重新加载”，关闭并重新打开旧阅读器、侧栏和设置页，再确认版本。保持加载目录和扩展 ID 可保留设置与书签。只构建或解压新包，不会自动更新浏览器已经加载的旧目录。[详细更新说明](docs/UPDATING.md)

**卸载：** 在浏览器扩展管理页移除 PDF Copilot；需要时运行 `windows-helper/uninstall.cmd` 移除小助手。助手卸载不会删除 Codex 登录，也不会卸载 Codex。

| 现象 | 检查方法 |
|---|---|
| 安装提示找不到 manifest | 选择直接包含 manifest.json 的 extension 目录 |
| 还是旧版 / 更新后行为没有变化 | 确认真正加载的路径，重新加载扩展并重开旧页面 |
| 快捷键无反应或显示“未设置” | 在浏览器快捷键页手动分配，检查是否冲突及 PDF 是否在前台 |
| 本地 PDF 截图失败 | 在扩展详情启用“允许访问文件网址”；也可改用增强阅读器选文件 |
| 滚轮没有跨页 | 在增强阅读器中把鼠标移到中间 PDF 阅读区，确认正在运行 v0.2.3 |
| 拖动没有截图预览 | 先点击“框选截图”，在 PDF 单页内拖动；页面未就绪时等待渲染 |
| 在线 PDF 无法读取 | 检查网站授权；下载后使用“打开 PDF”，尤其是一次性或登录下载地址 |
| 模型拒绝截图 / 参数 | 选择支持图片的模型或移除截图，确认模型 ID 与思考强度可用 |
| Codex 版本错误 | 查看设置中的实际 CLI 路径，更新该程序并重新安装助手 |
| Codex 连接正常但未登录 | 用同一 Windows 用户及显示的可执行文件运行 login，再检查 |
| 公式一直显示原文 | 确认安装默认版；等待回复结束；检查公式分隔符和支持的语法 |

## 从源码构建

开发机需要 **Node.js 22+**；编译 Windows 助手需要 .NET Framework 4.x 编译器，不需要 .NET SDK 或 NuGet。首次安装依赖需要网络。源码和 GitHub 自动源码归档均不含构建产物：

~~~powershell
npm ci --ignore-scripts
npm run build
npm run build:lite
npm run build:host
npm run check
npm run check:lite
npm test
npm run package
~~~

加载 `dist/extension`（自带公式）或 `dist/extension-lite`（极简）。发行文件位于 `release/0.2.3`。浏览器验收：

~~~powershell
npm install --no-save --package-lock=false playwright
$env:PDF_COPILOT_PLAYWRIGHT_PATH = (Join-Path (Get-Location) 'node_modules\playwright')
node scripts/browser-smoke.mjs
npm run test:acceptance
npm run test:upgrade
~~~

Playwright 仅用于开发验收，不进入发行包。脚本使用本机 Edge、隔离浏览器目录与本机模拟服务；Edge 不在默认位置时，可设置 `PDF_COPILOT_EDGE_PATH`。加密 PDF 验收还需要 Python 和 pycryptodome：先用 `tests/fixtures/encrypted.py` 生成样本，再将 `PDF_COPILOT_ENCRYPTED_FIXTURE` 设为该文件的绝对路径。可选 `scripts/native-inference-smoke.mjs` 会调用真实 Codex、使用少量账户额度，不属于默认测试。

~~~text
extension/       浏览器后台、阅读器、对话、设置与服务适配
native-host/     可选 Windows Native Messaging 小助手
scripts/         构建、安装、打包与浏览器验收
tests/           单元测试与合成 PDF 样本生成器
docs/            使用、架构、兼容性、隐私及测试说明
~~~
