# 开智 0.10.102

## 管理对话

- 入口两个：右键顶栏的「阅读助手」→「管理对话…」；点助手上沿的对话标题，小菜单里「新对话」旁边的「管理」。
- 一棵树：每本书是根，下面是它的对话，对话下面是这段对话记下的记忆。
- 左键直接进入那本书 / 那段对话；右键选中并弹出操作；按住拖动是框选，Ctrl / Shift + 左键加选，Ctrl + A 全选，Delete 删除。
- 操作：打开、重命名、记不记入记忆、移到另一本书（可以一次移多段）、删除（先确认）。
- 书从文档库移除后，对话和记忆都留着，树上还有它，根节点压一层斜纹阴影并标「已移除」。可以把它的对话移到别的书名下。

## 记忆

- 记的是你学过什么：每段对话整理出几行「哪个概念、掌握得怎样」。答完后过一会儿、或者你离开这段对话时，由小模型整理。
- 新对话的欢迎页上有一枚「这段对话记入记忆」，默认开，点一下关掉。之后也可以在管理界面里改。
- 删除对话时，它记下的记忆一起删掉；管理界面里可以单独忘掉某一条。
- 提问时这些记录会带给阅读助手，只用来判断讲解的起点和深浅。提示词里写明：不要因为有记录就去回顾、联系旧知识，不要说「你之前学过」，除非你自己问起或者当前问题直接建立在某一条上。
- 快速解释、自由提问、翻译不读也不写记忆。
