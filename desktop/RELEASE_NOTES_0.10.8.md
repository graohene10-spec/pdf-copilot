# 开智 0.10.8

## 新液态玻璃
「设置 → 外观 → 界面风格」多了一套**新液态玻璃**，原版液态玻璃保留不动，两套随时切换。布局完全一样，换的是材质：

- 底板光斑更饱和（六套底板预设都有对应的新配色，深色主题也有）。
- 玻璃更薄更清，边缘的镜面高光更亮，下沿带一点冷色回光。
- 悬浮投影带一点蓝，面板和按钮的圆角更大。
- 弹窗和菜单比面板更厚，压得住身后的内容。
- 文档库里鼠标移到书卡上，会有一道高光从左到右扫过。
- 透明度、模糊、边缘高光、折射、底板、背景图这些玻璃设置照常生效；系统开启「减少透明度 / 提高对比度」时退回实色。

## 细节与动画
- 换界面风格时整屏柔和地淡入淡出，不再一下子跳变。
- 铅笔草稿：阅读助手的标题框在纸上左右居中，回形针别在标题框的左上沿（原来别在纸边、框偏右）。
