# 开智 0.8.0

- **界面风格**：设置 → 外观最上方新增「界面风格」，与液态玻璃并列的两套新外观，浅色、深色都有：
  - **暖色极简**：象牙白底，侧栏、顶栏、阅读助手平铺贴满窗口，只用细线分隔；文件标签像文件夹页签；标题、助手的回答用 Anthropic Serif，强调色只有陶土橙。动效只做缓入缓出，不回弹。
  - **铅笔草稿**：方格纸桌面上摆着歪放的纸——侧栏贴着胶带，文件标签是纸片索引，阅读助手是别着回形针的横线本、问题写在便利贴上、输入框用蓝胶带贴在下面；按钮与输入框是铅笔描的框，选中项用斜线排线。界面文字是手写的龙藏体。纸片落下、便利贴贴上、标题一笔写出等动效。
- **回答字体可选**：铅笔草稿下 AI 回答默认用马善政楷书（好认，仍有手写味），也可在设置里换成站酷小薇体、站酷快乐体、龙藏体、系统楷体，或跟随阅读字体。
- 新风格下界面文字都不会折成两行；玻璃透明度、底板等设置只在液态玻璃下显示。PDF 与 Markdown 正文不受风格影响。
- 手写字体均为 SIL OFL 开源字体，裁成常用字后随应用内置，不联网。

0.3.1 起的版本可在应用内一键升级到本版本。
