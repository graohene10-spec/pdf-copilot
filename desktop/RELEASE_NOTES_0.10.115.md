# 开智 0.10.115

## 滚动条

- 滑块有了最短长度：阅读区 72px，其他地方 36px。几百页的文档里不再缩成一小点。
- 阅读区的竖滚动条占 14px 宽，平时只画中间 4px 的细条，指上去或拖动时变成 8px。
- 系统开了「提高对比度」时，滑块用正文色，阅读区的滑块一直显示。

## 阅读器

- Markdown 长文档滚动：算「现在读到第几行」原来每个滚动事件都从第一块量到当前块，现在用二分查找，并且一帧只算一次。
- PDF 全文搜索和目录页码解析：原来每页（每 40 条）都用一次定时器让出主线程，每次至少等 4 毫秒；现在攒够 50 毫秒才让一次，用 `scheduler.yield()`，长书搜索更快。
- 排版：Markdown 和助手回答的标题几行尽量一样长，段落最后一行不落单。
- Markdown 里的网络图片改为异步解码。
