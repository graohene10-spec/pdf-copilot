# PDF Copilot 使用教程

适用于 v0.2.3。完整的功能、安装、模型连接、快捷键、更新与排障说明见 [README](../README.md)。首次使用建议下载 Release 的 **pdf-copilot-0.2.3.zip**，而不是 GitHub 自动生成的源码归档。

## 第一次使用：用一段文字确认连接

1. 在浏览器扩展管理页打开开发人员模式，加载解压后的 **extension** 文件夹。
2. 固定 PDF Copilot 图标，点击它打开侧栏，再点“设置”。
3. 选择服务商。API 模式填写密钥、模型和思考强度，保存并允许访问 API 地址；Codex 模式先安装可选 Windows 小助手，再检查连接和读取模型。
4. 返回侧栏，输入“请用一句话介绍你能如何帮助阅读 PDF”，发送。
5. 检查是否先出现“AI 思考中…”，随后收到回答。没有回答时，先根据页面错误检查配置。

默认不记住 API Key；关闭浏览器后需要重新填写。开启“记住密钥”前，请确认是可信的个人电脑。

## 在浏览器自带阅读器中使用

打开 PDF 后点击扩展图标，或使用设置页显示的实际快捷键。文字可复制到侧栏；浏览器支持扩展选文菜单时，也可选中文字后右键发送。

对于公式、图表或扫描内容：

1. 先把目标区域滚动到屏幕上，按需放大。
2. 点击侧栏“截图框选”，或按截图快捷键。
3. 在截图窗口内拖出矩形，检查预览并确认添加。
4. 在对话里确认附件，输入问题后发送。

本地 file:// PDF 截图需在扩展详情启用“允许访问文件网址”。原生截图截取当前可见标签页，不会解析整本 PDF，也不能跨屏一次截取整个页面。

## 在增强阅读器中使用

从侧栏点击“增强阅读器”，或在 PDF 标签页使用增强阅读器快捷键。在线文件首次需要授权网站读取；本地文件可以点击“打开 PDF”或直接拖入。

鼠标在中间阅读区时滚轮可连续跨页。顶部可输入页码、上一页/下一页、缩放、恢复适合宽度、添加书签和切换夜间；左侧可跳目录或个人书签。没有内置目录的 PDF 不会自动生成目录。

![合成 PDF 的增强阅读界面](images/reader.png)

### 文字与截图

- **文字**：在 PDF 页内选中文字，底部选择“发送到：侧栏 / 临时对话”，点击“发送选中文字”。
- **图片**：先点“框选截图”，再在一页内按住左键拖动。松开后检查预览，点“发送到对话”。
- **重试**：预览中点“取消”，可以重新框选；按 Escape 或再次点击“框选截图”退出模式。
- **等待**：页画布未完成时会等待渲染。缩放、导航、切换文档或新的框选会取消旧等待。
- **引用**：增强阅读器附件中的页码按钮可回跳到来源页并高亮。夜间显示不改变截图原色。

加入附件不等于发送给模型；对话中可以移除误选附件，再输入问题并发送。跨页内容请分别截图。

## 对话与公式

对话顶部可改服务、模型和思考强度。输入框按 Ctrl + Enter 发送；“停止”中止当前请求，“清空”清除当前文档会话。临时问答窗口有独立会话，关闭后释放。

![合成附件与本机模拟回复](images/chat.png)

可以尝试：

- “用中文解释这段内容，先列出用到的定义。”
- “图中横轴和纵轴分别表示什么？只依据这张截图回答。”
- “解释这个公式各个符号的含义，并给出推导中需要的假设。”

模型只看到你发送的内容，不会自动知道前后章节。需要补充上下文时，选择相关文字或其他截图再次发送。

默认版在回答结束或停止后排版 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 公式，无需安装额外环境。复制按钮保留原文。极简版公式显示原文，不完整或不支持的语法也会保持原文。

## 快捷键找不到或无反应

设置页显示浏览器实际启用的快捷键。点击“设置浏览器快捷键”，或者在地址栏打开：

- Edge：`edge://extensions/shortcuts`
- Chrome：`chrome://extensions/shortcuts`

找到“PDF Copilot · 阅读助手”，修改“打开 AI 侧栏”等具体操作；“激活扩展”是另外一行。返回设置页点击“重新检查”。冲突的组合需手动更换。

建议默认组合为侧栏 Ctrl + Shift + 7、增强阅读器 Ctrl + Shift + 8、临时问答 Alt + Shift + Q、截图 Alt + Shift + S；已经自定义过的键位由浏览器保留。

## 更新与卸载

更新请看 [更新说明](UPDATING.md)。关键是更新实际加载的 extension 目录、点击重新加载、关闭并重开旧页面，最后确认设置页为 v0.2.3。

扩展可从浏览器管理页移除；Codex 小助手用随包 uninstall.cmd 卸载，不会删除 Codex 认证。更多问题见 [README 排障表](../README.md#更新卸载与常见问题)、[小助手说明](WINDOWS_HELPER.md)、[兼容性说明](COMPATIBILITY.md) 和 [隐私说明](../PRIVACY.md)。
