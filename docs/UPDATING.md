# 更新已加载的扩展

源码构建或解压新安装包，不会自动更新 Edge / Chrome 已登记的加载目录。首先在扩展详情中确认“加载自”路径；设置页顶部显示当前运行版本。

0.2.3 修复五处问题：带链接的页面改用当前 PDF.js 支持的坐标转换接口，避免页初始化失败；页面仍在渲染时保留框选，完成后显示预览；翻页后保留框选模式提示；取消文字选择后立即禁用“发送选中文字”；取消加密文档密码输入后正确显示取消提示。退出框选、切换文档、缩放或再次框选会取消旧的等待预览。

1. 将新安装包 `extension` 文件夹的内容复制到原加载目录，或把本项目 `dist/extension` 作为新的加载目录。保持相同开发公钥和扩展 ID，可保留设置与书签。
2. 打开 `edge://extensions` 或 `chrome://extensions`，在 PDF Copilot 卡片上点击“重新加载”。
3. 关闭旧的增强阅读器和设置页，重新打开。设置页顶部应显示 **v0.2.3**；增强阅读器底部应显示“连续滚动”。旧的已打开页面不会自动换成新的代码。
4. 设置页显示的是浏览器实际注册的快捷键。侧栏默认 **Ctrl + Shift + 7**，增强阅读器默认 **Ctrl + Shift + 8**；如果显示“未设置”，点击“设置浏览器快捷键”手动分配，然后返回“重新检查”。用户手动修改过的普通命令组合由浏览器保留。

0.2.2 修复侧栏快捷键：此前使用浏览器保留的 `_execute_action`，该命令的描述会被忽略，在 Edge 中显示成“激活扩展”，Alt+Shift+A 在本机与隔离配置均未成功注册。新版本改为普通 `open-sidebar` 命令，浏览器快捷键页明确显示“打开 AI 侧栏”，建议键为 Ctrl+Shift+7。命令收到按键事件后立即打开相应窗口的侧栏，保留用户操作状态。

Edge 的设置位置是 `edge://extensions/shortcuts`（Chrome 为 `chrome://extensions/shortcuts`）。找到“PDF Copilot · 阅读助手”，在“打开 AI 侧栏”右侧点击编辑按钮并按所需组合。扩展设置中的“设置浏览器快捷键”按钮也会打开此页。

0.2.1 将增强阅读器的建议组合从 Alt + Shift + R 改为 Ctrl + Shift + 8，并使用快捷键事件携带的标签页打开 PDF；无法注册的快捷键会明确提示。扩展通过浏览器的 Commands API 接收快捷键，不往浏览器内置 PDF 页面注入脚本。浏览器或系统保留的组合仍可能无法使用，扩展不能自动覆盖这些按键。

增强模式采用连续页布局，鼠标停在 PDF 阅读区域内即可向下滚动跨页、向上滚动回到前页；无需先点“下一页”。最多保留当前页及相邻页的三个画布。

扩展可能仍从旧版本的解压目录加载，即使你已经下载或构建了新版本。请以浏览器实际加载路径和设置页版本为准。

快捷键注册与冲突处理依据：[Chrome 官方 Commands API 文档](https://developer.chrome.com/docs/extensions/reference/api/commands)。
