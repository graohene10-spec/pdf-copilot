# 开智 0.10.103

## 管理对话重做

- 现在是单独一整页，不再是一个小窗口。左上角「返回」或 Esc 回到阅读。
- 树从左往右长：书在左，右边是它的对话，再右边是这段对话记下的记忆（点对话上的记忆图标展开）。
- 选中后可以直接拖：把对话拖到另一本书上就是移动。拖的是选中的之一，整批一起走；拖一本书，是把它的全部对话移走。目标书不在树上时，拖到底部的「树上没有的书…」再挑。
- 在空白处点一下取消选中；空白处按住拖动是框选。左键进入、右键选中并弹出操作不变。

## 记忆

- 提示词放宽：可以联系读者学过的东西，条件是两者有实质关系（是当前问题的前提、同一个思想的另一种形式、上次卡住的正是这里），而且提一句能讲得更清楚。只是沾边（同一领域、同一个词、勉强的类比）不提。

## 其他

- 有功能用着本机 Codex 时，打开应用会自己检查登录并读取模型名单，不用再去设置里点。没连上会提示一次。打开设置时如果还没查过，也会自动查。
- 教程「截图提问」：补上关闭「框选快捷提问」后右键一拖、图直接进输入框这一步；整课放慢。
- 侧栏书签：页数紧跟书签图标，名称在页数右边，各行左对齐。
