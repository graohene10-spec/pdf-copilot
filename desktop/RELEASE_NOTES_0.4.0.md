# 开智 0.4.0

## 阅读助手

- 空白对话只留助手形象和一句问候：按当地时间随机的英文问候（Fancy a cup of tea? / The moon is beautiful, isn’t it? / Good morning…）或与时辰、读书相合的古诗（附出处），固定使用内置的 Anthropic Serif。「设置 → AI → 空白页问候」可选英文问候、中文古诗、两者，或每行一句的自定义问候。原来的「关于《……》，直接提问……」说明和三个快捷提问按钮已移除。
- 输入框空着时显示一句随机的学术格言或典故（如「我来，我见，我征服。」「大胆假设，小心求证。」）。
- 问题预判：有上下文时，小模型（DeepSeek Flash、GPT-5.4 Mini，或 Codex 当前模型的最低思考强度）读一下当前页、选区和最近对话，把最可能的下一个问题淡淡地写在输入框里，按 Tab 或回车采用，Esc 收起。可在设置中关闭；发送内容见隐私说明。
- 思考时显示 Claude Code 式的转动星标、随机英文动词（Thinking… / Pondering… / Deciphering…）和用时，答完显示「Thought for 4.0s」；不再显示 token 计数。
- 模型与思考强度卡片精简为一张更通透的小玻璃卡：去掉说明文字和闪电按钮，强度滑杆改成细槽液态玻璃，拖动时滑块变成透明的玻璃透镜；字体、圆角与按钮和应用其他弹层一致。
- 「文档上下文」芯片加入一枚小开关：开为实心、关为空心描边，浅色底图上也一眼可辨。

## PDF

- 放大后页面超出阅读区时，底部出现可拖动的玻璃横向滚动条；滚动范围覆盖整页（含左右留白），缩放、开关侧栏或调整窗口后自动更新。
- 深色模式重做：文字与线条按色调曲线反相，底色是深灰而不是纯黑，正文是柔白；浅灰细线、淡底色不再糊成一片。彩色图片和照片保留原色，只略微压暗；扫描页仍按文字处理，深底浅字。

## 主题与玻璃

- 修复自定义图片底板下切换深浅主题后，部分组件呈浅色、部分呈深色的问题。现在每块玻璃都使用当前主题的文字颜色；底图太亮或太暗时只把那块玻璃加厚，不再换成另一主题的字色。连续切换、重新打开助手或重启后样式一致。
- 修复深色主题下打开设置后整个窗口变暗、以及打开 PDF 时窗口底色被染色的问题（几处样式选择器误作用到了根元素）。

安装版与免安装版继续使用原文档库、阅读进度、主题、设置、对话记录和已保存凭据；0.3.1 起的版本可在应用内一键升级到本版本。

Windows x64 发布包含安装版、免安装 ZIP、完整源码 ZIP、程序清单和 SHA-256 校验文件。
