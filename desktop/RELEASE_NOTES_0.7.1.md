# 开智 0.7.1

- **打开 / 关闭阅读助手和左侧侧栏时不再卡一下、瞬移**：PDF 每一帧都和面板宽度同步缩放，位置一直对齐，动画结束时不再横向跳。侧栏收起时以前会停在 26 像素宽、最后一下子消失，现在顺滑收到 0。
- **书签标记在白色页面上也看得清**：改成白色磨砂玻璃、深色芯、深色细边加一圈白色光晕，白纸、深色页面和深色底图上都清楚。
- **提问导航**：鼠标放到刻度上，刻度不再消失，也不再出现白色方框。
- **玻璃边缘高光**：默认强度减半；在「设置 → 外观 → 边缘高光」可以从 0 到 100% 自由调整（100% 是以前的强度），拖动时界面实时预览。

0.3.1 起的版本可在应用内一键升级到本版本。
