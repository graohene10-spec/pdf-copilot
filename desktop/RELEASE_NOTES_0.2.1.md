# 开智 0.2.1

- 新增可选的框选快捷提问模式，在「设置 → AI → 快捷提问」开启。框选后保持 PDF 尺寸、压暗选区外区域，在选框旁显示自定义快捷问题与「继续」；快捷发送沿用并发队列并保留草稿，继续则带截图打开助手。默认关闭，缺少连接或队列已满保留截图，Esc 可取消。

- 「设置 → AI」加入快捷提问配置，可分别编辑三个按钮的介绍和发送提示词。介绍限制 12 字，支持中文输入法与组合字符；提示词不能为空，支持单项和整组恢复默认。保存后更新侧栏，点击直接发送并保留草稿与多文件并发规则。单独修改快捷提问不重写未修改的 AI 服务配置。
- 完成 Apple Liquid Glass 和四个开源项目的文字对比度研究，供后续组件文字优化参考；本轮保持原玻璃视觉与字体补偿算法。

- 新增全屏模式，顶部按钮和 F11 可切换，退出后恢复原窗口状态。Esc 优先关闭弹窗 / 框选，再退出全屏。
- PDF / Markdown 阅读工具栏加入统一玻璃搜索框，Ctrl + F 聚焦，支持跨页匹配、上下结果、高亮、清除与各标签独立搜索状态。PDF 按页扫描可取消；Markdown 阅读与源码模式都支持。
- 阅读区较窄时工具栏压缩间距与文字标签，保留操作图标；极窄时搜索框单独占一行。
- 全屏与文档内搜索快捷键可在设置中更改、禁用或恢复。已有设置自动补入新默认键。

- Codex 模型采用完整下拉列表，首次打开自动读取本机可用模型，并同步支持的思考强度。
- 修复深色原生菜单文字不清晰的问题，选项使用明确的明暗配色。
- 默认缩放改为 Ctrl + 鼠标滚轮，设置支持录入、禁用与恢复滚轮组合；保留自定义键盘快捷键。
- “梳理核心观点”“解释概念与公式”“查找假设与局限”点击即发送，保留已有草稿，继续使用同一并发队列与附件校验。
- 最近三个阅读器可直接复用；后台 PDF 停止预绘并只保留当前页，关闭标签释放缓存。较大文件自动减少驻留阅读器数量。
- 支持拖入多个 PDF / Markdown 文件加入文档库，重复文件不建立重复标签。源文件修改后重新加入会使旧缓存失效。
- 修复玻璃文字在深浅主题往返后未恢复，以及旧底板解码结果覆盖当前颜色的问题。
- 活动 PDF 渲染窗口从三页扩大为五页，当前页优先绘制，保持原有单页清晰度与侧栏原子重绘。

文档库、阅读进度、主题、AI 配置和凭据沿用原数据目录。

阅读器最多保留 96 MiB 原始文件数据；存在超过 32 MiB 的文件时最多两个阅读器，活动文件超过 96 MiB 时只保留它。活动 PDF 的五页位图与一个重绘缓冲合计不超过 2400 万像素。文件数据预算不包含 PDF 解析、文字层和位图等进程内存。

框选快捷模式验证：64 项 JavaScript 测试、类型检查、8 组新模式、10 组原附件及 17 组设置检查通过。真实鼠标框选、DPR 1.5 下遮罩对齐、快速双击、草稿与图片快照、继续、取消、窗口变化、多文件排队、队列满重试及缺少配置返回均覆盖；全部图片提问使用本机模拟服务，无外部 AI 请求。
