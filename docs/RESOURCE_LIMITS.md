# 调整 PDF 资源限制

本功能从 **v0.3.3** 提供。从 v0.3.2 升级时，按[更新说明](UPDATING.md)覆盖原加载目录并重新加载扩展；Codex 用户同时运行本版小助手的 `windows-helper/install.cmd`。

## 操作步骤

1. 点击浏览器工具栏的 PDF Copilot 图标，打开侧栏。
2. 在顶部点 **⋯ → 模型与密钥设置**。
3. 展开 **PDF 资源限制**。这里默认收起，避免影响日常模型配置。
4. 在下面范围内填写上限。默认每题允许 5 次页图，包括直接提问时自动附上的当前页。
5. 点击页面底部 **保存设置**，看到“已保存”后返回 PDF。
6. 从下一次发送问题开始使用新限制；正在回答的问题沿用发送时的限制。无需重开阅读器或对话窗口。

点 **恢复默认限制** 会填回默认数值，再点 **保存设置** 才生效。偏好只保存到本地，不保存 PDF 内容或图片。

| 设置 | 默认 | 可调范围 | 如何计算 |
|---|---:|---:|---|
| 页图次数 / 每题 | 5 | 1–10 | 一次完整页图或局部页图算一次；自动当前页计入，手动截图附件不计入 |
| 证据页数 / 每题 | 8 | 1–40 | 文字、搜索片段及自动页图共用不同 PDF 页的总数；同一页重复读取不增加页数 |
| 证据文字 / 每题 | 24,000 | 1,000–120,000 字符 | 附近种子、搜索片段和读页正文累计；问题、元数据、图片本身不按正文字符计算 |
| PDF 读取次数 / 每题 | 12 | 1–60 | 查目录、搜索、读页和查看页图累计；自动当前页使用一次；无效/超限工具尝试也会占用读取次数 |
| API 检索轮次 / 每题 | 3 | 1–8 | OpenAI / DeepSeek 工具模式的补充阅读轮次，之后用已有证据回答；Codex 工具模式由读取次数约束 |
| 搜索扫描页数 / 每次 | 120 | 10–500 | 每次搜索最多扫描的页数，包含优先检索的附近页；已有索引仍可复用 |
| 搜索时间 / 每次 | 10 秒 | 1–30 秒 | 每次搜索的扫描时间预算；超过预算停止继续扫描并报告覆盖范围 |

## 选用数值

- 一般教材解读：保留默认值。直接提问附一张当前页，AI 还可按需查看最多四次其他页或局部。
- 需要核对更多图表：例如页图设 7、证据页数设 16、读取次数设 24。三个上限分别起作用，证据页数或读取次数太低时，仍可能先达到另一项上限。
- 更重视速度/用量：降低页图和读取次数，例如页图 2、读取 6。正文少时可下调字符数。实际使用多少由问题与模型决定，并非每题自动用完上限。
- 搜索长教材：指定章节、公式编号或页码范围优先于盲目调高扫描量。超出一次扫描范围时，模型可在剩余读取预算内续查。

限制控制的是本机向模型提供材料的过程，不改变模型自身的最大上下文、输出长度或账户额度。调高可能增加等待、内存和 API/Codex 用量。单图尺寸、请求体、附件、索引缓存、阅读画布和超时仍有固定边界，不能设置无限读取；增强页图继续在内存生成，不主动保存图片文件。

## 常见问题

- **看不到设置项：** 核对实际加载目录，更新扩展文件后在浏览器扩展管理页重新加载，关闭旧设置页再打开。
- **Codex 提示小助手不支持自定义资源限制：** 运行本版的 `windows-helper/install.cmd`（从源码可运行 `scripts/install-host.ps1`），关闭旧对话再重试。旧助手会明确提示升级，不会静默忽略配置。
- **改到 5 次，但只拿到 2 张图：** 上限是允许量；模型可能无需更多图片。还应核对读取次数、证据页数、模型图片能力和传输大小。自动当前页已占一次。
- **途中改设置没影响当前回答：** 这是预期行为。每题锁定一份资源预算，防止回答中途突然扩大或缩小读取范围。
