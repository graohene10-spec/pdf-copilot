# 开智 0.7.3

## 阅读助手
- **回答更像人话**：系统提示词精简成两句，只要求自然、直接地说人话，可以自由用自己的知识解释，不再反复强调「原文」「根据材料」。默认快捷提问里「引用原文」的要求也去掉了（你没改过的旧默认提示词会自动换成新说法，自己写的不动）。
- **输入框可以附图片**：点输入栏左下角的「添加图片」，或复制图片后在输入框按 `Ctrl + V` 粘贴；一次最多 4 张，随问题一起发出，和框选截图可以同时带上。

## 框选提问
- **松手就弹出提问卡片**：不再等截图编码完；截图在后台生成，好了自动补上。
- **按 Esc 只收起卡片，截图保留**：之后打开阅读助手自己提问，截图还在输入框上方。

0.3.1 起的版本可在应用内一键升级到本版本。
