# PDF Copilot v0.3.3 安装与使用教程

本教程从下载开始，按顺序完成即可安装并进行第一次 PDF 提问。使用 API Key 和使用 Codex 是两条可选路线，选择一条即可。

[下载本版](https://github.com/graohene10-spec/pdf-copilot/releases/tag/v0.3.3) · [功能介绍](../README.md) · [隐私说明](../PRIVACY.md)

## 1. 下载正确的安装包

1. 打开上面的下载页，找到 **Assets**。如果附件列表收起，点击展开。
2. 下载 **pdf-copilot-0.3.3.zip**。这是推荐完整包，包含扩展、公式字体、可选 Windows 小助手和本文档。
3. 在 Windows 文件资源管理器中右键该 ZIP，选择 **全部解压**。例如解压到 `C:\Tools\PDF-Copilot`，这个目录应长期保留。
4. 打开解压后的目录，确认能看到以下结构：

~~~text
extension/
  manifest.json
  background.js
  reader/
  chat/
  vendor/
windows-helper/
  install.cmd
  uninstall.cmd
  PdfCopilotHost.exe
  scripts/
docs/
README.md
~~~

**成功标志：** `extension` 中直接有 `manifest.json`，`windows-helper` 中有 `install.cmd`。

不要选择 GitHub 自动生成的 **Source code (zip/tar.gz)**，它需要自行构建。若只下载了 `pdf-copilot-extension-0.3.3.zip`，解压目录本身直接包含 `manifest.json`，后续加载这个目录即可。极简版的安装步骤相同，但公式显示原文；新用户建议用默认完整包。

## 2. 在 Edge / Chrome 加载扩展

需要基于 Chromium 132 或更新版本的 Edge / Chrome。浏览器太旧时，先在浏览器“帮助 / 关于”中更新。普通发行包不需要安装编程工具或 LaTeX。

1. 打开浏览器，在地址栏输入 `edge://extensions`（Edge）或 `chrome://extensions`（Chrome），按回车。
2. 开启页面中的 **开发人员模式**，不要进入 Windows 系统的开发者设置。
3. 点击 **加载解压缩的扩展**。Chrome 的按钮也可能叫“加载已解压的扩展程序”。
4. 在文件夹选择窗口中，选中上一步解压的 **extension 文件夹**，点击选择文件夹。完整包示例为 `C:\Tools\PDF-Copilot\extension`。
5. 确认管理页出现 **PDF Copilot · 阅读助手**，且开关处于启用状态。
6. 点击浏览器工具栏的扩展菜单，找到 PDF Copilot，固定/显示到工具栏。
7. 点击工具栏上的 PDF Copilot 图标，右侧应打开对话栏。点顶部 **⋯ → 模型与密钥设置**。

**成功标志：** 设置页顶部显示 **v0.3.3**。若没有插件卡片，或提示找不到 manifest，请返回第 4 步，选择直接包含 `manifest.json` 的目录。

浏览器持续从所选目录加载插件，安装后不要删除或移动它。企业管理的浏览器可能限制开发人员模式或侧载；此时需由管理员允许安装。

## 3. 连接模型：选择 A 或 B

### 方式 A：DeepSeek / OpenAI API Key

有自己的 API Key 时使用这条路线，**不需要安装 Windows 小助手或 Codex CLI**。

1. 在对应的 [DeepSeek API 平台](https://platform.deepseek.com/) 或 [OpenAI API 平台](https://platform.openai.com/)准备可用的 API Key，并确认账户可调用所选模型。
2. 回到插件设置，在 **服务商** 中选择 **DeepSeek** 或 **OpenAI API**。
3. 在 **API Key** 中粘贴密钥。密钥不应填入模型框、问题输入框或 GitHub。
4. 保留对应的 **API 地址**：

| 服务商 | 填写的基础地址 |
|---|---|
| DeepSeek | `https://api.deepseek.com` |
| OpenAI API | `https://api.openai.com/v1` |

5. 在 **模型** 中选择账户可用的预设，或直接输入模型 ID。预设只是便捷选项，不保证账户权限。直接发送页图和截图需要支持图片的模型；文字模型可在增强模式读取 PDF 文字。
6. 选择该模型支持的 **思考强度**。不确定时可使用模型默认；具体选项随模型能力变化。
7. 默认不要勾选“记住密钥”，密钥只保留到浏览器关闭。在可信个人电脑上希望重启后保留时，可勾选；该功能使用扩展本地存储，不是加密凭据保险库。
8. 点击 **保存设置**。浏览器若弹出网站访问请求，允许插件访问刚填写的 API 网站。
9. 返回侧栏，进行下文的 **第一次连接测试**。

**成功标志：** 设置页显示保存成功，对话顶部的模型摘要与所选服务/模型一致。

不要把 `/responses`、`/chat/completions` 拼到基础地址后面，插件会自动追加接口路径。自定义代理需兼容相应协议；远程地址必须 HTTPS，本机 localhost / 127.0.0.1 / ::1 可以 HTTP。切换服务前，应先在设置中为该服务保存密钥。

ChatGPT 网页登录与 API Key 是不同连接方式；选择 OpenAI API 时仍需 API Key。

### 方式 B：Codex 本机登录

这条路线使用 Windows 原生 Codex CLI 自己管理的登录。已有 CLI 的用户也要确认它的版本和实际登录状态；仅打开 Codex 桌面应用不能替代检查。

**B1. 安装或更新 Windows CLI**

1. 在 Windows 开始菜单搜索 **PowerShell**，打开普通 PowerShell 窗口，无需以管理员身份打开。
2. 按[官方 Codex CLI 安装说明](https://learn.chatgpt.com/docs/codex/cli)选择 Windows 安装方式。官方提供独立 Windows 安装脚本；可在 PowerShell 运行：

~~~powershell
irm https://chatgpt.com/codex/install.ps1 | iex
~~~

脚本来源和安装位置说明见[官方安装器文档](https://learn.chatgpt.com/docs/config-file/environment-variables#installer-variables)。已有 Node.js 的用户也可按官方说明用 npm 安装 Windows CLI；仅安装本插件无需 Node.js。

3. 安装结束后关闭这个 PowerShell 窗口，再打开一个新窗口，使新程序路径生效。
4. 输入以下命令检查版本并完成登录：

~~~powershell
codex --version
codex login
~~~

需要 **0.159.2 或更新版本**。按照打开的登录页面完成认证；使用同一 Windows 用户即可。认证流程见[官方认证说明](https://learn.chatgpt.com/docs/auth)。不要把认证文件或登录令牌复制到插件目录。

**B2. 安装小助手**

1. 回到解压的完整包，打开 **windows-helper**。
2. 双击 **install.cmd**，等待安装结束，查看窗口中的结果。它只为当前 Windows 用户安装并登记 Edge / Chrome，通常不需要管理员权限；它不会代替你登录 Codex。
3. 若 Windows 提示文件来自网络或程序未签名，先确认文件来自本项目 Release；发行包附有 SHA256SUMS.txt 可核对。受管理电脑请按组织规则处理，小助手目前没有代码签名。
4. 回到插件设置，将 **服务商** 改为 **Codex 本机登录**。
5. 点击 **检查连接并读取模型**，等待检查完成。
6. 核对 **版本兼容：符合要求**、**登录状态：已登录**；设置页同时显示实际调用的 CLI 路径和版本。
7. 在读取到的模型中选择一个，选择思考强度，点击 **保存设置**。Codex 模式不需要填写 API Key。

**成功标志：** 登录状态已确认，模型列表可选择，对话顶部显示 Codex 和所选模型。

如果电脑装了多份 CLI，以设置页 **实际程序** 为准。明确显示未登录时，在 PowerShell 用该路径执行登录，例如 `& 'C:\实际路径\codex.exe' login`。版本过低时更新 CLI 后重新运行 `install.cmd`；“登录尚未确认”表示检查未完成，不能据此判断已退出登录。完整动态 PDF 工具往返已在 CLI 0.160.0 验证；协议不兼容时会尝试有预算限制的兼容检索模式。

需要指定 CLI 或不同扩展 ID 时，见[小助手安装参数](WINDOWS_HELPER.md)，不要手动导出账号令牌。

### 第一次连接测试

1. 打开侧栏。若看到 **自动上下文** 开关，可先取消勾选，只测试文字连接；也可以在浏览器空白新标签页打开侧栏。
2. 输入“请用一句话介绍你能如何帮助阅读 PDF”，点击 **发送 ↑**。
3. 应先看到等待提示，再收到正文，底部显示 **回答完成。**
4. 如果报错，先按本文末尾的排障表解决模型连接，再测试 PDF。测试成功后，打开 PDF 时重新勾选 **自动上下文**。

## 4. 推荐的第一次阅读：增强模式

这条路径最适合开始使用：直接选择本地文件，不需要配置文件网址权限。

1. 在侧栏顶部点 **⋯ → 增强阅读器**，浏览器会打开一个新的阅读标签页。
2. 点左上角 **打开 PDF**，在文件选择窗口中选中教材/论文并打开。也可以把 PDF 从文件资源管理器拖到阅读区。
3. 等待顶部出现文件名和总页数，中间出现正文。鼠标放在中间阅读区，滚轮或触控板可以连续跨页。
4. 顶部可输入物理 PDF 页码并按回车，或点击上一页/下一页。左侧可点文档目录；没有内置目录的 PDF 不会自动生成目录。
5. 顶部 − / ＋ 调整缩放，点击百分比恢复适合宽度。☆ 收藏当前页，左侧“我的书签”可跳转或删除。点击 **夜间** 切换显示。
6. 点顶部 **AI 侧栏**，确认输入框下方 **自动上下文** 已勾选。
7. 不添加截图，直接问：“解释当前页的主要内容，列出符号与假设。”点击 **发送 ↑**。
8. 插件准备当前 PDF 页。图片模型收到完整当前页图；不支持图片的模型读取当前页文字。页图在消息中显示 **已附 · 当前 PDF 第 N 页**，点击可展开预览。
9. 增强模式下 AI 可以按需搜索术语/公式编号、读取相关段落或核对页图。等待提示会显示正在准备页面、搜索或读取。
10. 回答下方展开 **参考原文**，检查实际提供过的文字。点击原文引用可回跳来源；文档页标签与物理 PDF 页序分别显示，例如“页标签 1 · PDF 第 2 页”。

![增强阅读器示例，使用合成 PDF](images/reader.png)

**成功标志：** 直接提问时提供当前页，翻到另一页后再次直接提问会提供新页。历史问题的图片不会自动重发。

可尝试：“式 (6.23) 用到了哪些前面的定义和近似？请结合上下文解释并给出页码。”长教材最好指定章节、关键词或页码范围。索引在本机，整份文件不自动上传；搜索有覆盖与预算上限，没有文字层的扫描页无法全文文字搜索，可用图片模型查看该页。复杂公式/双栏排版提取不完整时，应以页图为准。

## 5. 精确提供一个公式、段落或图表

已有手动附件时，本次使用这些附件，不重复自动附整页；增强模式仍可补充附件附近与相关页的上下文。

**发送段落：**

1. 在增强阅读页用鼠标选中文字。
2. 在底部 **发送到** 选择 **侧栏** 或 **临时对话**，点击 **发送选文**。
3. 对话中出现文字附件，输入问题后发送。附件加入对话时尚未上传，可以点 × 移除。

**框选公式或图表：**

1. 把目标区域滚动到可见位置，按需缩放。
2. 点底部 **框选截图**，确认进入框选模式。
3. 在同一 PDF 页内按住鼠标左键，拖出矩形后松开。
4. 检查预览，点击 **发送到对话**；在对话中确认附件，输入问题再点击 **发送 ↑**。
5. 误选时在预览点 **取消** 重新选；按 Escape 或再点“框选截图”退出模式。跨页内容请分开选。

画布未完成时会先等待渲染。缩放、换文档或再次框选会取消过期的等待预览。夜间只是显示滤镜，发送的增强模式页图/选区保持原色。

## 6. 继续使用浏览器自带 PDF 阅读器

1. 像平常一样在 Edge / Chrome 打开 PDF，停在要问的地方。
2. 若是地址栏以 `file:///` 开头的本地 PDF，先到扩展管理页 → PDF Copilot **详细信息**，启用 **允许访问文件网址**。
3. 返回 PDF 标签页，点击工具栏的插件图标打开侧栏。需要取得当前标签页的临时授权时，请从 PDF 标签页点击图标或使用插件快捷键。
4. 保持 **自动上下文** 勾选，输入问题，点击 **发送 ↑**。插件附的是当前标签页的**可见区域**，不会获取整本 PDF，也不会一次截取屏幕外的整页。
5. 只想解释局部公式时，点侧栏 **＋ 截图**，或在 PDF 标签页按 **Alt + Shift + S**。在截图窗口拖出矩形、确认预览、加入对话，再输入问题发送。
6. 文字可以复制粘贴到对话；浏览器支持扩展选文菜单时，也可右键发送选文。原生 PDF 的右键菜单支持取决于浏览器。

原生模式自动提供可见区域需要图片模型。文字模型可改用增强阅读器获取文字，或关闭自动上下文并手动粘贴。原生模式没有增强模式的本机 PDF 全文检索和准确页码回跳。

若想切入增强模式，在该 PDF 标签页用 **Ctrl + Shift + 8**，或侧栏 **⋯ → 增强阅读器**。在线文件首次点击允许读取，授权相应网站；本地 `file:///` 还要在新阅读页点 **授权本地文件读取并打开 PDF**。网址开关和读取授权是两项条件。失败时直接在阅读页点“打开 PDF”重新选文件即可。

## 7. 对话、字号、公式与快捷键

在 **模型与密钥设置 → PDF 资源限制** 可调整自动页图数量及读取预算，默认每题 5 次页图；展开后修改数值，点击 **保存设置**，从下一题生效。点 **恢复默认限制** 后也需保存。升级到本版时，Codex 用户需同时更新小助手。各项范围和示例见[资源限制教程](RESOURCE_LIMITS.md)。

- 点击对话顶部的模型摘要，展开服务、模型和思考强度，再次点击收起。切换服务前先保存对应密钥。
- 顶部 **A− / A+** 调整回复字号，范围 14–24，默认 17；点击中间数字恢复默认。字号在侧栏与临时窗口同步，代码和公式一起缩放。
- 输入框中按 **Ctrl + Enter** 发送。点 **停止** 中止本题读取/接收，部分回答不作为后续回答的上下文。
- 点 **⋯ → 清空会话** 清除当前文档会话；不同文档分别保留有限内存会话。临时窗口与侧栏会话独立，关闭临时窗口后释放。
- **自动上下文** 可随时关闭并保存选择。关闭时只发送问题、手动附件与有限文字历史；开启时按输入区提示提供当前页或相关内容。点击发送才会上传，翻页本身不会上传。
- 默认版在回答结束/停止后排版公式，无需安装 LaTeX。极简版、未完成或不支持的公式显示原文；复制按钮保留原始内容。

![对话示例，使用合成材料与本机模拟回复](images/chat.png)

| 操作 | 建议默认组合 |
|---|---|
| 打开 AI 侧栏 | Ctrl + Shift + 7 |
| 打开增强阅读器 | Ctrl + Shift + 8 |
| 临时问答 | Alt + Shift + Q |
| 截图并框选 | Alt + Shift + S |

如果没有反应，到插件 **模型与密钥设置 → 设置浏览器快捷键**，或在地址栏打开 `edge://extensions/shortcuts` / `chrome://extensions/shortcuts`。找到 PDF Copilot 下对应的操作，点击编辑框，按新的组合。回到插件设置点 **重新检查**，确认不再显示“未设置”。“激活扩展”是浏览器的另一项操作；优先配置明确的“打开 AI 侧栏”。已自定义键位由浏览器保留，插件不能覆盖冲突组合。

## 8. 更新和卸载

从上一发行版更新时：

1. 下载本版完整包并解压，关闭旧侧栏、临时窗口、阅读器和设置页。
2. 在扩展管理页确认原来的加载路径，把新 **extension 的内容**覆盖到该目录，保留目录位置。无需移除原扩展，以保留设置和书签。
3. 在扩展卡片点 **重新加载**。若改用新目录，确保只启用一个 PDF Copilot；两版使用同一扩展 ID。
4. **Codex 用户运行本版 windows-helper/install.cmd 更新助手**；API Key 用户跳过。
5. 重开设置确认 **v0.3.3**，再打开 PDF。确认 **自动上下文** 已开启；主动关闭的选择会被保留。

卸载时在浏览器扩展管理页移除插件。需要卸载小助手时运行 **windows-helper/uninstall.cmd**，它不会卸载 Codex 或删除其登录。详细见[更新说明](UPDATING.md)。

## 常见问题：按提示排查

| 问题 / 提示 | 按顺序处理 |
|---|---|
| 找不到 manifest，或缺 PDF.js 资源 | 下载完整安装包并全部解压；选择直接含 manifest.json 的 extension，不选源码归档 |
| 设置不是 v0.3.3 / 界面没更新 | 核对实际加载目录，覆盖新文件，点重新加载，关闭并重开旧页面 |
| API Key 未配置或关闭浏览器后失效 | 在相应服务的设置页重新填 Key 并保存；希望保存时再勾选“记住密钥” |
| API HTTP 错误或模型不存在 | 检查 Key、账户模型权限/额度、基础地址及代理协议；不要在地址末尾重复加接口路径 |
| 原生模式无法读取当前可见页 | 返回 PDF 标签页点击扩展图标或快捷键重新调用；本地文件开启“允许访问文件网址”；仍失败改用增强阅读器选文件 |
| 本地 URL Unexpected server response (0) | 开启文件网址开关，再点“授权本地文件读取并打开 PDF”；确认文件未移动/删除，或直接用“打开 PDF”选文件 |
| 在线 PDF 打不开 | 允许该网站读取；需要登录时先在浏览器登录；一次性下载链接失败时下载后本地打开 |
| 当前模型不支持图片 | 切换图片模型；增强模式可读文字页。扫描页无文字层时必须提供图片或手动文字 |
| Codex CLI not found / 版本太低 | 安装或更新 Windows 原生 CLI，关闭重开终端确认版本，再运行小助手 install.cmd |
| 浏览器未找到小助手 | 确认已全部解压并运行 install.cmd；关闭重开设置，再检查连接 |
| 小助手不允许当前扩展 ID | 在设置中复制实际 ID，按小助手说明用 -ExtensionId 重新登记 |
| CLI 符合要求但未登录 | 使用设置页显示的那个程序、同一 Windows 用户执行 login，再检查；“尚未确认”先看诊断详情 |
| 拖动没预览 | 先点框选截图，在单页内拖动；等待该页渲染。取消后重试，勿在缩放/换页途中继续旧选区 |
| 滚轮没跨页 | 把鼠标移到增强阅读器中间 PDF 区域，确认重新加载并重开旧页 |
| 公式显示源码 | 确认使用默认完整包，等待回答完成；极简版或不支持的语法会保留原文 |
| 快捷键未设置 / 无反应 | 在浏览器扩展快捷键页分配无冲突组合，返回 PDF 再测试 |

更多连接参数见[Windows 小助手说明](WINDOWS_HELPER.md)和[兼容性说明](COMPATIBILITY.md)。图片、对话及检索缓存的保存范围见[隐私与权限](../PRIVACY.md)。
