# 开智 0.10.148

- 新增学习对话：在阅读助手里点「学习这一段」，助手先出两道题摸底，再给出大纲，然后一步步带读，每一步链回原文。有速通、复习、深度理解三种学法。
- 大纲栏：可放在助手栏左侧或屏幕最左，可拖宽；节点可以右键标「快讲 / 细讲」、拖动换次序、删除。
- 左侧栏新增「学习进度」，列出所有学习对话；文档库卡片上多一条学习进度。通过检查的要点记在「设置 → 记忆」里那本书下面。
- 教程新增「学习」「大纲与进度」两段，原有各段的文案和动画也核对修补了一遍。
- 自动压缩的默认大小改为 200 千 tokens，并且不超过所用模型窗口的六成（已保存过设置的不受影响）。上下文圆环的提示改短。
- 附属对话展开时主栏和正文不再逐帧重排。
- 用 Codex 时会显示思考摘要，长时间思考不再毫无动静。
- 左侧栏原来的 Intelligent UI 入口换成了「学习进度」。
