# 开智 0.5.1

## Markdown

- **框选提问**：Markdown 也能框选了。拖出一块区域，助手同时拿到这块区域的截图和其中的原文；公式附带 LaTeX 源码，表格按行列读取。和 PDF 一样可以直接在选区旁快速提问。
- **手写标记**：钢笔、荧光笔、划线、橡皮，用法和快捷键（`Alt + 1/2/3`）都和 PDF 一样。笔迹挂在各自的段落上，改字号、缩放或窗口变宽时跟着段落走，重启后保留。「清除全部标记」可撤销。
- **整页缩放**：`Ctrl + 滚轮`、`Ctrl + = / -` 和工具栏的 − / ＋ 现在放大整个文档（文字、公式、图片、表格、版心宽度一起），以光标所在位置为中心；点百分比恢复 100%。字号仍可在「设置 → Markdown」里调。

## 文档库

- **排序**：可按加入时间、阅读时间、文件名称、文件大小、文件类别排序，再选一次或点箭头切换升降序；「默认排列」仍是最近阅读或自己拖好的顺序。
- 左上角的卡片 / 列表视图切换在深色背景上改用和其他文字一样的浅色。

## 其他

- `Ctrl + B` 开关侧栏不再一卡一卡：动画期间暂停生成玻璃折射贴图，停下后再按最终尺寸生成一次。
- 新应用图标：黑底白色的打开的书与一颗星火。

安装版与免安装版继续使用原文档库、阅读进度、设置、标记和对话记录；0.3.1 起的版本可在应用内一键升级到本版本。
