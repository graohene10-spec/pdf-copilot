# 开智 0.10.78

## Intelligent UI 合集

- 文档库统计行右边新增「Intelligent UI」入口：PDF 里钉住的、Markdown 里记入文档的解释，只要带界面都收在这里，按书归组。
- 每个界面照样能操作；点页码 / 行号跳回原处。
- 单击标题选中（Ctrl / Shift 多选），在空白处按住左键拖出框也能选，Delete 删除；删除时文档里对应的卡片 / 释义一起删掉。

## 快速解释

- 「思考了 N 秒」改成卡片底部按钮行右边的一枚小签「✻ Ns」，点开看思考过程。
- 卡片和 Markdown 释义的右键菜单：复制、深入 / 简化 / 举例 / 用图解释、钉住、切换图层、关闭 / 删除，不再弹出浏览器自带的菜单。
- Markdown 的解释纸片可以拖右下角调整大小，记入文档时一起存下，双击恢复。
- 钉住卡片后，没用过「跟着书页走 / 停在屏幕上」的切换时会提示一次（一共两次）。
- 用图解释的卡片初始更宽；修复图解刚出来时文字重叠、放大后才正常的问题。

## 思考状态

- 模型给了思考简述（Codex、OpenAI 的推理摘要）就显示简述的小标题，替代「Thinking…」；助手栏和快速解释都是。
- 正在生成界面时显示「正在生成 Intelligent UI…」。
