# 开智桌面版隐私说明

本文适用于开智 Windows 桌面版 0.7.1。浏览器扩展的行为见[扩展隐私与权限](../../PRIVACY.md)。

## 本机文档与设置

加入文档库时，开智记录原文件路径、名称、大小、阅读位置、标签和收藏等信息，不移动或改写原 PDF / Markdown 文件。Markdown 正文及已读取的 PDF 文字可建立本机搜索索引。原文件移动或删除后，文档库中的记录并不替代原文件。

桌面文档库位于 Windows 当前用户的应用数据目录，使用 `com.phydog.reading/library.sqlite3` 保存记录、搜索索引和普通设置。安装版与免安装版均使用应用数据目录；免安装 ZIP 中的程序文件夹不是一份完整的用户数据备份。

外观、快捷键、框选快捷提问、问候语、底板图库、助手形象和压缩后的书目封面保存在本机设置中；导入字体的字节也保存在本机文档库。切换外观、预览底板和生成文档封面在本机进行。内置字体随应用提供，用户导入的字体保留在本机。

PDF 与 Markdown 的书签按文档保存在本机文档库，包括名称、阅读位置和创建时间；同一本书的副本共用。PDF 记录页码和页内位置，Markdown 记录整篇阅读比例。

## 对话历史与图片

桌面版会保存对话历史，关闭标签或重启软件后仍可重新打开。保存内容包括问题、回答、模型返回的思考内容、原文引用与摘录、用于追问的所选文字，以及会话标题、时间和分支关系。每份文档最多保存最近 40 个非空对话，每段对话最多保存 60 条消息，消息正文、思考内容和引用摘录有长度限制。

对话记录写入本机文档库的普通设置表，不使用 API 密钥的 DPAPI 加密方式。能够访问此 Windows 用户文件的程序或人员，可能读取这些记录。

截图、页面图像、尚未发送的选区和草稿保存在运行内存中。发送后，截图、所选文字及文档页码显示在对应问题下方，输入区的选区预览清除。当前运行中的图像可用于重答；重启后保留文字历史，图片附件不随历史恢复。钉住问题的状态随文字对话保存。

切换文件标签或关闭助手栏不会自动停止正在回答的问题。关闭某文档的最后一个同书标签会中止其请求、保存文字历史并释放该文档的会话内存；再次打开仍可加载已保存历史。加密 PDF 的打开密码仅在同书标签打开期间保存在内存。

## PDF 与 Markdown 手写标记

钢笔、荧光笔和划线等标记独立保存在本机文档库，PDF 按页定位，Markdown 按段落定位，同书副本共用。原 PDF / Markdown 文件保持不变，迁移笔迹需同时备份文档库。撤销记录只在当前运行期间保留，当前版本不提供带笔迹 PDF 导出。

## 使用 AI 时发送什么

打开文档、翻页、选取文字或完成框选本身不会发送 AI 请求，唯一的例外是下文的「猜你想问」。点击发送、框选快捷提问气泡，或按对应发送快捷键时，开智向用户选择的服务商与 API 地址发起请求。问题、被选为附件的文字或截图、有限的文字对话历史，以及此前引用的部分原文摘录可能随请求发送。

开启输入框的“文档上下文”后，开智还提供文档名称、当前阅读位置和受预算约束的上下文，模型可按需搜索或读取文档片段与页面图像。阅读 PDF 时，所选模型支持图片且没有手动附件，就会自动提供当前页图像；不支持图片时使用文字能力。文件解析、文字索引和原文件留在本机，模型收到本次请求及工具调用选出的文字和图像，应用不会直接把整份 PDF 文件作为附件上传。一次对话可能通过多次工具调用读取不同片段，范围受设置中的资源预算约束。

框选后点击快捷问题时，会发送该问题、选区截图和有限文字历史。Markdown 还提供区域内原文，公式保留 LaTeX 源码，表格按行列提取；快捷问题不额外附整页或启用文档检索。“自己提问”将选区带到阅读助手，继续编辑后发送。清除本机截图不撤回服务商已经接收的数据。

**猜你想问**默认开启：输入框为空，且有文字选区或已有有效文字对话时，开智向当前服务商发起推荐请求。空白新对话与单独截图不触发推荐。请求包含文档名称、页码、所选文字（最多 800 字）和最近四条有效文字消息（每条最多 500 字）；开启文档上下文时，再附当前阅读位置约 1800 字原文。关闭文档上下文时，推荐只使用选区和对话等信息。

DeepSeek 使用 Flash，OpenAI 使用 GPT-5.4 Mini，Claude 使用 Haiku 低思考强度；GLM 使用当前模型并关闭思考，Kimi、通义千问和自定义接口使用当前模型，Codex 使用当前模型支持的最低思考强度。成功的推荐按上下文缓存在运行内存中，每次请求消耗模型额度。可在「设置 → AI → 猜你想问」关闭并保存，清除建议、取消进行中的推荐请求，并停止后续推荐；重启后保留该选择。

API 服务商、用户自定义 API 地址，以及通过 Codex 连接的模型服务，分别按各自的账户和数据政策处理收到的内容。应用中删除历史或中止请求，不等于删除服务商已有记录。

## 密钥与普通配置

普通 AI 配置（服务商、API 地址、模型、接口协议、思考强度和资源限制）保存在桌面 WebView 的本机存储中，不包含 API 密钥。支持 DeepSeek、OpenAI、Claude、Kimi、GLM、通义千问、自定义接口和本机 Codex；自定义接口将请求发送到用户填写的地址，包括本机 HTTP 服务。

API 密钥默认供当前运行使用。开启“记住密钥”后，桌面版以 Windows DPAPI 加密并保存到应用数据目录的 `credentials/`，绑定当前 Windows 用户；关闭记住选项并保存可移除对应服务商的已存密钥。自定义接口也使用这一保存方式，换电脑或 Windows 账户时需重新配置。

复用 Codex 登录时，认证由 Codex 自己管理，开智不读取或导出其登录令牌；本机小助手负责连接。向模型发送的问题与文档资料仍会经过所选模型服务。

## 其他网络连接

“设置 → 更新”中的自动检查默认开启，也可关闭。检查访问本项目 GitHub Releases API，下载时访问 GitHub 及其附件分发域名；检查请求使用带应用版本的 User-Agent，不附带文档、对话或密钥。下载包保存在系统临时目录；应用优先使用 GitHub 接口中的附件 SHA-256 摘要，接口未提供摘要时读取 `SHA256SUMS.txt`，校验通过后安装或替换程序文件。

Markdown 中的 HTTP / HTTPS 远程图片会按文档内容从对应网站加载，链接也可由用户打开；目标网站因此可以看到相应网络请求。阅读器会为远程图片设置不发送来源页地址，但这不能隐藏网络地址。文档目录中的相对图片由本机读取，不需要上传到开发者服务器。

## 删除与保留范围

- 在“对话记录”中删除某段对话，会中止该会话的请求并从本机保存的对话列表中移除。关闭标签、关闭助手栏或退出软件只结束当前界面或运行，不等同于删除已保存历史。
- “从文档库移除”会移除文档记录、阅读进度、标签和搜索索引，保留原文件。独立保存在设置表中的对话、笔迹、书签与封面数据也会保留。需要删除对话时，应先在对话记录中分别删除。
- 底板图库、助手形象和自定义字体可以在相应设置中更换或移除。删除本机记录不会撤回已发送给服务商的内容，也不保证清除系统备份、交换文件或已产生的崩溃转储中的副本。
