# 开智 0.10.106

## 管理对话

- 顺序定住了：书和对话按你排的顺序放，移动一段对话不会让目标书跳到最前。
- 可以在一本书里拖动对话排序；拖到别的书时也能选落在第几个。拖动时一道红线标出会落在哪。
- 展开、收起、移动、删除时，其余节点滑到新位置，不再突然跳。
- Ctrl + Z 撤销：移动、排序、删除、重命名、记不记入记忆、忘掉一条记忆都能退回去。左上角有「撤销」按钮，每次操作后左下角也有一条带「撤销」的提示。
- 鼠标停在一段对话上，旁边显示它最后一轮的问和答。
- 右侧一栏列出现在记着的全部内容，按书分组；点一条会定位到它来自的那段对话，也可以在这里忘掉某一条。
- 以前的对话还没整理过记忆：右栏有一个「整理 N 段还没整理的对话」按钮，点了才会整理。
- 样子换成构成主义：红、黑、纸色，直角和斜线，右栏顶部一幅构成。

## 书签

- 按住书页上的小书签（长按，或按着拖开）可以挪位置。竖向挪到哪儿，它标记的就是哪儿。
- 靠近书页右边会吸上去；靠近左边也会吸上去并且掉头，燕尾朝左。这也是给书签掉头的办法。
- 两边都不靠时，停在松手的地方，页面内外都可以。
