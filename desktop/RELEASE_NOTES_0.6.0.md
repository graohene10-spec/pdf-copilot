# 开智 0.6.0

## AI 接口

- 新增 **Claude（Anthropic）**、**Kimi（月之暗面）**、**智谱 GLM**、**通义千问**，在「设置 → AI」里选服务商、填 API Key 即可。Claude 走官方 Messages 接口，支持看图、PDF 检索工具和思考强度。
- 新增 **自定义接口**：填 API 地址、模型名称，再选协议——OpenAI 兼容（/chat/completions）、OpenAI Responses 或 Anthropic Messages。OpenRouter、硅基流动、公司网关都能接；本机的 Ollama、LM Studio 可以不填密钥。
- 列表里没有的新模型，可以直接在「模型」里填名称。

## 阅读

- **书签**：按 `Alt + B` 在当前位置加一个书签，阅读区右侧细条上出现一枚浅色小标记。左键点击跳过去；`Ctrl + ↑ / ↓` 跳到当前位置之前 / 之后最近的书签；右键可以命名或删除，命名后标记旁边显示文字。PDF 和 Markdown 都能用，在阅读区右键也能「在这里加书签」。快捷键可在设置里改。
- 阅读区上下边缘改成渐渐淡出，不再一刀截断。
- 并排阅读时页面上方那排「· · ·」拖动把手去掉了，不再占阅读空间；拖动位置改用工具条空白处。
- Markdown 和助手回答里，`**粗体**` 紧挨中文标点时也能正确加粗；行内代码折行时，每一段都画完整的底色，不再在页边被截断。

## 工作区

- 顶栏右侧的「收起顶栏与侧栏」在普通窗口里也能用了；收起后左上角的小标签和阅读工具条一样高、顶边对齐。
- 打开或关闭阅读助手时，助手的宽度像侧栏一样弹簧收放，左边的阅读区每一帧跟着让位，不再最后一下子跳开。
- `Ctrl + B` 和助手开关动画期间暂停玻璃折射与可读性重算，停下后再统一更新，动画更顺。
- 文档库的排序选项换成液态玻璃菜单，当前项带勾和升降序箭头。

## 阅读助手

- 默认回车发送，`Ctrl + Enter` 换行（以前反过来）。
- 发出去的问题下面会显示这一问一起交给 AI 的内容：截图缩略图、所选文字、文档与页码；输入框上方的选区随之清空。
- 「参考原文」不再挂在每个回答下面；点开回答上方的 Thinking 时一起列出。
- 不再出现「所给材料未标注页码」之类的旁注。
- 思考强度改成一排分段：每一档直接写出名字，选中的那一档下面滑过一块玻璃，右侧四格强度条表示当前强度。
- 右侧的提问导航改成 Codex 式：刻度全部排在中间，指针靠近时逐个放大，指着的那一条最长最深；悬停卡片改用实底，不再是玻璃。
- 输入框的提示语换了一批，正常一点，也幽默一点。

安装版与免安装版继续使用原文档库、阅读进度、设置、标记和对话记录；0.3.1 起的版本可在应用内一键升级到本版本。
