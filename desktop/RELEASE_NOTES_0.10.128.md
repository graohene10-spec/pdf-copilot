# 开智 0.10.128

## Ctrl + Z 撤销删除

- 删分组、删书签（单个、多个、全部）、把文档移出文档库之后，按 Ctrl + Z 拿回来；提示里会写明。
- 移出文档库是先从列表里拿掉，30 秒后才真的删记录。这段时间里撤销，阅读进度、标签、书签都原样回来；过了时限就要重新加入。

## 总结草稿

- 表头不再写「查阅文档 · 395 段」这类进度：助手在忙时，表头下沿是一道流光，和快速解释卡片上的一样。
- 划选后冒出来的小输入框加宽了，提示不再被截断。
- 划选一段让助手改：对话栏里只显示你写的要求，划选的原文缩成一行（指上去看全文）。原来整段原文都贴进对话栏，没法读。
- 图解限了最大宽度并居中。原来在很宽的文档栏里被等比放大，几个圈占掉一整屏。

## Markdown

- 「查看源码 / 阅读视图」来回切换时，停在同一行上。原来按比例恢复，两边高度不同就会跳到别处。

## 动画

三个子代理把样式、组件、阅读器与背景的动画代码过了一遍。这次改了两处确定的：

- 拿掉输入框上方的一条引文时，后面的顺势滑过来，不再等它淡完才跳一下。
- 通知弹出时不再做模糊过渡。
