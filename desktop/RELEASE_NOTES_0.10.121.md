# 开智 0.10.121

## 字体发虚

- 草稿风格里，侧栏、助手面板、设置对话框和每组设置、标签、便签原来都转了零点几度（「歪着放的纸」）。转过的文字落不到像素格上，同一屏里有的清楚有的发虚。现在文字一律摆正；手绘感留给铅笔描的边框、胶带、回形针和图标。

## 总结

- **范围按章节选**：去掉「当前这一章」。范围那一行列出这份文档的章节（PDF 的目录、Markdown 的标题），勾哪几章总结哪几章；没有目录时提示说个大概就行。
- **界面重做**：设置表是一张实心的表单卡片，草稿面板是一整张纸。草稿风格下这两处不用手写体，也不描铅笔边，标题同样用正经的字体。
- **图解与可交互的二级选项**：打开后多出两条滑轨——数量（少 / 正常 / 多）、偏向（偏图解 / 平衡 / 偏交互）。选中的那一格下面有一块滑块，玻璃风格下是一滴玻璃。
- **草稿面板不再有一片空白**：助手还没写出字时，纸上显示标题和它正在做什么；没在写时写明接下来怎么用。面板也不再被书签轨道压在上面。
- **划选一段让助手改**：在草稿上划选一段，旁边冒出一个小输入框，写一句怎么改就发给助手。助手正在写会先打断它。
- **不再出现 `[S…]` 来源编号**：提示词里明确文档里不写这种跳转标记，写进草稿前也会再去掉一遍。
- **第一问显示成表格**：发出去的那张设置表在对话栏里是一张小表，不是便签。
- 阅读区右键菜单里补上「总结这份文档…」（原来只在选中文字时才有）。

## 其他

- **书签里挪书**：侧栏书签区按住书名拖动，这本书浮起来跟着指针走，别的书让出位置；顺序会记住。
- **界面上的字不能选中**：按钮、标签、提示、标题不参与选中，拖一下或按 Ctrl+A 不会把它们刷成一片。能选的只有内容：书页、文档、回答、你问的话、译文、报错和输入框。
- **记忆三选一可以用方向键**：焦点在上面时，左右键切换。总结表里的两条滑轨同样。
