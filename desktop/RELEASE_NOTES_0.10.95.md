# 开智 0.10.95

书签：

- 书签所在的位置看得见时，它夹在那一页的页边上，跟着书页走；翻走以后，右侧滚动条旁只留一条细线，颜色取自那幅画。指到细线上，画会伸出来；点一下照旧跳过去。
- 挨得太近的书签互相让开，不再叠在一起。
- 在书签旁边的空白处按住左键拖动，可以框选书签（不会再选中 PDF 文字）；Ctrl / Shift + 单击也能多选。选中后右键可以一起换画风或删除，按 Delete 直接删除，点别处取消。
- 侧栏的书签列表不再被底部的铅笔纹理截断，列表长了就盖在纹理上面。

使用教程：

- 改成右下角的小窗：一圈细边，里面整块都是动画，不挡住正在用的界面。左上角点章节名换段，右上角「看完了」、放大、关闭。
- 镜头推拉改成只做合成层缩放，不再每帧重画文字，帧率更稳。
- 快速解释：加上「点图钉旁的图标，卡片在跟着书页走 / 停在屏幕上之间切换」。
- 标记：改为直接按 Alt + 1 / 2 / 3 拿起工具，不用先点标记按钮；Esc 退出。
- 书签：用应用里真的那套画；讲到书签夹在页边、翻走后变成细线、Ctrl + ↑ / ↓ 在书签之间跳转。
- 文库：导入一步改成从桌面把文件拖进窗口。
- 侧栏底部的入口从一个播放图标改成带字的「教程」按钮。
