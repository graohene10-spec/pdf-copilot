## 验证方式与限制

- 常规浏览器回归使用独立 Edge 配置、合成 PDF 和本机模拟模型接口，不发送个人文档或调用收费 API。真实 Codex 检查只使用极小合成材料。
- 原生自动截图的无头测试副本显式授予 `<all_urls>`，用来替代无头环境无法点击扩展图标取得的 `activeTab`；**发行 Manifest 没有此权限**。截图授权拒绝另有单元/浏览器验证。本地 URL 回归直接使用原始 Manifest。
- Commands API 返回的建议键位、快捷键设置入口和侧栏用户手势调用已验证；无头命令桥接不等同真实浏览器级键盘输入。个人浏览器中的按键冲突及原生 PDF 右键菜单仍需实际按键/右键确认。
- 默认版与极简版已验证，不代表所有 Chromium 版本、操作系统、企业策略或商店审核都已通过。当前未在一台全新 Windows 电脑完成从零安装验收。
- DeepSeek / OpenAI 的协议与界面通过本机模拟测试；当前报告不声称完成两家真实账户的全模型、额度及思考强度矩阵验证。模型能力与账户权限需按实际服务确认。
- Codex 动态工具属于实验接口，真实往返已在 0.160.0 验证，不能据此保证所有未来 CLI 或未验证旧版行为。

## 数据与资源边界

- 默认自动上下文开启，点击发送才提供当前页和按需片段；已有手动附件时不重复附整页。关闭选择保留并在对话窗口同步。
- 图片、PDF 文字、检索缓存和会话保存在运行时内存；浏览器存储检查没有发现测试页图或 PDF 文字。书签只保存文档指纹和页码，字号/开关是用户偏好。
- 增强模式按需调用限制为 3 轮、12 次工具调用、8 页、24,000 字符和 2 张页图；搜索也有页数与时间限制。增强页图与原生可见截图压缩在内存中，历史图片不自动重新发送。
- 阅读器最多保留 3 个渲染画布、合计不超过 1,600 万像素；缩放、导航和换文件会清理过期框选等待。
- 不把操作系统交换文件、崩溃转储或服务商处理政策列为“不留痕”保证。具体范围见[隐私说明](../PRIVACY.md)。
