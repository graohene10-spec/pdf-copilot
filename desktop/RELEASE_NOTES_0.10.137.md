# 开智 0.10.137

## 搜索对话

- **对话栏和管理页都能搜**。对话栏点标题打开对话记录，顶上有「搜索对话」，打开就能打字；管理页顶上「撤销」旁边也有，Ctrl + F 聚焦。搜的是所有文档的对话，标题和内容一起搜。
- **模糊匹配**。先找一字不差的；找不到再放宽：字按顺序出现、中间隔几个字也算，打错或多打一个字也算。两个字以内只找一字不差的。空格隔开的几个词都要命中。
- **结果带出处**。每条结果有标题、所在的书和时间，以及命中的那句话，命中处标出来。标题里命中的排前面。
- **点开滚到命中的那条消息**，亮两下标出位置。回车打开第一条，Esc 先清空搜索。

- **阅读助手**：新增在对话记录里搜索；记忆选项的说法改成「全局」包括本书。
- **文库**：新增重命名（F2）和 Ctrl + Z 撤销。
