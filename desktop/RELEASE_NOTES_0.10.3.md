# 开智 0.10.3

## AI 翻译：去掉「自动（小模型）」
原因：用 Codex 时，「自动」实际上没有指定模型和思考强度，交给了 Codex 的默认配置——往往是大模型 + 高强度，短短一段也要想很久，和「小模型」的说法不符。

- 翻译只列具体的模型，思考强度也没有「默认 / 自动」档，用哪个、什么强度都写在翻译栏的标签上（例如「Codex 本机登录 · gpt-6-luna · 低」）。
- 没选过时，自动填上该服务商的默认模型和它最低的思考强度，并照样显示出来，可随时改。
- Codex 的模型列表还没读过时，翻译前先读一次，不再把空模型交给 Codex。
- 共用服务商时，阅读助手换了服务商，翻译的模型跟着换成新服务商的。
- 每张译文卡片标出用时（例如「AI · English · 2.3s」），快慢一眼可见。
- 小助手连接空闲 20 分钟才关（原来 5 分钟），隔一阵再翻译不用重新冷启动。
