# 开智 0.10.126

## Intelligent UI

- **回答里主动画图**。原来的提示词写的是「不要为了用而用」，助手就很少画。现在列明了该画的场景：概念之间有结构、推导有好几步、流程怎样变化、几样东西对比、量随量变化、空间关系、读者说没看懂。拿不准时偏向画。只有答案是一个事实、一个数、一句定义时不画。
- **总结里开了「图解与可交互」却一张图都没有**。原来写的是「可以用」，助手当成了可用可不用。现在是要求：少是全篇一到两处，正常是每节一处、全篇不少于三处，多是每节至少一处、全篇不少于五处；写完要回头数，不够就补。

## 顶栏

- 设置按钮旁边的那道空和细线去掉了。

## 交互上的毛病

派了三个子代理分头把阅读区、阅读助手、文库与外壳的代码过了一遍，这次先改掉其中确认成立、改动小的：

- 对话记录里的删除：点一下变成「再点一次」，三秒内再点才删。原来一点就删，连同它记下的东西。
- 对话记录按 Esc 收起；输入「/」出来的指令列表按 Esc 收起。
- 回答还没写完时按回车：会说一声「这一轮还没答完」。原来什么反应都没有。
- 在正在写的回答里划选文字，选区不再每隔一会儿被冲掉。
- 改中间某一问会另开分支，这一点写进了编辑按钮的提示里。
- 切换对话时，没改完的编辑框收起。
- 设置里改过东西后，点到对话框外面不再直接关掉、把改动全丢了。
- 文库卡片上用键盘按星标或移除，不再同时把文档打开。
- 详情对话框开着时：Esc 先关它，不是先清掉选中的文档；Delete、Ctrl + A 不再作用到后面的文库上。
- 详情里没加成的半截标签，不再带到下一份文档里。
- 批量加标签的输入框：点到别处是取消，不是把半截标签加到所有选中的文档上。
- 阅读区右键，没选中文字时也有「在这里加书签」。
- 搜索框按 Esc：第一下只是离开搜索框，结果和高亮留着；再按一下才清掉。
- 页码框：输入超过总页数的数，跳完后框里显示真正到的那一页；清空后移开不再跳回第 1 页。
- 右键菜单关掉后，焦点回到原来的地方，方向键和翻页键接着能用。
