# 升级开智

当前桌面版为 [0.3.1](https://github.com/graohene10-spec/pdf-copilot/releases/tag/desktop-v0.3.1)。可以在「设置 → 更新」查看当前版本和发行形式，并点击「检查更新」。设置共有「外观、阅读、快捷键、AI、更新」五页。

## 选择升级方式

| 当前版本与发行形式 | 升级方式 |
| --- | --- |
| 0.3.1 及以后，安装版或免安装版 | 发现更高版本后点「立即更新」，自动下载、校验、安装并重启 |
| 0.3.0 安装版 | 在应用内点「立即更新」下载，完成后再点「重启并安装」；升至 0.3.1 后，后续更新一键完成 |
| 0.2.2 及更早的安装版 | 手动下载安装一次 0.3.1 或更新的安装包，之后可在应用内一键更新 |
| 0.3.0 及更早的免安装版 | 手动下载并替换一次 0.3.1 或更新的免安装包，之后可在应用内一键更新 |

应用只提供版本号高于当前版本的更新。当前版本已是最新时，会显示「已是最新版本」。浏览器插件与桌面软件有独立版本，插件的 `v0.3.3` 等标签不代表桌面版高于 `0.3.1`。

## 应用内更新

默认开启「自动检查更新」：启动约 8 秒后检查一次，此后每 6 小时检查一次。发现新版本时，右下角出现包含更新说明的卡片；也可随时到「设置 → 更新」手动检查。

在 0.3.1 及以后版本中，点击「立即更新」后：

1. 下载适合当前发行形式的安装包或免安装 ZIP，并显示进度；下载期间可点「取消」。
2. 按发布附件中的 SHA-256 校验文件核对下载内容。
3. 自动安装并重新打开开智。安装版运行静默安装程序；免安装版替换当前文件夹里的程序文件。

更新会重启程序，请先完成正在进行的操作。已有文档库、阅读进度、设置、已保存对话与凭据继续使用；未发送的草稿和进行中的 AI 请求请在更新前处理。

- **稍后**：本次运行暂时隐藏该版本的卡片；手动「检查更新」或重新启动可再次看到。
- **跳过此版本**：后续自动检查不再提示该版本。手动「检查更新」仍可重新查看和更新。
- **关闭自动检查**：取消「自动检查更新」后保存，仍可手动检查。
- **测试版**：开启「接收测试版更新」后保存。测试版用于提前试用新功能；关闭后不会自动降级，会等待版本号更高的正式版。

如果发布中没有适合当前发行形式的更新包，或其校验信息不可用，卡片会提供「前往下载页」，可按下面的方法手动升级。

## 手动升级

在[桌面版 0.3.1 发布页](https://github.com/graohene10-spec/pdf-copilot/releases/tag/desktop-v0.3.1)选择相应附件；以后升级可从[发布列表](https://github.com/graohene10-spec/pdf-copilot/releases)选择较新的 `desktop-v` 版本。

**安装版**：下载 `kaizhi_0.3.1_x64-setup.exe`，关闭开智后运行安装包，继续使用当前 Windows 账号及原安装位置即可。无需先卸载，也无需重新导入文档。

**免安装版**：下载 `kaizhi_0.3.1_x64-portable.zip`，关闭开智，解压后将 `开智-portable` 中的新文件复制到原程序文件夹并替换同名文件。保留 `开智.exe` 旁的 `native-host/` 文件夹，以及原来额外放入的个人文件。也可以解压到新目录后运行；同一 Windows 账号下仍会读取原文档库。

发布页同时提供完整源码、`manifest.json` 和 `SHA256SUMS.txt`。源码包用于开发，不是可直接运行的桌面程序。

## 数据与运行环境

安装版和免安装版共用当前 Windows 账号的应用数据目录。Windows 默认位置为 `%APPDATA%\com.phydog.reading\`，其中包含 `library.sqlite3`、本地设置、对话与导入的字体；已保存的 API Key 位于同一数据目录的 `credentials/`，使用 Windows 当前账号加密。WebView2 也有自己的本机浏览器数据，不要在升级时清理它。

升级沿用应用标识与数据位置，不会搬动 PDF / Markdown 原文件。文档库引用原路径，原文档移动或删除后仍需重新定位、导入；将程序复制到另一台电脑不等于迁移文档库。已保存的 API Key 与 Windows 账号绑定，换账号或电脑时可能需要重新填写。

两种发行形式都使用系统 WebView2。安装版在缺少运行时时可联网下载；免安装版需要系统已有 WebView2，缺少时可以使用安装版补齐运行环境。Codex 模式仍需要本机已有兼容的 Codex 并已登录，API 模式继续使用用户自己的服务配置。

## 更新未完成时

- **检查失败**：检查 GitHub 网络或系统代理后重试。GitHub 请求额度用尽时，稍后再检查。
- **下载中断或校验失败**：应用会清理未完成或校验不符的临时下载，当前程序不会因此安装新包。点「重试」重新下载，或从发布页手动下载。
- **免安装版文件无法替换**：确认程序目录可写，其他开智进程没有占用该目录；替换失败时程序会尝试回滚已替换的文件，可关闭其他进程后重试。
- **没有自动重新打开**：从原位置启动开智，在「设置 → 更新」确认当前版本；必要时使用同种发行形式的完整包手动升级。

安装包尚未代码签名，Windows 可能显示安全提示。下载请使用本仓库发布页。发布者维护附件及自动构建的方法见[发布说明](RELEASING.md)。
