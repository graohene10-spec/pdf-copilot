常规自动验证不使用真实 Key，不发模型推理；真实收发测试仅按需执行并单独记录。发布前逐项记录浏览器/Windows/Codex版本和结果：

0.2.3 补充记录（2026-10-06）：本轮完整功能清单和测试范围见 [测试记录](QA_REPORT.md)。隔离 Edge 的常规回归仅用合成输入与本机模拟服务；另按需执行两次真实 Codex 推理，文字及 64 像素合成图片均通过，未使用个人文档。修复链接接口不兼容、慢渲染框选丢失、取消选择残留、框选模式提示和加密文档取消误报。个人 Edge 的真实快捷键和原生 PDF 右键菜单仍需 Computer Use 完成，不能用无头命令处理函数测试替代。

0.2.2 补充记录（2026-10-06）：在实际 Edge 配置中确认 `_execute_action` 未分配快捷键。隔离 Edge 复现旧版在快捷键页显示“激活扩展”、Alt+Shift+A 未注册。修复为独立 `open-sidebar` 命令，默认 Ctrl+Shift+7；确认 Commands API 返回正确键位及“打开 AI 侧栏”描述，扩展设置按钮能打开浏览器快捷键页并显示该条目。侧栏命令单元测试验证在查询标签页之前立即打开正确窗口、失败时不会跳转错误的截图页面；隔离浏览器通过真实按钮点击的测试桥接调用同一命令，侧栏真实 API 成功打开，验证用户操作状态保留。55 项自动测试通过，真实 Codex 元数据测试默认跳过；鼠标滚动、公式和等待提示的回归通过。测试桥接只存在于测试副本；真实浏览器级按键仍需重新加载后人工确认。

0.2.1 补充记录（2026-10-05）：检查实际 Edge Default 配置，发现仍加载 0.1.0 发行目录，且增强阅读器快捷键未注册。55 项自动测试通过，真实 Codex 元数据测试默认跳过。增强阅读器建议键改为 Ctrl+Shift+8，设置页显示运行版本及实际快捷键/未设置状态；命令优先使用浏览器事件提供的 PDF 标签页。隔离 Edge 验证建议键实际注册、原生 PDF 标签页经命令处理保留原 URL 并打开增强阅读器、40 页混合尺寸文件滚轮跨页/回滚、页码/缩放/书签和画布预算，以及原有公式/等待提示功能。无头浏览器输入无法触发浏览器级快捷键，所以命令集成测试仅在测试副本捕获监听器后调用，未声称验证真实键盘按下；用户浏览器重新加载后仍需按键验收。未写入个人浏览器配置或发送收费推理。
