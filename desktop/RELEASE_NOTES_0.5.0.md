# 开智 0.5.0

## 液态玻璃

- 玻璃有了真正的光线折射：每块玻璃（侧栏、顶栏、工具条、助手、卡片、菜单、提示……）边缘是一圈凸透镜，身后的照片、页面和光斑在边缘被拉伸、弯折；小块玻璃边缘还有很淡的色散。中间照常磨砂，文字不参与扭曲。可在「设置 → 外观 → 光线折射」关闭。
- 透明度拉到最大时真的通透了：页码胶囊、右键菜单、弹窗这些弹层的底色以前最多只淡到七成，现在随透明度一起降到约三成。
- 「泛白」现在可以自己调。它来自两样东西：玻璃本身的底色（浅色主题白、深色主题深灰），以及图片底板下的可读性补偿——身后图片和文字颜色太接近时，应用会把那块玻璃自动加厚，所以同一张图上有的面板发白、有的不发白。「设置 → 外观 → 玻璃可读性」提供：
  - 补偿方式：加厚玻璃（统一字色）/ 切换字色（玻璃保持通透，按身后明暗换深浅字色）/ 关闭；
  - 补偿强度：越低越通透，差的对比度改用一圈很淡的文字光晕补上（默认 50%，原来相当于 100%）；
  - 玻璃底色：跟随主题，或取自底图颜色（带上图片的色调，而不是一层白雾）。
- 右键菜单换成带折射的液态玻璃，跟随光标的镜面环，指向的那一项下面滑过一滴玻璃高光。

## 阅读助手

- 模型与思考强度不再弹出卡片：点模型按钮，输入栏下沿弹簧般拉长，露出模型胶囊和强度滑杆；再点一次、按 Esc 或点别处收回。「服务商、密钥与预算」入口移除，统一在设置里改。
- 「文档上下文」重做成一枚胶囊：关闭时是带斜线的描边小书本，开启时整枚胶囊带上主色玻璃，深浅主题下都清楚。
- 思考中的英文动词（Cogitating… 等）有了 Codex 式从左到右的流光；用时按整秒走，不再跳小数。
- 「猜你想问」只在真的有上下文时出现：已有对话或选中了文字。空白的新对话不再猜；文档上下文关着时也不读当前页原文。
- 「Tab / Enter 采用」提示只在前三次出现，之后只留淡色的问题本身。
- 空白页的古诗和名言不再显示作者与出处。

## PDF

- 快速滚动不再突然卡顿：深色模式的彩色图片保护层以前在浅色主题下也会从显卡回读整页画布判断图片，每渲染一页就卡一下。现在浅色主题完全不读像素；深色主题只在停下滚动、浏览器空闲时读几张 24×24 的缩略图，结果按页记住，缩放或翻回来都不再读。图片位置直接取自渲染时的操作列表，不再让 worker 重新解析一遍；搜索索引复用文字层已取到的文字；横向滚动条不再在每个滚动帧强制排版。
- 标记工具有了快捷键：`Alt + 1` 钢笔、`Alt + 2` 荧光笔、`Alt + 3` 下划线；再按一次当前工具的键退出标记。可在「设置 → 快捷键」修改，标记工具条的悬停提示会显示按键。

## 工作区

- 全屏时顶栏右侧多了「收起顶栏与侧栏」：顶栏和侧栏一起收走，阅读区占满整屏，左上角只留一枚竖向小标签；点它或按 `Ctrl + B` 一起展开，退出全屏时也会自动展开。
- `Ctrl + B` 开关侧栏有了弹性动画：侧栏宽度弹簧收放，阅读区每一帧跟着让位；PDF 换好新尺寸后从原来的位置和大小弹性缩放过去，不再一下子跳开。顶栏收放、目录、助手面板开关也一样。
- 右键书目卡片：打开、收藏、更换显示封面（首页预览 / 自选图片 / 默认图标）、从文档库移除。封面压缩后保存在本机文档库，同一本书的副本共用，重启后保留。

安装版与免安装版继续使用原文档库、阅读进度、主题、设置、对话记录和已保存凭据；0.3.1 起的版本可在应用内一键升级到本版本。

Windows x64 发布包含安装版、免安装 ZIP、完整源码 ZIP、程序清单和 SHA-256 校验文件。
