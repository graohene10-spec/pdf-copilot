# 开智 0.9.0

铅笔草稿主题：

- **格子纸背景上的流形**：文档库的格子纸背景里，一个很淡的铅笔线框流形慢慢自转 360°，占据大半块桌面，被卡片、面板挡住也无妨。共七种：Calabi–Yau（五次曲面截面）、Hopf 纤维化、克莱因瓶、Boy 曲面、Breather 伪球面、Dini 曲面、(2,5) 环面纽结；每隔 35–75 秒随机换一种，换的时候像重新画一遍。
- **浮现的微分几何**：旁边随机写出定理与定义（Gauss 绝妙定理、Gauss–Bonnet、Stokes、de Rham、Levi-Civita 联络……），有一部分直接画在正在旋转的流形上：切空间画成切平面、坐标基 ∂u / ∂v、法向量与高斯映射、黎曼度量的单位圆、坐标卡、Stokes 定理的区域与定向边界、向量场与积分曲线，跟着流形一起转。
- 阅读时默认不显示。设置 → 外观（铅笔草稿）里可以关掉、打开「阅读时也显示」，或选择在哪几种流形之间轮换。每秒只画 15 帧，窗口最小化时停下。
- **回形针真的别在阅读助手上**：外圈压在纸面上带一点投影，里圈绕到纸背后，只露出纸边外的一截；出现时从上面滑下来卡住纸边。
- **书名、对话标题放不下时**：从左边开始显示、末尾省略；鼠标指上去，文字从左往右走到头，再弹回左边循环。
- **右上角的按钮**都画上铅笔圈，和工具条一样是实心纸片，正在用的涂黄，左右不再失衡。
- **并排文档组的红圈**画在页签下面的桌面上，比页签大一圈、不规则，来回圈了两道，被纸片挡住的部分藏在后面。
- **侧栏空白处**：一朵铅笔画的向日葵（植物大战僵尸的那种），站在地上左右轻轻摆。

0.3.1 起的版本可在应用内一键升级到本版本。
