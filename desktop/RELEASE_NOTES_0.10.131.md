# 开智 0.10.131

## 说明不再写死在界面上

用法提示改成两种：隔几次才冒一回的气泡，和指上去才显示的说明。

- **模型抽屉**：「模型不止这几个：滚轮可以左右翻」那一行拿掉了。改成气泡，在第 1、4、9 次打开时各冒一次（不是头三次连着），用过一次滚轮就不再提。
- **设置**：15 段常驻的说明文字收进了小问号，指上去才显示。
- **总结**：设置表底下的那句话、空草稿上的三步说明拿掉了。改成气泡：打开设置表时提「都可以不填」，草稿写完时提「划选一段可以直接改」。
- **记忆**：设置页的三句说明、管理对话页记忆栏的说明，收进了标题旁的问号和标题的悬停提示。
- **管理对话页**：底栏那行「左键进入 · 右键操作 · …」拿掉，打开时用气泡提。
- **翻译栏**：空白时的两句用法拿掉，改成气泡。
- **AI 设置**：Codex 和本机服务的两句说明挪到按钮提示和输入框占位里。
- **侧栏**：没有分组、没有书签时只写「还没有分组」「还没有书签」，怎么加在悬停提示里。
- Intelligent UI 合集的表头提示、并排阅读选择框的副标题也去掉了。
