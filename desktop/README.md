# 开智 0.2.0

基于 Tauri 2 + Vue 3 / TypeScript + Rust + SQLite 的 Windows PDF / Markdown 阅读管理工具。现有浏览器插件保留在父目录，桌面原型独立位于 `desktop/`。

0.2.0 将当前功能正式整理为新版本：包含自定义图片底板、连续玻璃透明度、局部文字与图标明暗适配、茶色毛玻璃弹窗，以及已有的多文件阅读和 AI 助手。升级沿用原应用标识和本地数据目录，保留文档库、阅读进度、设置与已保存凭据。

## 已实现

- 本地 PDF / Markdown 文档导入、文档库、标签、星标、搜索和阅读进度。
- PDF 连续阅读、目录、内部跳转、缩放、选文、图表框选和引用定位；使用原插件的 PDF.js 渲染模块，限制驻留页面。
- Markdown 排版、目录、源码视图、字号、选文、本地相对图片和行号引用。
- OpenAI API、DeepSeek 与本机 Codex：流式回答、思考过程、停止请求、当前页上下文、按需读取 / 搜索文档、图表上下文、数学公式显示、可点击原文来源。
- 深浅主题。界面样式通过 CSS 设计变量统一控制，后续可扩展主题包；本版没有执行第三方插件的入口。
- SQLite 保存本地文档信息。导入引用原文件，不移动或改写文件。移除文档只移除库中的记录。
- Windows API Key 可按用户选择使用 DPAPI 加密保存；浏览器预览只在当前会话内保存 Key。
- 集中设置：外观、阅读、快捷键和 AI 服务配置。快捷键可修改、禁用或恢复默认。
- Windows 启动时自动最大化，按显示器工作区和系统 DPI 适配；保留任务栏及窗口还原操作，默认还原尺寸也会限制在显示器工作区内。
- 打开 PDF 侧栏后，页面超宽时自动缩小；可在阅读设置中关闭。
- PDF 缩放保留已绘制画面，用一个后台缓冲完成重绘后再替换；快速切换会取消过期重绘，相同缩放比例不重复渲染。
- 多文件标签：一次导入多个文件即可打开多个标签，重复打开会切回已有标签；顶部标签栏可横向滚动、关闭和用键盘切换，占用原顶部区域的 48px 高度。
- 各标签分别保留 PDF 页码 / 页内位置 / 缩放 / 目录、Markdown 滚动位置 / 源码视图，以及选区、AI 对话和草稿。
- AI 问题按文件隔离，共用当前窗口的并发与等待队列；切换标签、回文档库或收起助手不会停止回答，关闭标签则取消该文件的运行 / 排队任务。
- PDF 框选完成后自动展开助手并聚焦输入框，可在阅读设置中关闭；普通选文只显示紧凑的「问 AI」浮动入口，点击后带入原文。

0.1.1 将应用名称统一为开智，并简化文档库与阅读界面的装饰性文字。
0.1.2 优化侧栏与缩放时的 PDF 渲染连续性，避免先清空画布造成黑白闪烁。过渡期间使用原画面缩放，重绘完成后恢复目标清晰度。
0.1.3 加入紧凑文件标签、独立阅读状态、后台 AI 问答和可配置的调度队列，并减少选区提问的操作步骤。
0.1.4 浅色使用近白色底板与两组大尺度同心圆水波；宽淡灰波槽与成对明暗边缘营造微浮雕层次。主水波位于右下，另一组从左上角露出局部圆弧，两组之间留有空隙。深色保留烟晶炭灰底板、云状色层与细矿脉。纹理为静态 SVG，水波按比例显示，避免窗口缩放时变成椭圆。侧栏、顶栏、工具栏和面板为半透明悬浮组件，加入透光边缘、柔和投影和随光标移动的高光；键盘焦点也有同等反馈，正文保持实色。
侧栏与目录按最终尺寸布局，通过 260ms 弹出 / 180ms 收缩显现；设置窗从浮层弹出，关闭时收缩后移除。玻璃透明度可在 0–100% 连续调节，默认 70%；旧四档自动转换。外观可选择本地 PNG、JPEG、WebP 作为底板，自动按比例铺满窗口；图片压缩到不超过 2560px、400 万像素及 1 MB，随设置保存到本机，不依赖原图路径。图片与滑块均支持即时预览，取消恢复原配置，保存后重启保留。

主界面采用较清透的玻璃与分层投影；自定义图片下，文字和图标根据组件所在区域的明暗与实际玻璃透明度自动选择深色或浅色，不额外改变组件底色。选中与非选中按键保持同一前景颜色，只通过灰度区别。设置和确认弹窗采用淡暖灰茶色 / 深烟茶色毛玻璃，更强的模糊隔开底下的 PDF 内容。系统减少动效、减少透明度和高对比度设置仍优先；背景只在更换图片时采样，布局和外观变化时计算颜色，不持续运行动画循环，也不作用于 PDF 与 Markdown 正文。
文件标签使用竖直左边缘与弧形右肩，相邻标签轻叠，当前文件置于前层，仍占用 48px 紧凑顶栏。材料与交互层次参考 [Liquid Glass React](https://github.com/rdev/liquid-glass-react) 与 [Apple 的 Liquid Glass 设计说明](https://developer.apple.com/videos/play/wwdc2025/219/)，采用适合 Vue / WebView 的轻量实现，未增加 React 或渲染依赖。
阅读助手的「更改」和「清空对话」采用 36px 高度的独立玻璃按钮；窄窗口下长模型名与快捷键自动省略，保留发送入口。运行中的禁用状态和空对话的清空保护保持一致。
阅读助手移除顶部标题行，模型、并发状态、更改入口与关闭按钮集中在一行。框选截图仅在发送前显示预览；问题成功提交或入队后收起预览，消息列表也不显示截图缩略图，实际提问仍携带原图。配置缺失、队列已满等未提交情况保留截图和草稿；已提交的截图不会自动作为下一题附件重复发送。
面板、按钮、输入框和文档卡片采用直角矩形，保留文件标签的档案夹轮廓与状态圆点。按钮文字在浅色主题使用近黑色、深色使用近白色，选中与悬停只改变中性灰度底色。添加文件统一使用左栏的「加入文档」，左栏收起后不显示该入口；快捷键继续可用。
侧栏引起的 PDF 自动适配会先锁定现有阅读区的屏幕位置与尺寸，在弹出 / 收缩动画期间就按最终宽度后台绘制；动画与位图均完成后，再在同一帧提交页面位置、尺寸与清晰画面，避免先重新居中再缩放的两次变化。收回中的面板临时浮在原处，为阅读区提前提供最终宽度。适应宽度与超宽纠正合并为一次请求，快速反向切换会取消过期适配，保留当前页内位置。框选使用双色十字光标与双色边缘，适配白底和滤镜后的深色 PDF。

## 运行与开发

Windows 分发版位于 `release/`，安装版使用系统 WebView2。Codex 功能复用原插件的 `PdfCopilotHost.exe`，需要本机已安装并登录兼容的 Codex；API 服务需要用户自己的 Key。

首次体验：

1. 运行 `release/开智_0.2.0_x64-setup.exe`，或解压 `release/开智_0.2.0_x64-portable.zip` 后打开 `开智-portable/开智.exe`。免安装版需要系统已有 WebView2，请保留旁边的 `native-host/` 文件夹。
2. 点击左栏的「加入文档」，可先导入同目录 `samples/` 中的示例。
3. 打开「设置」→「AI」选择服务。OpenAI / DeepSeek 填写自己的 Key；Codex 使用本机登录。点击「保存」，打开文档后通过右侧阅读助手提问。

安装版与免安装版共用当前 Windows 账号的本地文档库。免安装表示无需安装程序，文档库仍保存在用户应用数据目录。

从上一版本升级为开智后，会继续使用原有文档记录、标签、星标、阅读进度、设置和已保存的 API Key。应用标识和存储位置保持一致，无需重新导入文档。

## 设置与快捷键

侧栏底部和顶部工具栏均可打开集中设置。设置分为四类：

- 外观：主题、文档视图、0–100% 玻璃透明度、本地底板图片及恢复默认。正文保持实色；系统减少动效时关闭动画。
- 阅读：PDF 初始缩放、缩放步长、侧栏打开后的超宽适应、框选后自动展开助手；Markdown 默认字号和内容宽度。
- 快捷键：录入新的按键组合，禁用某项操作，或恢复默认；重复与保留组合会提示冲突。
- AI：服务、模型、接口地址和凭据，以及每题阅读预算和多文件并发数。默认同时运行 2 题，其中 Codex 最多 1 题，最多等待 8 题。阅读助手中的「AI 设置」也会打开此页面。

PDF 默认使用适应宽度。手动缩放后，打开文档库侧栏、目录、文档详情或阅读助手时，仅当页面超出可用阅读宽度才自动缩小；未超宽则保留当前比例。在「设置」→「阅读」中取消「侧栏打开后，仅在页面超宽时适应宽度」即可关闭该行为。适应宽度模式本身会随阅读区域宽度调整。

默认快捷键如下；可在设置中更改：

| 操作 | 默认快捷键 |
| --- | --- |
| 导入文档 | Ctrl + O |
| 搜索文档 | Ctrl + K |
| 打开设置 | Ctrl + , |
| 显示 / 隐藏侧栏 | Ctrl + B |
| 显示 / 隐藏阅读助手 | Ctrl + Shift + 7 |
| 下一个 / 上一个文件标签 | Ctrl + Tab / Ctrl + Shift + Tab |
| 关闭当前文件标签 | Ctrl + W |
| 显示 / 隐藏目录 | Ctrl + Shift + O |
| 框选 PDF 区域 | Alt + Shift + S |
| PDF 适应宽度 | Ctrl + 0 |
| 缩小 / 放大 | Ctrl + − / Ctrl + = |
| 上一页 / 下一页 | Alt + ↑ / Alt + ↓ |
| 发送 AI 问题 | Ctrl + Enter |
| 停止 AI 回答 | Ctrl + Shift + Enter |

快捷键会根据文档与输入框状态启用，输入文字和中文输入法组合期间不会触发全局阅读操作。

开发需要 Node.js、Rust MSVC 和 Microsoft C++ Build Tools / Windows SDK。

首次从源码构建时，在仓库根目录先安装共享依赖并构建 Windows 本机助手，再进入桌面目录。助手使用 Windows 的 .NET Framework 4.x 编译器；生成的程序和离线阅读资源由桌面构建脚本自动复制。

```powershell
npm ci
npm run build:host
cd desktop
npm ci
npm run build
npm run desktop:dev
```

前端可以独立运行：`npm run dev`，打开终端提示的本地地址。浏览器使用 IndexedDB 文档库，内置两份合成示例；这是界面与接口验证入口，Windows 版使用 Rust + SQLite。

```powershell
npm test
cargo test --manifest-path src-tauri/Cargo.toml
npm run desktop:build
npm run package:desktop
```

若本机编译工具不在 PATH，可使用 `scripts/build-windows.ps1`。该脚本先检查项目临时目录里的工具，再使用系统工具。

`npm run package:desktop` 会检查前端、Tauri 与 Rust 的版本一致性，将安装包、主程序和本机助手整理到 `release/`，自动生成带版本号的免安装 ZIP，并写入全部交付文件的 SHA-256。Windows 生产构建完成后再运行此命令。

## PDF 重绘策略

旧渲染器在缩放时释放并重建画布，PDF.js 完成新页面之前存在空白间隔；慢速渲染复现中检测到了 9 次白画布。桌面渲染器在一个离屏缓冲中完成新位图、文字层和链接层，再在同一显示帧中整体替换。手动缩放先用现有位图响应；由侧栏引起的自动适配锁定现有阅读区的屏幕位置与尺寸，通过独立布局容器测量最终可用宽度。离场面板提前移出布局、在原处收缩，让后台绘制与面板动画并行；新位图与全部动画完成后同时解除锁定、提交尺寸与清晰画面。等待提交的任务可取消，不阻塞后续绘制队列；窗口连续调整仍保留防抖。该策略参考 [PDF.js 的画布显示与替换实现](https://github.com/mozilla/pdf.js/blob/master/web/base_pdf_page_view.js)。

连续改变尺寸会取消过期任务；相同放大率不触发新的位图渲染。适应宽度直接使用当前页尺寸，滚动条预留宽度保持稳定，避免额外重绘。失败时继续显示原位图，再次点击适应宽度可重试。

同一 1400×980、双倍 DPI 的浏览器环境中，示例 PDF 使用未添加延迟的实际绘制，对比优化前后的面板适配：从动画开始到最终画面提交，收回由 322ms 降至 204ms，展开由 405ms 降至 278ms。当前页绘制提前到动画初始，性能改进来自动画与重绘重叠以及缩短面板动效，未降低画布清晰度。另以人为增加 120ms 绘制延迟的合成文档验证慢速准备仍可重叠。图像多或复杂的 PDF 仍需等待其实际绘制完成，期间继续保留原画面。对比原始记录保存在 `artifacts/reader-timing-*-before.json`、`*-after-parallel.json` 与 `*-after.json`。

仍然只保留三页显示窗口，同时最多生成一个缓冲位图，合计限制为 1600 万像素。普通手动缩放过渡期间可能短暂柔化，完成后恢复目标清晰度；极高放大率仍受像素预算限制。手动缩放的预览阶段暂停文字和链接命中；侧栏适配期间旧布局固定，原文字与链接保持可用，提交新画面时一同更新。AI 框选等待新画面完成，避免坐标偏差。逐帧验证使用带底色的合成文档及人为延迟，结果说明这些覆盖场景中的显示连续性。

## 多文件与 AI 生命周期

标签保存轻量状态，阅读区域只挂载当前文件；切走时释放原阅读器的画布、文件数据及 PDF worker，切回时恢复位置和视图。各文件的进度和搜索索引按文档编号保存，异步回调检查打开版本，避免快速切换后更新另一文件。

AI 会话独立于侧栏组件。每份文件同时最多一题，所有标签共用从原插件复用的 `RequestQueue`；按最早可运行的任务分配额度，Codex 已满时不会堵住可用 API 额度。排队任务只保留发送时的文件编号、页码、选区、模型和问题；取得额度后才加载自己的原文会话，故切走阅读器不会破坏 PDF 工具检索。完成或取消后释放原文会话与额度；关闭标签时取消该标签的任务，忽略过期回答和证据回调。队列满时保留草稿以便重试。

文件标签、视图状态和对话在本次运行中保留，关闭标签会释放对应会话；程序重启后阅读进度仍在文档库中。加密 PDF 的密码只在标签打开期间留在内存中，用于切回阅读及该文件的 AI 原文检索，关闭标签后移除。

## 结构与接口

| 路径 | 职责 |
| --- | --- |
| `src/components/` | Vue 界面和阅读器 |
| `src/settings/` | 集中设置模型、持久化、快捷键解析与冲突检查 |
| `src/reader/` | 阅读区域宽度、PDF 超宽适应和阅读布局计算 |
| `src/reader/continuous.mjs` | 桌面 PDF 缓冲重绘、原画面过渡、过期任务取消；复用原插件的三页驻留窗口 |
| `src/sdk/` | 文档库接口；Tauri 和浏览器适配器 |
| `src/document/` | 独立文档问答服务和 Markdown 行号锚点 |
| `src/ai/` | 模型协议、流式传输、工具循环、设置和 Codex 桥接 |
| `src/ai/workspace.ts` | 按文件隔离的 AI 会话、草稿、回答与取消生命周期 |
| `src/ai/request-scheduler.mjs` | 当前窗口共享的并发 / Codex / 等待额度；复用原插件队列 |
| `src/document/ai-context.mjs` | 运行中的提问独立拥有原文会话，结束后释放 |
| `src/components/FileTabs.vue` | 紧凑标签栏、关闭、任务标记和键盘导航 |
| `src-tauri/src/` | SQLite、文件读取、凭据、可取消的 HTTP 流和固定 Codex 助手进程 |
| `src-tauri/capabilities/` | 主窗口命令权限 |
| `tests/` | 无付费请求的 AI 协议验证 |

桌面界面通过命名命令访问本地能力，没有本地 HTTP 后端、任意 SQL 或任意程序执行接口。命令声明和权限限于主窗口；Markdown 图片按文档目录校验路径。文档内容属于资料，不授予模型执行权限。API 请求通过 Rust 的可取消 HTTP 流发送，以支持用户配置的 HTTPS 服务地址；只允许 HTTPS 或本机回环 HTTP，禁止重定向，限制请求大小和并发数。停止回答会销毁正在读取的网络响应，浏览器预览使用浏览器 fetch 并受 CORS 限制。

原插件 AI 的只读 PDF 工具协议保留。Markdown 适配器在协议内部以每 80 行一个的片段兼容页式工具，同时向模型明确提供原文件行号，并在界面按行号定位。

## 原型范围

- PDF 全文搜索索引随已阅读页面逐步建立；未读取页没有建立全库索引。AI 文档检索独立按题目预算按需扩展，搜索结果会说明覆盖范围。
- SQLite FTS5 使用 trigram 支持中文子串；1–2 字词使用本地扫描回退。原型文档库查询最多返回 1000 条。
- PDF 上限 256 MB，Markdown 上限 16 MB；无 OCR、PDF 写回编辑、云同步、完整插件沙箱或持久化聊天记录。
- 变更原文件后需要重新导入以刷新元数据与索引；未实现文件监听。
- Codex 通过外部已安装的 CLI 接入；没有捆绑模型。该兼容桥接保留原插件的版本检测与隔离规则。
- 原型未做代码签名。AI 端到端测试使用合成文档与模拟服务；真实服务的可用性取决于用户配置、账号权限和本机 Codex 版本。
