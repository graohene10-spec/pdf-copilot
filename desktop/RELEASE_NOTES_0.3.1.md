# 开智 0.3.1

- 一键更新：发现新版本后点「立即更新」，开智自动下载、校验、安装并重启，不再跳转 GitHub 页面。安装版静默运行安装程序；免安装版直接替换所在文件夹里的程序文件，文档库和设置保留。
- 内置 Anthropic Serif（可变字体）：Markdown 正文与阅读助手回答的西文默认使用它，中文仍用系统黑体；仍可在设置中导入其他本机字体。
- 关闭标签后马上点另一个标签，不再被切回原来那个标签。
- 阅读栏较窄时，PDF 工具栏的搜索框换到第二行，不再挤出工具栏。

安装版与免安装版继续使用原文档库、阅读进度、主题、设置和已保存凭据。0.3.0 及更早的安装版可在应用内更新到本版本；免安装版需要手动下载一次本版本，之后的版本都能在应用内一键更新。

Windows x64 发布包含安装版、免安装 ZIP、完整源码 ZIP、程序清单和 SHA-256 校验文件。
