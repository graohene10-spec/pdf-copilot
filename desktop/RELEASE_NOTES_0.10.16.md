# 开智 0.10.16

## 背景画面重画得更细

- **DNA 双螺旋**：B 型 DNA 的球棍模型——磷酸、脱氧核糖、碱基的每个重原子都是一个球，近的挡住远的；碱基对之间的氢键是虚线，红笔逐对读过去（A = T、G ≡ C）。
- **洛伦兹吸引子**：加了坐标轴、两个不动点、一团起初挤在一起、慢慢抹满吸引子的点，左下角是两条轨道的 x(t)。
- **凯莱图 A₅**：60 个顶点是 60 个置换；五边形的边带方向箭头，里面套着正二十面体，红点走到哪里就写出那个置换，所在的陪集淡淡涂红。
- **墨西哥帽势**：七个小球各自滚向谷底的不同方向，地面上有等势线、坐标轴和小球的影子。
- **Dijkstra**：顶点一确定最短距离就升到与距离成正比的高度，最短路径树像山一样长出来；左下角是优先队列。
- **生命游戏**：一门高斯帕滑翔机枪加一片随机初始图样，下面叠着前几代，刚出生的细胞用红笔。
- **分形二叉树**：无限放大——镜头对着不动点一直钻进去，每钻一级画面与上一级完全相同。
- **机柜的海**：机柜一排排铺满下半个桌面，一直排到天际线；水滴落下、涌浪起伏，镜头缓缓向前。
