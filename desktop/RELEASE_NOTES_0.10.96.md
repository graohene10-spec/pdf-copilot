# 开智 0.10.96

使用教程：

- 启动时右下角只弹一个很小的提醒窗，里面在放动画。点它，展开成完整的教程（左边章节、右边动画、「看完了」打勾）。指上去右上角有关闭。
- 侧栏底部不再放「教程」按钮。入口移到设置窗口左下角的「使用教程」。
- 「启动时不再自动弹出」在完整教程的左下角。

书签：

- 页面上的小书签现在和 PDF、Markdown 的页面在同一层：跟着书页一起滚，滚到上方工具栏下面会被工具栏挡住，不再浮在工具栏上面。每个书签都一直夹在它那一页上。
- 滚动条旁的标记重新设计：一根贴着滚动条的发丝细线，书签不在视野里时，线上多一道带小圆点的刻度，颜色取自那幅画，高度和滚动条滑块走到那里时对齐。指到刻度上，画会伸出来。
