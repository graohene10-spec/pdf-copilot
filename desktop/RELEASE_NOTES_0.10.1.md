# 开智 0.10.1

## 谷歌翻译连不上
原因：「谷歌」用的是免密钥的公开接口。不开代理时直连被墙（等到超时）；开了代理，谷歌按出口 IP 限流，很多人共用的代理节点会直接被拒（HTTP 429）。浏览器里的谷歌翻译网页走的是另一套服务（带 cookie 与人机验证），所以网页能用、这个接口不一定能用。

- 新增「谷歌云」：谷歌官方的 Cloud Translation API，用自己的 API 密钥（在 Google Cloud 控制台启用 Cloud Translation API 后创建，每月前 50 万字符免费），按密钥计量，不受共用 IP 限流影响。密钥加密保存在本机。
- 选「谷歌」失败时，如果已经填好了谷歌云或有道的密钥，自动改用它，卡片上注明「已改用谷歌云 / 有道」，悬停可看谷歌失败的原因。
- 错误提示写明真正的原因：12 秒没有响应（多半是直连被墙）、HTTP 429 / 403（出口 IP 被限流）、或其他 HTTP 错误，不再一律显示「连不上」。

## 摘录卡片更紧凑
- 摘录只占一行：图标表示来处（本对话 / 主对话 / 附属对话），文字过长截断，悬停看全文；去掉「之后的提问会带上它」的说明，移除按钮悬停时才出现。
- 附属对话标题栏只写「挂在「…」旁边」。
