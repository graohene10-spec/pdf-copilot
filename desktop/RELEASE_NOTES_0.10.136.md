# 开智 0.10.136

## 文档库

- **可以改文件名**。在文档上右键选「重命名」，或选中后按 F2：名字变成输入框，回车生效，Esc 取消。磁盘上的文件跟着改名，扩展名不变；书签、对话、分组、阅读进度都还在。改错了按 Ctrl + Z。同一个文件夹里已有同名文件时不会覆盖。
- **总结的文件名由助手起**。第一次把总结存入文档库时，助手照内容起一个短名字（书名简称加范围），不再是一长串原文件名加「· 总结」。没连上服务或十二秒内没起出来，就还用原来的叫法。再存一次是覆盖，名字不变。
