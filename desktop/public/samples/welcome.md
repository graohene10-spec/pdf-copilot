# 开智 0.5.0 使用说明

开智用于阅读和管理 PDF 与 Markdown 文档，支持结合文档内容进行 AI 问答。

## 导入与管理

点击「加入文档」、按 `Ctrl + O`，或将 PDF / Markdown 文件拖入窗口。文档库记录原文件的位置，导入不会移动或改写文件。

- 为文档添加标签，按项目或主题整理资料。
- 星标常用文档，方便再次打开。
- 阅读进度自动保存，重新打开时继续上次的位置。
- 搜索文档标题、标签和已建立索引的内容。
- 右键书目可更换显示封面：首页预览、自选图片或默认图标。

## 并排阅读与标记

点击顶栏「并排阅读」或按 `Ctrl + \`，可同时显示最多三份 PDF / Markdown 文档。右键标签选择「在右侧再开一份」，可查看同一本书的不同位置；两份共用对话和手写标记。

PDF 工具栏的「标记」提供笔、荧光笔、划线和橡皮，也可以按 `Alt + 1` / `Alt + 2` / `Alt + 3` 直接拿起钢笔、荧光笔或下划线；标记模式下 `Ctrl + Z` 撤销、`Esc` 退出。笔迹保存在本机，不改写原 PDF，当前不导出带标记的 PDF。

## 阅读与问答

在「设置」→「AI」中连接 OpenAI API、DeepSeek 或本机 Codex，保存后打开文档，通过右侧「阅读助手」提问。API 服务需要填写自己的 Key；Codex 使用本机已安装并登录的账号。

选中文字可以让助手解释内容。阅读 PDF 时，也可以概括当前页、搜索其他页面，或框选图表进行问答。回答中的原文引用可点击定位。

按 `Alt + Shift + S` 框选后，点击选区旁的提问气泡或按数字键即可发送；「自己提问」带截图打开输入框。这些问题可在「设置 → AI → 框选快捷提问」中增删和修改。

点输入区的模型按钮，输入栏下沿会拉长，露出模型与思考强度；「文档上下文」书本胶囊开着时，助手才读取当前页与原文。

对话菜单可新建、切换、删除或查看「全部文档」的历史。已保存的对话文字在重启后仍可查看；草稿和截图不跨重启保存。并排阅读时，助手保持当前阅读对象，需要时从标题菜单选择「改读」。

Markdown 支持目录、公式、本地图片和源码视图。文档引用按原文件行号定位。

## 外观与更新

「设置 → 外观」可更换底板、字体，连续调节玻璃透明度和模糊程度，开关光线折射；图片底板上玻璃「泛白」的程度可在「玻璃可读性」里调（补偿方式、强度、玻璃底色）。全屏时可把顶栏和侧栏一起收成左上角的小标签，按 `Ctrl + B` 展开。0.3.1 内置 Anthropic Serif 西文字体，中文使用系统黑体；也可导入自己的 TTF / OTF / WOFF / WOFF2 字体。

「设置 → 更新」可检查新版本。0.3.1 起，安装版与免安装版都能一键下载、校验、安装并重启，文档库与设置保留。免安装版的数据同样保存在 Windows 账号的应用数据目录，复制程序文件夹不会同时迁移这些数据。

## 示例

公式可以写成 $E=mc^2$，也可以单独成段：

$$
E=mc^2
$$

可以先导入同目录的 `sample.pdf`，试用页码跳转、目录和文档问答。

## 猜你想问

「设置 → AI → 猜你想问」可打开或关闭问题推荐，保存后生效。开启后，已有对话或选中了文字、且输入框为空时，会推荐下一个问题；按 Tab 或回车采用，Esc 收起。关闭后清除建议并取消推荐请求，重启后保留选择。推荐会消耗模型额度。

PDF 放大超宽时，可拖动阅读区底部的横向滚动条查看左右内容。深色模式通过色调映射显示正文、公式与图像。
