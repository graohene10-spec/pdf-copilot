# 开智 0.10.22

## 背景画面 GB300

- 机柜有三个面了：柜顶、朝着画面中间的侧板、正面。一排里先画侧板、再画柜顶、最后贴正面，机柜之间不再穿帮、叠在一起。
- 最前面的一排一直画到整个机柜滑出画面下沿，不会凭空消失；远处的排从透明慢慢显出来，不再一排排地跳。
- 波不再突然冒出来：振幅从零慢慢起来，最后慢慢平息。形状有三种，随机出现在随机位置——一滴水的圆环、从画面外推进来的平面波、两滴水的干涉。
- 中景、远景和近景一样每帧都画，不再隔几帧才动一下。

## 用 Codex 登录时的对话

- 提示词改成「先答再查」：问题附带的当前位置附近内容够回答，就直接回答，不调用查阅文档的工具；确实需要别处内容时才查，次数尽量少。此前的提示词鼓励分三个阶段、最多十二次查阅，每查一次模型就要多跑一轮。
- 随问题带上的附近内容从 4000 字加到 8000 字，更多问题不用查就能答。
- 多备一条热连接：预判问题、翻译和正式提问各占一条连接，正式提问不再因为连接被占用而等小助手冷启动（几秒）。
- 用 Codex 时，预判问题多等一会儿再发，翻页时不白跑一整轮对话。
