# 开智 0.10.122

## 总结

- **改草稿只发改动**：以前每改一处，助手都把整份文档重新输出一遍。现在它只给出「要换掉的原文」和「新内容」，应用把这一处套到草稿上，别的地方不动、不重新生成。几处一起改也是各发各的。只有换语言、整体压缩这类遍及全文的改动才整篇重写。
  - 改的时候草稿会滚到那一处，改过的几块淡淡亮一下。
  - 助手抄的原文和草稿对不上时，那一处不会改动，面板上方提示「几处没改成」，点一下让它对照草稿重新给。
- **侧重的选项重排**：知识体系、概念与定义、公式与结论、推导与证明、例题与方法、重点与易错，可以选几样。
- **每个选项是什么意思**：展开一行后，指着哪个选项，下面立刻显示它的意思；选中的也会显示。这些意思同样会告诉助手，同一个词不会各有各的理解。
- 「结构」改叫「写法」。
