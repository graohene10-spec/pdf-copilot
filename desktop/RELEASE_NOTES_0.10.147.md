# 开智 0.10.147

- Intelligent UI 换成现代外观：系统无衬线、细边框、白底、一种强调色、等宽数字；去掉手写字体、抖动线条和发光。各主题只保留强调色和卡片底色的一点呼应，暖色极简主题完全用中性色。
- 可调参数的图：图在上、滑块紧贴图下、读数和公式在最后；滑块两端标出最小和最大值，当前值右对齐；「重置」在卡片右上角。
- 图表：纵轴名和图例移到图上方，数值横轴加竖向网格；修正折线、柱状、散点图会丢掉自己标题的问题。表格里整列是数字的自动右对齐。
- 窄的对话栏和解释卡片里，参数和数字卡自动改成一列。
- 什么时候画图的规则改了：默认用文字，只有「去掉图读者明显更难懂」时才画，一次回答通常不画或只画一处；该画的情形（量随参数变化、三个以上对象同维度比较、集合与映射这类结构、依赖要紧的多步推导）对应到具体的图。总结文档不再为凑数补图。
