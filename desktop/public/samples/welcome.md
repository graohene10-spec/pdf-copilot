# 开智使用说明

开智用于阅读和管理 PDF 与 Markdown 文档，支持结合文档内容进行 AI 问答。

## 导入与管理

点击「加入文档」或「导入 PDF / Markdown」导入本地文件。文档库记录原文件的位置，导入不会移动或改写文件。

- 为文档添加标签，按项目或主题整理资料。
- 星标常用文档，方便再次打开。
- 阅读进度自动保存，重新打开时继续上次的位置。
- 搜索文档标题、标签和已建立索引的内容。

## 阅读与问答

在「设置」→「AI」中连接 OpenAI API、DeepSeek 或本机 Codex，保存后打开文档，通过右侧「阅读助手」提问。API 服务需要填写自己的 Key；Codex 使用本机已安装并登录的账号。

选中文字可以让助手解释内容。阅读 PDF 时，也可以概括当前页、搜索其他页面，或框选图表进行问答。回答中的原文引用可点击定位。

Markdown 支持目录、公式、本地图片和源码视图。文档引用按原文件行号定位。

## 示例

公式可以写成 $E=mc^2$，也可以单独成段：

$$
E=mc^2
$$

可以先导入同目录的 `sample.pdf`，试用页码跳转、目录和文档问答。
