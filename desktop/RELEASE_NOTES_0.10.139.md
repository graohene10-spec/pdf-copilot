# 开智 0.10.139

- 对话不再有「已经很长，请新建对话」的上限；压缩之后可以照常继续发。
- 上下文到量时自动在后台压缩，不挡下一问。做法参照 Codex CLI 开源的 compact：较早的对话写成交接摘要，读者的原话另存一份，最近几轮原样保留。摘要篇幅随原文长短变化（约 800–4000 字），按「读者要求 / 已讲清的内容 / 做过的题 / 还不熟的地方 / 悬而未决 / 记号」分节。
- 摘要只给助手看，不再显示在对话里；压缩处只留一道细虚线，原来的消息照常保留。
- 压缩时的提示改成和「思考中」一样的转动符号与流光文字。
- 输入框旁的圆环改为显示离自动压缩还有多远，点击可立即压缩。
- 每次请求带的历史从 12 条放宽到 24 条。
- 右侧提问导航条：问题很多时刻度自动变密，不再有排不下的。
