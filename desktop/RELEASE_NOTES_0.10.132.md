# 开智 0.10.132

## 你点名的两处

- **对话标题左边那颗键改成「对话管理」**，换了新图标（一根主干分出两段对话）。挪面板位置直接拖整条表头。
- **自动缩放会复原了**。阅读区变窄时 PDF 为了不超出会自动缩小；现在变宽后回到你原来的比例。宽度回到原来那么宽，就原样回到你设的那个值（哪怕它本来就比页面宽）。你在变窄期间自己调过比例，就以你调的为准。

## 交互

四个子代理分头改了一遍，然后统一验证。

**阅读器**
- PDF 和 Markdown 的百分比按钮都是回到 100%；PDF 另有一颗「适应宽度」，按下时是亮的。缩放到头时 − 和 ＋ 变灰。
- 目录按 Esc 关，焦点回到「目录」按钮；页面视图菜单打开时焦点进去，Esc 在哪都能关。
- 右键菜单：点外面只是关菜单，不会顺带点到下面的东西；支持 Home / End。
- 页边外的书签刻度更好点中；拖书签更跟手。
- Markdown 里打不开的本地链接：点了会说明原因，样子也变成不可用。
- 横向滚动条可以用键盘。

**阅读助手**
- 输入栏上方的提示几秒后自己消失，开始打字也消失。
- 回答进行中变灰的控件，提示里写明为什么。
- 提问刻度最矮 8 像素，多了就滚动；图片和摘录上的叉平时也看得见。
- 刻度的预览在键盘操作时不再自己关掉；Esc 先关预览。
- 翻译栏清空要点两下；没发出去的字关掉再开还在。
- 快速解释卡片的提问框里按 Esc 只收输入，不关整张卡片。
- 复制问题或回答后，图标变成对勾。
- 长回答的重画间隔放宽；打开助手时旧消息分批出现，不再一下子卡住。

**总结、管理对话、记忆**
- 章节列表可以全键盘操作：上下移动，左右展开收起，空格勾选。
- 划选后的小输入框不再盖住选中的文字。
- 管理对话页的记忆条目：指上去有拖动把手；F2 修改、Delete 忘掉、Alt + ↑↓ 挪动。
- 让助手改记忆时可以停下；改完直接按 Ctrl + Z 能撤回。
- 设置里的记忆页也能按书折叠；编辑框随内容变高。
- 小问号可以点开钉住，再点、点外面或按 Esc 关闭，不会被边缘裁掉。

**文库与设置**
- 详情和移除确认框打开时焦点进去，Tab 不会跑到后面的页面，关掉后焦点回到原处。
- 分组可以按 F2 改名；新建分组的「+」再点一次收起；空名字点到别处是取消。
- 文档卡片按空格也能打开。
- 设置里改过东西后按 Esc、点叉或取消，会先问「放弃改动？」。
- 拖动并排面板、框选、卡片排序改成每帧算一次，更跟手。

## 删掉的操作提示

交互已经一目了然的，提示文字直接删了：空文库的两句用法（换成一颗「加入文档」按钮）、输入框占位里的「回车确定」、章节列表上方那句勾选规则、设置里 7 段只是复述标签或讲实现的说明（15 → 8）。「猜你想问」的 Tab 提示和分组改名改成隔几次冒一回的气泡，做过一次就不再提。
