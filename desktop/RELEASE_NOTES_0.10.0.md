# 开智 0.10.0

三项新功能：机翻、阅读助手的侧边对话、斜杠命令。

## 机翻
- 选中文字后右键「机翻」，或按 Ctrl+T：左侧滑出翻译栏，流式给出译文。
- 没有选中文字时，Ctrl+T 或右上角的翻译按钮（与设置按钮同样大小）开关翻译栏，开合带动画，阅读区跟着让位。
- 译成：自动（中文⇄英文）/ 中文 / English / 日本語；PDF 选区里被硬换行打断的句子会先接回整句再翻译。
- 译文按卡片排列，可复制、按当前语言重译、删除；也可以直接在底部输入框里粘贴文字翻译。最近 40 条保存在本机。
- 翻译用小而快的模型（与问题预判相同的选择）。

## 阅读助手：附属对话（侧边对话）
- 在回答里选中一段，浮出「添加到对话」（Ctrl+↓）和「在侧边对话提问」（Ctrl+→）。Ctrl+→ 会打开附属对话：整个助手窗口用弹簧动画加宽，右边多出一栏，中间一道细线隔开，可以左右拖动调整两边宽度。
- 附属对话和主对话是同一种助手：同样的思考过程、回答、复制 / 重新生成、模型与思考强度、文档上下文开关、图片、斜杠命令，只是没有分支。顶部标题栏与主对话齐平，标明「附属对话」和它挂在哪段主对话旁边。
- 上下文各自独立：附属对话开始时继承主对话当时的上下文；之后主对话再说什么，附属对话看不到，主对话也看不到附属对话。
- 两边的内容靠 Ctrl+方向键传递：选中文字后，Ctrl+→ 带到附属对话、Ctrl+← 带回主对话、Ctrl+↓ 摘录到本对话。选中的文字像一张小纸条飞过去，落成一张「摘录卡片」，之后的提问会带上它，可以随时移除。两边的输入框都不会被改动。
- 附属对话与主对话绑定、永久保存：换回这段主对话时它还在；删除主对话时一起删除；不出现在对话记录列表里。

## 阅读助手：斜杠命令
- 在输入框里打「/」弹出命令列表，方向键选择，Tab / 回车补全。
- /btw 问题：顺便问一句。回答显示在输入框上方的便签里，不写进对话记录，Esc 关闭。
- /compress [要求]：把目前的对话压缩成一份摘要。原消息仍在（变淡），之后的提问只带摘要和其后的消息，省上下文。
- /usage：用量卡。包括当前对话占用的上下文、今天的用量（对比近两周峰值）、本次会话的请求数与用时、按模型的输入 / 输出 / 思考明细，以及用量花在哪里（主对话、侧边对话、翻译、预判……）。可以一键复制为文字。三种界面风格各有样式：草稿风格是铅笔描边的便签，进度条用斜线涂出来。
