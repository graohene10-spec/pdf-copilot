# 开智 0.8.3

全面的流畅度优化，重点是液态玻璃。逐帧实测（同一台机器、同一套操作，帧时间中位数 / 95 分位）：

| 操作 | 之前 | 现在 |
|---|---|---|
| 滚动 PDF | 100 / 183 ms | 17 / 17 ms |
| AI 流式输出 | 100 / 133 ms | 17 / 17 ms |
| 打开 / 关闭阅读助手 | 67 / 200 ms | 17 / 67 ms |
| Ctrl+B 收放侧栏 | 50 / 100 ms | 17 / 67 ms |
| 打开 / 关闭设置 | 100 / 183 ms | 17 / 67 ms |

（17 ms 即 60 帧满帧。暖色极简与铅笔草稿本来就是满帧，保持不变。）

- **预设底板上的大面板不再逐帧重算模糊**：侧栏、顶栏、工具条、阅读助手和文档库卡片身后只有柔和的渐变，实时模糊和折射看不出差别，却在页面每次重绘时整块重算。现在它们直接用玻璃的底色与高光，外观几乎一致；弹窗、菜单、页码胶囊等压在内容上的玻璃仍是实时模糊与折射。
- **图片底板**：所有玻璃仍完整生效；内容滚动、AI 输出或弹窗弹出时，折射透镜短暂停一下（模糊不变），停下后马上恢复。图片底板下滚动 PDF 从 100 ms 降到 17 ms。
- **弹窗遮罩只压暗不模糊**：全屏实时模糊是打开设置时卡顿的主要来源，弹窗自身的玻璃仍会模糊身后的内容。
- **动画不再逐帧失焦**：关闭阅读助手、收起侧栏时去掉整块面板的模糊滤镜，只保留缩放与淡出。
- **收放侧栏和助手时**，横向滚动条不再逐帧强制重排，停下后再精确测量。
- 设置里说明了预设底板与图片底板下玻璃效果的区别。

0.3.1 起的版本可在应用内一键升级到本版本。
