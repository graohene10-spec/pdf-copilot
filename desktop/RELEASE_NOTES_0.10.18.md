# 开智 0.10.18

## 背景画面：放慢、减弱存在感，逐个重做

- 新画面全部放慢：洛伦兹轨道、凯莱图游走、Dijkstra、墨西哥帽的小球都慢到原来的三分之一左右。
- **DNA 双螺旋**：没有尽头——整条链沿轴缓缓滑过画面，两头褪进纸里，约九十秒才转一圈。原子只用纸色、铅笔、红笔三种平涂，不打高光，右下角划几道铅笔斜线当阴影。
- **墨西哥帽势**：曲面改成一片片纸色的小面片，近处挡住远处，从上往下看，帽顶、谷底、帽檐一目了然；地面只留两条轴和谷底的投影。
- **生命游戏**：直接拿桌面的格子纸当格点，一格一个细胞，不再是立体的；刚出生的细胞是红的，刚死的留一点淡影。
- **红黑树**（原「分形二叉树」）：键一个个插进来，破坏规则时重新着色，或者把一小段子树左旋 / 右旋——只有那一段在动，整棵树不转。
- **GB300**（原「机柜的海」）：近处画出机柜的样子——上下的电源框、两组计算托盘、中间的交换机段、托盘把手与网孔、柜顶的出风口和冷却液软管，每八个机柜留一条过道；细节随距离连续淡出，中景仍是一个个方头的机柜，再远才连成一线。镜头和波都慢了很多，同一时间只有一圈波。
