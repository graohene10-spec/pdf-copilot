# 更新已加载的扩展

适用于从上一公开发行版 v0.2.3 升级到 v0.3.2。首次安装请按 [安装与使用教程](USER_GUIDE.md)操作。

## 逐步更新

1. 在 [v0.3.2 Release](https://github.com/graohene10-spec/pdf-copilot/releases/tag/v0.3.2) 的 Assets 下载 **pdf-copilot-0.3.2.zip** 并全部解压。
2. 在浏览器打开 `edge://extensions` / `chrome://extensions`，找到 PDF Copilot 的详情，确认当前“加载自”目录。不要只更新一个没有被浏览器加载的另一份文件夹。
3. 关闭旧增强阅读器、侧栏、临时窗口和设置页。将新包 **extension 文件夹的内容**覆盖到原加载目录，保留该目录位置。无需先移除扩展，以保留设置和书签。
4. 回到扩展管理页，在 PDF Copilot 卡片点击 **重新加载**。
5. 使用 **Codex 本机登录**时，打开本版 `windows-helper`，双击 **install.cmd**，更新只读 PDF 工具桥接。仅用 DeepSeek / OpenAI API Key 时跳过。
6. 点击插件图标打开侧栏，再进 **⋯ → 模型与密钥设置**。顶部应显示 **v0.3.2**。Codex 用户点击 **检查连接并读取模型**，确认版本和登录；必要时重新选择模型并保存。
7. 重开 PDF 阅读页，确认 **自动上下文** 已勾选。默认开启，但用户主动关闭过的偏好会保留；已有 API 配置和书签沿用相同扩展 ID 的本地存储。
8. 先在增强阅读器用 **打开 PDF** 选择文件，不添加截图，提问“解释当前页”。确认出现等待提示和回答；图片模型消息可展开自动页图，文字模型读取当前页文字。

**成功标志：** 设置页为 v0.3.2，新页面显示字号按钮、上下文提示，直接提问可以提供当前页。只解压新包不会自动更新正在运行的旧代码，必须重新加载并重开旧页面。

## 本地文件与快捷键

本地 `file:///` 截图需要扩展详情开启 **允许访问文件网址**。从该标签页切入增强阅读器后，还需点击 **授权本地文件读取并打开 PDF**，以获得可选本地读取权限。也可以直接用 **打开 PDF** 文件选择器，避免网址读取授权。

设置页显示浏览器真正启用的快捷键；已有用户自定义组合会保留。显示“未设置”时点 **设置浏览器快捷键**，分配后返回点 **重新检查**。建议侧栏 Ctrl+Shift+7、增强阅读器 Ctrl+Shift+8、临时问答 Alt+Shift+Q、截图 Alt+Shift+S。

默认版与极简版使用同一扩展 ID，选择一版使用；不要同时保留两份启用状态的插件。遇到加载/连接问题，见 [逐步排障](USER_GUIDE.md#常见问题按提示排查)。
