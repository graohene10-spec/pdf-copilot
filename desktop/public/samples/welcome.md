# 开智 0.7.1 使用说明

开智用于阅读和管理 PDF 与 Markdown 文档，支持书签、手写标记和 AI 问答。

## 文档库

点击「加入文档」、按 `Ctrl + O`，或将 PDF / Markdown 拖入窗口。文档库记录原文件位置，原文件保留在原处。

- 用标签、收藏和搜索整理文档。
- 按加入时间、阅读时间、名称、大小或类别排序，也可保留默认排列。
- 右键书目可打开、收藏、更换封面或从文档库移除；封面可选首页、自选图片或默认图标。
- 阅读进度自动保存，重新打开时继续上次位置。

## 阅读与书签

`Ctrl + 滚轮` 缩放。PDF 可用 `Ctrl + 0` 适应宽度，超宽时拖动底部横向滚动条。Markdown 的文字、图片、公式和表格一起缩放，点击工具栏百分比恢复 100%。默认字号和内容宽度在「设置 → 阅读」调整。

按 `Alt + B` 添加书签，点击右侧玻璃标记跳转，右键命名或删除；`Ctrl + ↑ / ↓` 跳到前一个或后一个书签。

`Ctrl + F` 搜索正文，`Enter / Shift + Enter` 切换结果。`F11` 进入全屏；普通窗口与全屏都可收起顶栏和左栏，点左上角标签或按 `Ctrl + B` 展开。

## 并排阅读与标记

点击顶栏「并排阅读」或按 `Ctrl + \`，最多同时显示三栏。右键文件标签选择「在右侧再开一份」，可查看同一本书的不同位置；副本共用对话、书签和笔迹。

PDF 与 Markdown 均可手写标记：`Alt + 1 / 2 / 3` 切换钢笔、荧光笔、下划线，也可从工具栏选择橡皮。`Ctrl + Z` 撤销，`Esc` 退出。PDF 可清除本页，Markdown 可清除全部并撤销。

笔迹保存在本机：PDF 按页定位，Markdown 跟随段落布局。原文件保持不变，当前不提供带笔迹 PDF 导出。

## 阅读助手

在「设置 → AI」选择 DeepSeek、OpenAI、Claude、Kimi、智谱 GLM、通义千问或自定义接口，填写地址、模型与密钥；Codex 使用本机已安装并登录的程序。本机 HTTP 接口允许不填密钥。

打开阅读助手，输入问题后按回车发送，`Ctrl + Enter` 或 `Shift + Enter` 换行。点击模型按钮可展开模型与分段式思考强度；文档上下文开启时，助手可读取当前页并检索相关原文。

按 `Alt + Shift + S` 框选 PDF 或 Markdown，点击选区旁的气泡或按数字键发送；Markdown 同时提供截图与区域原文，公式附 LaTeX 源码。点「自己提问」带选区进入输入框。快捷问题可在「设置 → AI → 框选快捷提问」修改。

发出的问题下方显示附件与原文信息；回答的参考原文收在 Thinking 中，引用可点击跳转。右侧刻度可定位历史问题，悬停卡片可钉住问题。

「设置 → AI → 猜你想问」可开关问题推荐。有文字选区或已有文字对话时，空输入框会显示建议；按 Tab 或回车采用，再修改或发送，Esc 收起。推荐会消耗模型额度，关闭后清除建议并取消推荐请求。

对话文字和思考内容会保存，草稿与图片附件不跨重启恢复。

## 外观与更新

「设置 → 外观」提供六套底板、本机图片、字体，以及连续可调的玻璃透明度、模糊程度和边缘高光。边缘高光默认 50%；可单独开关光线折射，选择加厚玻璃、切换字色或关闭可读性补偿。

选择底板时先预览整个界面，点「采用」保留选择，点「不采用」还原；采用后再保存设置。拖动玻璃滑杆时，设置遮罩暂时撤去，便于观察效果。

「设置 → 更新」检查新版本。安装版和免安装版共用当前 Windows 账号的文档库；迁移到另一台电脑时，需同时备份文档库及原文件。新版优先使用 GitHub 附件摘要完成 SHA-256 校验，升级沿用设置和已保存数据。

## 示例

公式可以写成 $E=mc^2$，也可以单独成段：

$$
E=mc^2
$$

可以先导入同目录的 `sample.pdf`，试用页码跳转、书签、框选和文档问答。
