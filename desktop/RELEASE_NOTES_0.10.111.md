# 开智 0.10.111

## GB300 改用 WebGL 画

- 原来每个机柜要发五条绘制指令，一帧约五千条。现在每个机柜是一个实例，全部机柜一次交给显卡：一帧一次绘制调用。
- 线不再另外描：每个面在着色器里算出像素到边的距离，离边半个像素以内就是线。线的深浅只取决于几何，相邻机柜高低差一点点，粗细就连续地跟着变。0.10.109 里机柜之间的线一闪一闪的问题，是「够平就换一种画法」造成的，现在没有这种切换。
- 波、排、镜头、帧率目标（60）都和原来一样；近处的画面和原来基本一致，远处从「一道墙」到「一个个机柜」的过渡比原来平滑。
- 显卡不可用（或没有硬件加速）时，退回 0.10.108 的二维画法。0.10.109、0.10.110 里对二维画法的合并改动已全部撤回。
- 设置里的图案预览仍用二维画法。
