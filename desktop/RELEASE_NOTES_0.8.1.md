# 开智 0.8.1

铅笔草稿主题按反馈修改：

- **阅读助手头部**：拖动、改名、关闭这几个按钮各自用铅笔圈起来，看得出哪些能点；回形针挪到左上角，不再压住标题。
- **阅读工具条**：按钮改成实心的纸片；正在用的工具（框选、标记、目录、页面视图）涂成黄色。
- **阅读助手开关**：平时是白纸，只有助手打开时才变成黄色便利贴。
- **书签**：草稿主题下是夹在书页边上的红色小纸签，命名的书签写在黄色便签上；暖色主题也换成了暖色标记。
- **批量删除书签**：右键书签多了「删除全部 N 个书签…」，再确认一次就一起删掉；选中书签按 Delete 也能删。
- **页面不再浮空**：纸张改为贴着桌面的短投影，上沿不再淡出。
- **并排的文档组**：红笔圈放大，圈在整组页签外面，不再被页签挡住。
- **分屏选中的那栏**：去掉圆角红框，改为工具条下一道红笔划线，没选中的那栏淡一些（暖色主题是一道陶土色细线）。
- **字号**：便利贴上的问题、输入框里的字、AI 的回答都调小一号；横线本的行距随之收紧。输入框的蓝胶带挪到右边，不再挡住回答下面的复制、重答按钮。
- **回答里的代码、表格、流程图也跟着风格走**，可读性优先：
  - 铅笔草稿：代码块是贴着胶带的白色索引卡，表格是铅笔格子、表头用黄色荧光笔涂过，流程图用手绘线条和便利贴色块，引用旁一道红笔竖线；代码仍是等宽字，公式仍用数学字体。
  - 暖色极简：代码块与表头用暖沙色，流程图用象牙白与陶土色，引用用陶土色细线。
- 删除了输入框里「草泥马，能不能说人话。」这条提示语。

0.3.1 起的版本可在应用内一键升级到本版本。
