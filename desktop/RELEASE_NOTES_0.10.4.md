# 开智 0.10.4

## 单页 / 双页切换时页面飞到一边
原因：切换后页面先按旧比例排成新版式，要等新比例画好才铺满。这段时间两页并排比阅读区还宽，又被居中摆放，左页被挤出屏幕、右页从屏幕中间开始。PDF 越大，画得越慢，这个状态停留越久。

- 切换时先把页面藏起来，新版式排好后淡入。
- 两页并排比阅读区宽时贴左排，不再往左溢出到滚不到的地方。

## 暖色极简也有底板动画
- 自转的流形、训练中的神经网络和知识注记，现在暖色极简里也有：墨棕色线条、陶土色标注、衬线字注记；深色主题同样适配。
- 设置 → 外观里的「背景动画」「阅读时也显示」「轮换」在暖色极简下也能调。液态玻璃不变。
