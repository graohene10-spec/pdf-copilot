# 开智 0.3.0

- 新增 PDF 手写标记：可在页面上用笔、荧光笔划线做记号，笔迹带手写的粗细变化，可擦除、撤销，并随文档保存在本机。
- 同一本书可以多开：在文件标签右键「在右侧再开一份」，两份各自保留阅读位置，共用对话与标记。
- 并排阅读时，点另一本书不再让阅读助手来回切换对话；助手标题下可主动「改读」另一份。历史记录新增「全部文档」，可以集中查看、打开所有文档的对话。
- 阅读助手重新设计：标题栏与输入框成为独立的浮动玻璃层，主体颜色更沉稳，不再泛白。
- 空白对话页改为按时间段随机的问候语；旁边的形象可在设置中更换：像素小螃蟹动图（默认）、Claude、ChatGPT、DeepSeek，或上传自己的图片 / GIF / 动态 WebP。
- 字体：设置中可导入本机字体文件（TTF / OTF / WOFF / WOFF2），导入 Anthropic Serif 后阅读字体自动使用它。字体只保存在本机，不随应用分发。
- 设置中拖动透明度、模糊度滑杆时，设置窗口会暂时变淡，可实时看到界面效果。
- 关闭侧栏、PDF 栏和助手栏时有收拢动画；打开文档改用合成层交叉淡化，不再一卡一卡。

安装版与免安装版继续使用原文档库、阅读进度、主题、设置和已保存凭据；应用内「检查更新」可直接升级到本版本。

Windows x64 发布包含安装版、免安装 ZIP、完整源码 ZIP、程序清单和 SHA-256 校验文件。
