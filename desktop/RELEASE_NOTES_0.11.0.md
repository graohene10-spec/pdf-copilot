# 开智 0.11.0

## 安装路径与程序名改成英文
- 程序名改为 `OpenIntelligence.exe`，安装目录改为 `%LOCALAPPDATA%\OpenIntelligence`。窗口标题仍是「开智」。
- 从旧版本自动更新时：新版本装进新目录并启动，旧的「开智」安装在后台静默卸载。文档库、对话、设置都在原来的应用数据目录里，保留不动；桌面与开始菜单的快捷方式换成 OpenIntelligence。
- 便携版：压缩包里的程序也叫 `OpenIntelligence.exe`，自动更新后会删掉旧的 `开智.exe`。

## Codex 翻译 / 回答变快
原因在阅读器：之前每发一次请求都要重新启动一遍本机小助手和 `codex app-server`（加载配置、校验权限），光冷启动就要好几秒，翻译这种短请求大部分时间都花在这上面。
- 小助手的连接现在用完留着复用，空闲 5 分钟才关；同时有几个请求时各用一条连接。
- 打开阅读助手、或翻译选了 AI 时，如果用的是 Codex，会提前把小助手拉起来。
- 停止回答后等小助手确认收尾再复用这条连接，不会把下一个请求卡住。

## Fast
- Codex 本机登录与 OpenAI API 支持 Fast（优先通道：出字更快，额度消耗更多）。模型抽屉的「思考」一行右侧有 Fast 开关，开了之后模型按钮上有一个小闪电；设置 → AI 里也能开。
- Codex 走 `serviceTier: fast`；如果本机 Codex 版本太旧、不认这个参数，会自动去掉它重试。OpenAI 走 `service_tier: priority`。

## 翻译与阅读助手的 AI 设置分开
- 设置 → AI → 「翻译用的 AI」：默认「与阅读助手共用服务商」，一键勾掉就能给翻译单独选服务商（需要时单独填密钥）。
- 翻译和阅读助手各自选模型、思考强度和 Fast。翻译模型留空时自动用该服务商的小模型。
- 翻译栏选了 AI 时，下面多一枚小标签显示当前用的服务商和模型，点开就能换模型、强度、Fast。

## 摘录放进输入框
- 选中回答里的文字后「添加到对话」（Ctrl ↓）、「在侧边对话提问」（Ctrl →）、「返回主对话提问」（Ctrl ←）：摘录飞进目标对话的输入框，在输入框上方排成一行一枚，悬停看全文，可单独移除。
- 发问题时摘录随之发出，问题下面显示带过的摘录；对话列表里不再插入单独的摘录卡片（旧对话里已有的摘录卡片照常显示）。

## 字体
- 界面字体、阅读字体、铅笔草稿的回答字体都可以直接选常用西文字体：Arial、Times New Roman、Georgia、Segoe UI、Calibri、Verdana、Garamond、Cambria 等。中文部分自动落到黑体或宋体。

## 暖色极简
- AI 栏的拖拽条挪进 AI 栏一侧，不再压在阅读区滚动条上。
