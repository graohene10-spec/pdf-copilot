# 开智 0.2.0 · Windows 桌面版

基于 Tauri 2、Vue 3、TypeScript、Rust 和 SQLite 的 PDF / Markdown 阅读与管理工具。

## 功能

- 文档库、标签、收藏、搜索与阅读进度；多文件标签分别保留阅读位置、缩放和本次运行中的 AI 对话。
- PDF 连续阅读、目录、选文和框选；Markdown 排版、公式、本地图片、目录与源码视图。
- OpenAI API、DeepSeek 与本机 Codex；流式回答、原文检索、引用跳转，以及各文件独立的 AI 会话和共享并发队列。
- 外观、阅读、AI 与快捷键集中设置；Windows 启动自动按工作区最大化。
- 本地图片底板、0–100% 连续玻璃透明度、局部文字和图标明暗适配、茶色毛玻璃弹窗；深浅主题和系统辅助显示设置。
- PDF 侧栏适配时保留原画面，后台重绘完成后统一提交尺寸和清晰画面，减少空白闪烁与重复尺寸切换。

## 下载与升级

| 文件 | 用途 |
| --- | --- |
| `开智_0.2.0_x64-setup.exe` | Windows x64 安装版 |
| `开智_0.2.0_x64-portable.zip` | 免安装版，解压后运行 `开智-portable/开智.exe` |
| `开智_0.2.0_source.zip` | 与 `desktop-v0.2.0` 标签一致的完整源码 |
| `manifest.json` | 安装包与免安装程序的构建校验清单 |
| `SHA256SUMS.txt` | 本次发布附件的 SHA-256 校验和 |

免安装版使用系统 WebView2，请保留旁边的 `native-host/` 文件夹。AI 服务需要用户配置，Codex 使用本机已有安装与登录。升级继续使用原来的文档库、阅读进度、设置与已保存凭据。

源码包含桌面应用、浏览器插件公共模块和本机助手；从源码构建请按 [桌面 README](../desktop/README.md) 先在根目录构建助手，再进入 `desktop/`。浏览器插件保留自身版本号，本次发布标签为 `desktop-v0.2.0`。

## 验证

封装时通过 39 项 JavaScript 测试、7 项 Rust 测试、前端类型检查和 Windows x64 生产构建。实际免安装程序验证 PDF / Markdown 阅读、深浅主题、设置与本地图片保存；图片原文件移除后，底板仍可在重载后恢复。程序内置版本号为 0.2.0，安装包、免安装目录、ZIP 与构建校验清单一致。
