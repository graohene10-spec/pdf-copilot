# 开智 0.10.85

自动更新更可靠（针对「点了更新、重启后还是旧版」）：

- 更新前先关掉随应用启动的 Codex 小助手：它就在安装目录里，开着的话安装程序换不掉那个文件。
- 旧程序没能在两秒内退出时强制结束它，再等一秒才开始安装，不让安装程序碰上还被占用的程序文件。
- 装回正在运行的这一份所在的文件夹。以前安装程序按系统里记的位置装，电脑上有两份开智时可能更新了另一份，重启的仍是旧的。
- 安装程序报告失败时等几秒自动再装一次。
- 重启后如果还是旧版，会明确告诉你「上次更新没有装上」和大致原因，并给「重试」，不再悄悄停在旧版。

快捷键：

- 新增「收起 / 展开顶栏与侧栏」，默认 Ctrl + Shift + H，可在设置 → 快捷键里改。
