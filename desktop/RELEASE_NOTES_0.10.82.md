# 开智 0.10.82

Intelligent UI：

- 阅读助手和快速解释用的是同一套组件、同一个渲染器，画出来完全一样；给模型的说明分成两份：阅读助手里图解和可交互并重、按内容选（两者都合适时可以各放一个）；快速解释首选图解，可交互（模拟、图表、表格）只作可选的补充。
- 一张图第一次出现时是「画」出来的：线条描出来，色块和文字依次浮现，只走一遍；回答还在写时不会从头重来。
- 映射图：圈出一组点（核、像）时先把这组点排到一起，不再把中间不相干的点也圈进去。
- 图表：坐标刻度在窄栏里不再缩成看不清的小字；修掉图表左下角那个空的小圆框。
- 模拟：参数名和当前值排在一行，「重置」收到标题右上角，读数之间加细线。
- 草稿主题：图解的线描粗一点，圆和外框不再断开。

Intelligent UI 合集：

- 草稿主题下是一张张铅笔描边的纸片；图不再多套一层框。
- 进入时一张张浮上来；删除时缩一点淡出，剩下的滑过去补位；确认条滑入。
- 提示缩短，隐藏和合集无关的文档统计。

触控板：

- 两指捏合缩放文档：WebView2 默认不把这个手势交给页面，现在打开；按手指张开的幅度缩放，不会一捏就飞出去。整个界面不会被放大。

Codex：

- 装了 Codex 桌面版就能用，不必另装 CLI：优先用桌面版自带的引擎，其次才是 PATH 里的 CLI。设置里的说明和状态相应改成「桌面版 / CLI」。

其他：

- 设置换页、点开思考过程 / 参考原文时内容轻轻展开，不再硬切。
- 输入框里占位的句子太长时，最下面一行淡出，不再被拦腰截断。
