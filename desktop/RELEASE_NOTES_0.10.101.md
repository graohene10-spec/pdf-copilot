# 开智 0.10.101

- 教程：鼠标和它点的地方对不上的问题修好了。原因是画面缩放把镜头的位移一起放大了，镜头离左上角越远错得越多（「阅读助手」一课最明显）；点击的水波纹现在也跟着画面走。
- 教程「快速解释」一课加了一步：双击标题，就这段内容自己问一句。
- 阅读助手里，问题下面的引文、图片、页码一律只占一行；「编辑」「复制」放进同一行左边，指上去就出现，不再悬在消息外面。
- 输入栏从「思考中」到「答完」有了过渡：停止键旋转着换回发送键，灰掉的控件渐渐亮回来，输入栏外沿荡开一圈光（只一次）。
- 书签：滚动条旁的刻度一直都在，翻到书签那一页也不再收起。
- 侧栏的书签列表：页数一律靠右对齐。
